落地方式（选定后我来接）

1. productName 由「校园叙事 RPG」改为「他山之石」，窗口标题与任务栏随之变； 桌面图标换成 Game/Assets/icon.png（现有那张是占位）。
2. exe 文件名要不要跟着改是个决定点：改中文他山之石.exe 会打断 taskkill //IM Campus.exe、构建脚本与 docs 里所有验收命令； 建议 exe 保留 Campus.exe，对外显示名走 productName。
3. Unity 默认 splash 去不掉：m_ShowUnitySplashLogo=0 与自定义 splash 图都是 Pro 版功能， 个人版只能在它后面接一段我们自己的开场 logo（黑底 → 标题像素字淡入 → 青色横线划出 → 淡出进主菜单）， 这段完全由代码控制，也就是你实际会看到的 logo。
4. 标题字用系统字体（雅黑 / 楷体）程序化烘成贴图，不引入外部图片资产，符合本作"资产全程序化"的约定； 像素版是真实像素化处理（先小字号栅格化再最近邻放大），所以它确实是 16-bit 质感而不是模糊放大的字。
