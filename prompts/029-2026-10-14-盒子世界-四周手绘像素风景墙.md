# prompt-029 · 盒子世界：四周高墙手绘像素风景 + 夜空叠加层（2026-10-14）

## 目标

作者提议："要不把整个场景改为在一个盒子里并不是平面，盒子四周加高像素贴图"（此前 3D 锥形山反复调整仍不满意：近看大灰锥、和建筑重合、没颜色）。

## 方案（采纳作者思路）

1. **四周高墙（盒子世界）**：四面板墙（±82，高 34 ≈ 20°仰角），墙上贴**手绘像素风景全景**（8192×768 画布，四面各取 1/4 段）：
   - 层叠山脉三层（远山青灰+雪顶 / 中山青绿 / 近山深绿）+ 两条雾带 + 山脚双层松林；
   - **关键校准**：可见视角带只覆盖墙下部（仰角 0-7°），风景全部压缩绘制在画布 y 406-610 的该带内；风景以上为天底渐变（与穹顶地平线色衔接）。
2. **夜空叠加层**：第二张透明画布（星星 900 + 十字亮星 22 + 块状像素月亮）覆在墙内侧 0.6u 处，加色混合，夜晚随昼夜混合值淡入（白天不可见）。
3. **材质**：墙与星空层均 fog=false 不受灯光；墙颜色按昼夜染色（白天原色 / 夜晚压暗偏蓝 #3d4a66 / 晨昏微暖）。
4. **移除**此前全部 3D 锥形大山（MOUNTAINS）——被手绘墙体取代；保留边界林带/远景楼/假山作为中景层次。
5. 天空穹顶的云/星带同步上移（墙顶之上区域），供更平视角时可见。
6. 版本号 → **v0.29**。

## 验证

- 白天：校区上方可见墙上风景的山脉青绿横带（常态俯角）；平视角可见完整山脊+雪顶+松林。
- 夜晚：墙压暗为深色山影，星空叠加层点亮（星星+月亮）。
