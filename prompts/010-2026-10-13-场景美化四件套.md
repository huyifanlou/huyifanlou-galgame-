# prompt-010 · 场景美化四件套：配色 / 大门 / 间距 / 栅栏（2026-10-13）

## 目标

作者反馈：① 建筑和植被色彩太单调 ② 大门只有一块黑色 ③ 建筑间距太近 ④ 路两边加栅栏。

## 我的 Prompt（原文）

- 「整体建筑和植被色彩还是太单调了，需要丰富，建筑门的位置只有黑色的一块，需要添加，建筑物之间的间距可以拉大一点到合理的位置，路的两边需要添加栅栏，」

## AI 产出

- **建筑四色系**（不再灰扑扑）：
  - 教学楼：奶油白墙 + 檐口/楼层线描边 + 红棕顶 + 侧楼 + 天线（红顶针）
  - 宿舍楼：砖橙墙 + 蓝灰双坡屋顶 + 屋顶水箱
  - 图书馆：石灰色 + 墨绿双层顶 + 台基 + 立柱
  - 食堂：暖黄墙 + 红顶 + **红白条纹雨棚**（程序化条纹纹理）
- **外墙纹理升级**：砖石噪点、檐口/楼层线/基座三段配色、窗户带窗框 + 随机亮灯/暖色窗帘/窗台花箱
- **大门重做**（程序化 doorTexture）：门框 + 暖光气窗（带窗棂）+ 双开木门 + 金色把手 + 踢脚线；门口新增**台阶**与**两侧门灯**（暖光）
- **建筑间距拉开**：教学楼 (-16,-12)、宿舍楼 (14,-10)、图书馆 (0,-22 北移至纵路尽头)、食堂 (20,10)；图书馆正对纵路尽头（纵路缩短至其门前）；新增 **3 条岔路**从主路通往教学楼/宿舍楼/食堂
- **栅栏系统**：12 段白色栅栏（立柱 + 双横杆），沿两条主路两侧；缺口与十字路口 / 岔路 / 操场入口一一对齐；**加入碰撞**（不能穿栏，须走路口）
- **植被多色**：树冠六色（深绿/中绿/亮绿/黄绿/**樱花粉**/**金叶**，共 4 棵彩色树）；灌木四色

## 结果

- 已推送；默认视角 / 全景 / 岔路口三张截图逐一验证
