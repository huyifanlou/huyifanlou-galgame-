# prompt-006 · 画面清晰度二轮修正 + 引擎选型调研（2026-10-13）

## 目标

作者反馈"还是不够清晰，考虑换引擎"→ 先联网调研同类游戏的引擎选择，再决定技术路线并修复画面。

## 我的 Prompt（原文）

- 「还是不够清晰，要不你换个好点的游戏开发引擎，或者网上搜索类似游戏使用的是什么引擎」

## 调研结论（联网核实）

- **星露谷物语**：C# / MonoGame（自研框架，非 Unity/Godot），2D 像素画，**原生分辨率**渲染
- **八方旅人（HD-2D）**：虚幻引擎 4 —— 高清 3D 场景 + 2D 像素精灵 + 后处理（移轴/景深/泛光）；**像素感来自美术资产，不是降分辨率糊化**
- **中国式家长 / 太吾绘卷**：Unity（国产模拟经营的主流选择）
- **共同规律**：画面清晰的关键是**原生分辨率渲染**，引擎不决定清晰度

## 决策：不换引擎，修渲染方案（记录理由，供技术文档引用）

1. 根因是渲染策略（此前的"整帧降分辨率再放大"）而非引擎能力——换引擎沿用此策略依旧糊
2. 比赛硬约束：「10 分钟极速复现」——纯 Web 单文件（1.1 MB）双击即玩 vs Unity/UE 导出数十 MB + 需安装环境
3. AI 协作效率：本项目的迭代方式（代码直改 + 秒级构建 + 自动截图验证）在 Web 技术栈下最快；Unity/UE 的编辑器 GUI 流程会显著拖慢 5 周工期

## 修正内容

- 默认画质 1/2 → **`dpr=1` 原生分辨率（高清档）**；画质档位改为 0.5 / 0.75 / 1 / 1.5（P 键循环）
- 纹理采样策略：`magFilter` 保持 Nearest（像素风美术）+ `minFilter` 换 mipmap（远景稳定不闪烁）
- **开启 MSAA 抗锯齿**（几何边缘平滑，纹理保持锐利）
- 程序化纹理细节翻倍：草地 32×32、石板路 2×2 石板带勾缝/磨损、窗户带窗框/楼层线/基座阴影、招牌 320×80 / 52px 加粗
- 新增半球光（天空/地面双色补光），室外色调更自然

## 结果

- 单文件离线版更新（1115 KB）；"宿舍楼"等招牌在原生分辨率下清晰可读；关联提交见 git log（prompt-006）
