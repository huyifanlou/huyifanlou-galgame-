# 110 樱花林重建与天空旧渲染清理

2026-11-11，按作者要求重建樱花林，配合学校区虚影排查。

## 樱花林

旧樱花是长直树干加多个粉色球壳，交叠处有黑缝，枝条与花冠连接生硬；启动时还会生成不再显示的旧体素樱花网格。

`WorldBuilder.CherryGrove.cs` 改为低处分叉、横向展开的枝条与伞形花冠。`BlossomCrown` 将多个椭球场融合为连续闭合表面，沿采样边共用顶点，统一重算法线，顶点色提供柔和变化。四种普通樱花有冠高、花色和垂枝差异；巨樱降低直干比例、扩大横向树冠，保留现有林道和中央空地。

- 树内按材质合并，花冠关闭外扩描边，降低边缘光，继续接入 LeafMats 天气覆雪。
- 樱花不再使用整树 ProximityHide，树下观察时不会整棵突然消失。
- 林下杜鹃改为低花丛，区域内贴地花纹换成立体小花；落瓣避开林道，降低数量、尺寸和亮度。
- 树下长椅、石灯笼、步石重建；灯笼接入昼夜暖光。
- 学校、北侧连接步道和林道通过铺装并集去除共面覆盖。
- 删除旧体素字段、叶团/树干生成函数、旧普通樱花分支与旧巨樱实现，不再生成备用旧网格。

## 天空

旧天空把 64×128 的云贴图铺在两层透明天穹上，放大和染色后成为明显的灰色大块。已替换为 `Resources/Shaders/WorldSky.shader` 单层天空，按视线计算渐变、小尺度云、星星与月亮，时间系统直接控制昼夜、晨昏及天气亮度。

删除旧双穹渲染及无效 `_skybox` 驱动；后处理色调量化只作用于有实体深度的像素，保留天空连续渐变，避免夜景产生弧形色带。历史 sky_day / sky_night 配方仅供旧贴图导出对拍，当前场景没有引用。
