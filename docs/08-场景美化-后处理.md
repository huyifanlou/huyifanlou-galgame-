# 08 · 场景美化①：后处理栈（2026-10-16）

按 HD-2D（八方旅人风）主流配方，自写后处理栈（Built-in RP，**不引入第三方包**）：

| 效果 | 作用 | 参数 |
| --- | --- | --- |
| **移轴景深** | 画面上下虚化、中央清晰 → 微缩模型质感（HD-2D 灵魂） | 焦点带 0.16 / 过渡 0.30 / 强度 0.7 |
| **泛光 Bloom** | 路灯/窗户/月光发光晕开（夜晚尤为明显） | 阈值 0.72 / 强度 昼 0.30 → 夜 0.72 |
| **暗角 Vignette** | 四周压暗、聚焦中心、怀旧感 | 昼 0.62 → 夜 0.78 |
| **色彩分级** | 饱和 ×1.12、对比 ×1.06、暖色调 ×(1.03,1.00,0.96) | — |

实现：`Assets/Shaders/PostFX.shader`（3 个 Pass：亮度预过滤 / 可分离高斯模糊 / 合成）+
`Assets/Scripts/PostFX.cs`（半分辨率双级模糊，性能友好），运行时挂到主相机，随昼夜联动。

验收截图：`docs/img/fx-day.png`（可见上下虚化与中央清晰）｜`docs/img/fx-night.png`（路灯/窗户发光晕开）。
