## 一、白底残留（修一类，六张全修）

残留是两类：**封闭白底洞**（腿间/臂间白三角，边界 flood-fill 够不到）与**漂浮白点/水印碎屑**。
`tools/matte-portraits.py` 重写为五步：边界 flood-fill → 水印黑框按区域强制透明 → 封闭洞种子点泛填 → 漂浮白点 → 去白边 feather。
**全程在无损生成原图（`vibe_images/*.png`）上做**，最后按入库 jpg 的同公式裁切补白到 1024×1536，保证与自选菜单用的 jpg 构图一致。

踩过的判据坑（都实测失败，别再试）：
- 在 **JPEG 上**用「连通块均值≈背景色」判洞：背景与衣物白均值差实测 0.1~0.9 灰阶**互相重叠**（白T均值被褶皱拉回背景值），必误吃衣服。
- 容差 ±1 泛填穿不过 JPEG 噪声（只走 2 像素）；±3 又会沿轮廓抗锯齿漏进衣物。
- 最终方案＝**种子点泛填、安全性靠连通性**：洞与衣物被深色轮廓隔开互不连通，泛填到轮廓即停，故容差可放宽 ±8；
  种子点逐张标定在 `HOLE_SEEDS`（源图归一化坐标），换立绘后对着深色底看图重新点。
- 水印检测阈值：黑框用 `max<210`（莉莉雅那粒是浅灰 ~190，120/180 都够不到）；区域逐张标定在 `WM_REGION`
  （莉莉雅在右下 (0.90,0.975)–(0.954,0.988)，区域放太宽会擦到鞋）。
- 瑶清寒只有 jpg 且背景与白衫同色（都 255）→ 不做洞判定；改清「独立小连通块且均值纯白」（裙侧白线碎屑），
  加均值纯白条件是因为皮肤暖白高光 (255,244,238) 也近白，不加会吃脸和腿。

## 二、瑶清寒缩小一圈

她原图人物占画布高 0.97、宽 0.999（坐姿撑满），其余站姿约 0.97 高但窄得多 → 同高度规则下观感大一圈。
处理：jpg 侧把人物 bbox 裁出、**线性缩到 0.80** 居中补白回 1024×1536（现占高 0.80、宽 0.71），再重跑 matte。
对话立绘高度规则不变（框高 ×2.5，全局统一），只改她源图留白 → 实机里她比别人小一圈。

## 三、按键侧边栏（H）

新组件 `Game/Assets/Scripts/HelpSidebar.cs`，`H` 开关，世界与剧情播放中都可用；验收钩子 `-help` 开场即开。
内容五组：移动/视角、世界交互、时间/天气、剧情、系统（含地图手势与开场跳过），与 PlayerRig/TimeOfDay/Weather/Minimap/DialogueManager 实际绑定逐条对齐。
**挂载顺序坑**：OnGUI 默认按脚本名排序，Minimap 会在 HelpSidebar 之后画、小地图盖住侧边栏 →
组件挂在 CharacterPicker 之后创建（WorldBuilder.cs）并设 `GUI.depth = -100`（depth 越大越先画，实测 +100 仍被盖）。
自选菜单卡片也改用透明 `-cut` 版（原来用白底 jpg，卡片上一块白矩形）。
Hud 左上操作行与对话框底行都补了「H 按键侧栏」提示。

## 四、剧情浏览章节目录（L）

`DialogueManager.DrawLog` 改双栏：左栏章节目录（「全部章节」+ 八章，当前播放章带 ▶），点章过滤右栏句子；
打开时默认落在当前章并滚到当前句；右栏点任一句仍 `JumpTo` 定位播放（含后续句）。
章标题本身含「第一章 …」，目录与列表头不再重复拼「第 N 章 ·」。
