# 115 · 虚影、全图路灯与主线追踪传送衔接

2026-11-14。作者截图反馈：路边虚影、全图灯位不合理、缺少明显的主线追踪与直接传送，并要求出生在家中。

## 本轮改动

- 脚底“圆影”原材质没有遮罩，0.84m 方片整片可见。MatLib.Shadow 改用 64×64 双线性采样的径向透明遮罩，圆外 alpha=0，边缘渐隐，保留正常太阳投影。
- TownLampPlanner 在完整世界数据生成后统一重排灯位。街道灯杆置于人行道外缘以外，灯臂朝道路；按原候选纵向前后搜索，并过滤建筑、门厅、家门通道、车道/人行道、河岸步道、广场步道、围栏、实体障碍、树木与灌木，灯杆之间至少 5m。无法安全放置的候选剔除，不把杆挤进通行带。
- 主线卡持续显示章节、目标与进入室内的要求。J 展开剧情追踪；换段自动展开，显示当前场次、章内步数以及到达方式。Esc/J 收起后可继续步行探索。
- 卡片按钮或 G 执行“传送并继续”：当前室内先正常离开，需要室内的目标走门外安全点→进门过渡→门厅安全点（避开角色站位）→恢复当前剧情，不重置章节；到达后自动存档。地图大图也有同一主线按钮。
- 室内地图将玩家箭头投影到当前建筑门口，避免室内坐标区 x≈900 使箭头消失。地图自由传送共用室内外衔接流程：人在屋内也能选地标或双击空白传送，先出门再找室外安全落点；自由传送不自动播放剧情。
- 常规新开游戏出生在家中门厅，镜头朝室内；幕前世界说明的剧情入口也在家中，读完再追踪学校南边街。显式定位、室内、剧情和校验参数保留原验收语义，不抢占读档落点。
- 保留原八章正文、存档格式和已有手动档。不提交、不推送。
