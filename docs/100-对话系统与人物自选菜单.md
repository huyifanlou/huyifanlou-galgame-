# 100 · 对话系统 + C 键人物自选菜单（玩法线零的突破）

> 写于 2026-11-07。本轮把**剧本线**（docs/90~95 的第一卷 8 章扩写稿）正式接进**工程**：
> 行语法 → 可播放对话序列 → IMGUI 对话框（立绘卡＋名字条＋旁白/内心/演出分样式）。
> 同时把 C 键从「盲循环」改成「六人自选菜单」。这是 docs/89 第八节第 1 项（剧情与对话系统）的首次实装。
> 立绘重画（樊楼/景楠）因 ImageGen 额度耗尽本轮搁置，沿用现有 `Portraits/` 图。

---

## 一、做了什么

1. **剧本解析器** `ScenarioData.cs`：把第一卷 8 章 `.md` 的行标记正则解析成对话数据。
2. **对话运行时** `DialogueManager.cs`：IMGUI 播放（对齐 Hud/IntroScreen 纯代码 UI 路线），打字机＋点击推进。
3. **人物自选菜单** `CharacterPicker.cs`：C 键弹出六人卡片，点选/数字键 1–6 切换玩家模型。
4. **入口**：命令行 `-scenario <章号> [-scenline <句序>]`；世界里按 **B** 开/继续剧情。
5. **构建期同步** `Bootstrap.SyncScenario`：每次构建自动把 `Scenario/第一卷-初遇/0*.md` 拷进 `StreamingAssets/Scenario`，源文件不动。

## 二、剧本解析规则（与 docs/95 行语法一一对应）

| 源行 | 处理 |
|---|---|
| `# 第一章 …` | 章标题 |
| `## 场 N｜标题` / `幕前` / `幕尾` / `本章背景` | 正文分场，更新左上场景标签（非阻塞） |
| `## 台词分布/新增事实/拿不准/裁定/回退清单/待你定` | **文末附录：一遇到即停止解析**，之后整段丢弃 |
| `【场景】X` | 更新地点副标题（非阻塞上下文） |
| `【BGM】X` / `【音效】X` | 更新左上 ♪/🔊 提示（非阻塞） |
| `【旁白】X` | 叙述行（对话框，无名字条，暖灰字） |
| `【内心】X` | 心声行（对话框，斜体冷蓝字） |
| `【演出】X` / `【黑屏】` / 其它【标签】 | 演出行（屏幕居中斜体灰字） |
| `【伏笔】X` | **隐藏，不显示给玩家** |
| `角色：「…」` | 台词行（立绘卡＋名字条＋对话框） |
| `**第N章 完**` | 结束卡（居中大字） |
| 行首 `※` | 新写行标记，剥掉后照常显示 |
| 行尾 `†` | 说话人判定标记，剥掉 |
| `> …` / `---` / 表格 / 散文 | 跳过 |

**实测计数**（Python 原型与 C# 同规则核对）：全 8 章共 **958 步**＝台词 602 ／旁白 115 ／内心 21 ／演出 212 ／结束卡 8。
每章结束卡恰 1 张（`**第N章 完**`），证明附录被正确截断、无校验表泄漏。
说话人前列：樊楼 198 ／镜荧 165 ／景楠 64 ／莉莉雅 50 ／瑶清寒 38 ／紫薇 7，六位主角都有立绘。

**说话人 → 立绘**：`ScenarioData.PortraitResource(speaker, cut)` 从 `CharacterDef` 六人预设反查（`label → id`，樊楼 id 空补 `fanlou`）。
`cut=true` 取抠白底透明 PNG `Resources/Portraits/{id}-cut`（对话用）；`cut=false` 取白底 JPG `{id}-dialogue`（自选菜单缩略图用）。
无名角色（同学甲/校长/广播/士兵/人界代表…）只给名字条、无立绘。
透明 PNG 由 `tools/matte-portraits.py` 生成：从四边 flood-fill 近白像素当背景（内部白·白发/白衬衫保留）＋边界去白边 feather；
逐张阈值（默认 240，镜荧渐变浅灰底用 232；瑶清寒肤浅靠纯白底 240 保护腿部）。源 JPG 不动。

## 三、对话运行时

- **UI**：压暗世界 → 居中窄对话框（深色半透＋青色顶线，宽 0.62W）→ 名字条居中（角色名＋青色下划线）→
  **透明立绘一左一右**压在对话框两端之上（后画＝在框前面）。左上场景标签（章·场＋地点＋♪/🔊），右上进度（第 N/8 章 · 句 X/Y）。
- **立绘去白底**：改用抠图透明 PNG（`{id}-cut`），不再用白底展示卡；角色直接站在场景里。
- **一左一右**：维护 `_slotL/_slotR` 两个说话人位＋`_activeSide`。当前说话人全亮、搭档压暗（0.45）；
  新说话人顶替「当前暗的那一侧」、原说话人留下作搭档，左右位在一场对话内稳定不跳。
  开场/跳转时 `SeedSlots` 往回找最近两个不同说话人，保证一开就是双人而非单人。旁白/内心两人皆暗。
- **环境相适应**：`EnvTint` 按 `TimeOfDay` 昼夜/晨昏/室内给立绘乘光色（白天暖白、夜晚冷蓝、晨昏橙、室内中性）。
  本轮**整体提亮**：夜晚亮度下限 0.70→0.90、夜色 (0.60,0.66,0.85)→(0.78,0.83,0.98)、去掉 0.92 总压暗；暗搭档系数 0.45→0.62。
  解决「晚上立绘太暗」（对比 `shots/101-night.png` 旧 vs `shots/103-night.png` 新）。
- **正文安全区**：对话框正文左右让开立绘压住框边的宽度（`padL/padR` 按立绘宽自适应），名字条与提示居中，保证可读。
- **立绘统一尺寸（本轮）**：高度统一＝对话框高 `BoxH` 的 **2.5 倍**（不随原图 aspect 变高度，只变宽度），底边对齐框底。
  水平**居中于「框边↔页面边」的边距带**（不贴框），夹取保证不出屏；为此对话框收窄到 `BoxW=0.44W` 给两侧让位，
  正文用满框宽（立绘不再压框，`padL/padR` 回归常规 28）。
- **剧情浏览＋定位（崩铁式，104 轮扩展）**：对话中按 **L** 或点「回顾」开面板，滚轮浏览。
  旧版只列「已播句子」，无法看后续；现改为**列出全部 8 章全部句子**：已播＝白、当前句＝青色加粗、未播后续＝灰。
  **点任一句即定位**到该句重新播放（`JumpTo`，向前/向后均可）。打开时自动把当前句滚进视野
  （`_scrollToCur` 记录当前句 `GetLastRect().y`，不再无脑滚到最底——否则含后续后会停在末章）。浏览打开时冻结推进。
- **自动对话（本轮）**：按 **A** 或点「自动」开关；打字机播完后按阅读延时（`1.0 + 字数*0.02` 秒）自动推进下一句。
- **剧情跳过（本轮）**：按 **S** 或点「跳过」开关；整句直出并每 0.06 秒连推，快速略过剧情；与自动互斥。
- **控制条**：右上「回顾 L ／ 自动 A ／ 跳过 S」三按钮（开启态青底青边）。手动推进改为**只点对话框本体**或空格/回车/↓，
  避免点控制按钮/回顾面板时误推进（`ClickInBox`）。
- **样式分流**：台词/旁白/内心进对话框；演出居中斜体；结束卡居中 46 号大字。
- **打字机**：48 字/秒；第一次点击补全整句，第二次推进下一句。`-shot` 时直接整句（截图用）。
- **控制**：点击 / 空格 / 回车 / ↓ 推进；**Esc** 退出回世界（toast「剧情已暂停（B 继续）」）。
- **锁定**：对话期间 `DialogueManager.Active` 为真，`PlayerRig.Update` 顶部 return（锁移动与相机），光标解锁可见。
  **例外：C 键**——`PlayerRig` 把 C 的处理放在对话锁**之前**，故剧情播放中也能按 C 换人（见第四节）。
- **章间衔接**：一句章末自动进下一章；第 8 章末 toast「第一卷播放完毕」并退出。
- **叠层清理**：对话/自选菜单打开时 `Hud.OnGUI` 与 `Minimap.OnGUI` 直接 return，
  不再把左上标题/操作提示与右上小地图压在剧情场景标签上。立绘改为压框（见上），不再做「底边收口」。

## 四、C 键人物自选菜单

- C 键不再盲循环，改为弹出**六人卡片菜单**（3×2 网格）：立绘缩略图＋名字＋简介＋序号徽标。
- **点选**卡片或按 **1–6**（主键盘/小键盘均可）切换玩家模型；当前角色青色描边＋「当前」角标；悬停高亮；开关淡入。
- **C / Esc** 关闭。切换只改玩家模型（`PlayerAvatar.SetCharacter`），剧情立绘仍按说话人独立显示，互不干扰。
- **对话中也可开（104 轮修复「c 键无法选人」）**：C 的处理移到 `PlayerRig` 对话锁之前，`CharacterPicker.Open` 去掉
  `DialogueManager.Active` 守卫（仅保留开场 `IntroScreen.Live` 拦截）。菜单打开时 `DialogueManager.Update`/`OnGUI`
  顶部 `if (CharacterPicker.IsOpen) return` 冻结推进并让位（不再压住卡片）。C 的开/关统一由 `PlayerRig.Toggle()` 负责，
  `CharacterPicker` 自身不再响应 C，避免同帧双切换。
- 六人顺序与旧循环一致：樊楼→镜荧→景楠→莉莉雅→瑶清寒→紫薇（`PlayerAvatar.Roster` 共用）。
- `-cycle` 验收钩子仍走盲循环（`Cycle` 复用 `SetCharacter`）。

## 七、已知限制 / 下一步

- **抠图残留**：透明 PNG 已落地（白底卡移除）。flood-fill 只去「与边相连」的近白背景，内部白（白发/白衬衫/蕾丝）保留；
  镜荧裙侧仍有一小块被发丝围住的封闭白点（不连通边界故未去），属可接受残留；换立绘后重跑 `tools/matte-portraits.py` 并逐张目视。
- **选项分支**：剧本目前没有选项行语法，本轮为线性播放；数据结构与 UI 已留 `LineType` 扩展位，
  待作者定选项语法（且须守口径「不新增设定/原句不动」）再接分支。
- **音频**：【BGM】【音效】目前只显示文字提示，无音频资产；后续接 AudioSource。
- **场景演出**：【场景】只更新文字标签，未驱动 3D 世界换景；剧情暂在世界之上压暗播放。
- 樊楼/景楠立绘仍是待定旧稿（ImageGen 额度恢复后重画，见本轮对话记录）。
