# 16 · 雨雪天气系统（2026-10-18）

作者要求：**加入雨雪天气变化，要写实**。

## 交互

- **Y 键**：晴 → 雨 → 雪 → 晴 循环（HUD 右上显示当前天气，切换有 toast）
- 命令行 `-weather rain|snow|clear`（截图验收：直接满强度、跳过渐变）
- 过渡：雨 1.6s / 雪 2.4s 平滑混入（不是硬切）

## 雨（写实线索）

| 项 | 做法 |
| --- | --- |
| 雨丝 | 粒子 Stretched Billboard，程序化「雨丝」贴图（柔边、两端渐隐），4200/s、上限 4000、寿命 1.1s、落速 16m/s + 风偏 1.6m/s |
| 发射范围 | 跟随玩家的 34×34m 盒，**世界空间**模拟 → 已落下的雨丝留在世界中，不会跟着人平移 |
| **地面变湿** | 路面/铺装/球场/石带/矮墙/草地材质统一：颜色 ×(0.60,0.64,0.70) 变暗 + 光滑度 → 0.58 → 路面出现湿反光 |
| 天光 | 直射 ×0.55、阴影强度 ×0.45、日色偏灰蓝、环境光 +6% |
| 雾 | 近 ×0.55 / 远 ×0.50，颜色转灰 `#525a66` |
| 天空 | 穹顶亮度 ×0.68 |

## 雪（写实线索）

| 项 | 做法 |
| --- | --- |
| 雪花 | 粒子 Billboard + 柔边圆点贴图，1600/s、上限 4200、寿命 9s、落速 1.15m/s，噪波漂移 + 自旋；尺寸 14~34cm（5cm 的真实雪片在 13m 外不到 1px，放大到可读） |
| **积雪层** | 全场 200×200m 半透明雪层（程序化「积雪」贴图，世界尺度 1.667m 一铺），Alpha 随雪量 0→0.90 淡入；压在地面/跑道/花坛之上（y=0.028），玩家影子仍在其上 |
| 树冠/绿篱 | 材质向冷白 lerp 55% → 覆雪感 |
| 天光 | 直射 ×0.38、阴影强度 ×0.15、环境光 **+32%**（雪面反光）|
| 雾 | 发白 `#ccd4e0`，更近 |
| 粒子亮度 | 随昼夜变暗（夜里雪花/雨丝不发光）|

## 顺带修的

- **灯罩玻璃 / 门灯** 原来是 Unlit（不受光照）→ 阴雨天画面变暗时它们像"自己发光"；改成受光材质
  （灯罩 0.35 光滑度），夜里仍由 TimeOfDay 改暖色 + 泛光。

- 进库图：`docs/img/weather-rain.png`、`weather-snow.png`（左=晴｜右=雨/雪，同机位）、`weather-rain-night.png`
- 需要作者实机确认：**Y 键**切雨/雪，站雨里看路面变湿反光、雪里看地面变白、雪花飘落

## 已知局限（下一轮可做）

- 雪只覆盖地面（雪层 + 树冠调色），**屋顶/墙顶没有积雪几何** —— 要做得更足需要给屋顶加"雪盖"几何或按法线方向的雪层
- 雨没有水洼/涟漪；湿反射靠材质光滑度 + 天光，工程里没有实时反射探针（无天空盒反射源），所以看不到建筑倒影
- 天气是手动切换，还没有按天数的随机/日程天气（可以接进玩法迭代 2 的日程系统）
