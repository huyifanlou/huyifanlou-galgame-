# 138 · 灌木花瓣、公园重建与天气路灯细化

2026-11-16。继续上一轮树木精修，按作者要求集中地图内：解决灌木花团整块外壳、雨雪与光影脱节、公园低精度和灯椅辨向问题。边界外不追加新布景。

## 植被与公园

- `GardenDetail` 生成细枝、独立折面叶片、五片有弯折的花瓣与花蕊。普通灌木、杜鹃、樱花林下、野花、学校花池、墙边花箱和普通花坛全部接入；删除活动的球冠/方块花托和贴地花贴片。原树位、灌木点位与主干碰撞保持。
- 全图长椅统一为圆管架、分条座面、后倾靠背、扶手、脚座和螺栓；局部 +Z 为坐者面朝方向，沿用现有数据。区域专用旧椅路径一起替换，避免只改普通模板。
- 公园喷泉改 96 段旋转剖面的有厚度空心水盘、收细立柱、金属点缀与五瓣冠饰；落水改细曲线水束和小尺度水滴，原巨大方块花瓣与白色落水柱退役。保留地标位置与原碰撞占地。
- 池岸改 128 块倒角石沿；木观景台改独立木板、管扶手和底架；石灯笼改收细柱、透空灯室、角柱与坡顶，使用共享昼夜灯材质。芦苇分细茎、叶片和穗，假山改倒角转角石组，移除假山绿色方块点缀。
- 池塘、喷泉和水盆接入现有 `Campus/Water`，替换旧亮蓝白条贴图。增加连续变化的细波法线、天空掠射色、雨天扰动及局部灯光附加反光；不宣称实现屏幕空间或镜面场景反射。既有凉亭结构和公园路线保留。

## 路灯与建筑

103 盏道路灯改轴对称灯头和收细圆杆，取消必须分辨灯臂方向的外观。透光板与实际光源同轴，灯源在灯罩下方、朝正下方的宽角聚光灯；删除贴地加色光斑。夜间只启用相机 30m 内光源，最近两盏聚光灯使用柔影，其他灯源不投影以控制开销；室内关闭室外灯源。石灯笼也具有对应实际光源，白天不再无条件自发光。

学校、住宅、老街等共用精细立面增加窗台托块、金属滴水边、雨管固定箍与出水弯头；坡屋顶补檐底椽头，砖墙建筑补转角石块。细节落在既有建筑外轮廓及碰撞垫范围内，入口映射和门廊位置不改。沿用已分段开洞的墙壳，不恢复旧整面墙/夜窗覆盖。

## 天气与光影

- 雨雪粒子换为柔边雨丝/六臂雪花纹理，缩小原粗雨条和大方片雪；雨丝加入世界碰撞，屋顶可截断下落。进入室内立即清除存量雨雪，停止发射，离开后继续当前天气。
- `RainSurfaceDetail` 在玩家附近投射取实际表面高度，生成短时扩散雨圈，限制每帧发射量和存量。
- 湿润保留材质原色，改为上表面暗化与粗糙度变化；雨停后逐渐干燥。积雪按实际表面朝向渐积/渐融，叶片、屋面和台阶自然覆白，删除旧独立贴地积雪网格。室内通过现有灯光状态屏蔽外部表面天气响应。
- 天空覆盖云量、晨昏暖色、太阳强度、环境光、阴影和雾联动；夜雨雾色按夜间亮度压低，雨雪时隐藏星月，避免阴天仍有明显晴夜星点。
- 这是受控程序化天气与表面表现，未实现实体积雪厚度、全场水洼积水或体积云。
