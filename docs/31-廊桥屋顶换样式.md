# 31 · 廊桥屋顶换样式

作者反馈：桥的房檐不美观，换一个样式。

原样式的问题：
- 屋顶坡度过陡、檐口高（2.95m），从远处看像一块悬空的黑板；
- 两端山墙没有封板，入口上方是敞开的，露出黑色屋顶底面。

新样式：
- **低缓人字坡**（0.30 rad），檐口降到 2.70m，屋脊约 3.9m，出檐收窄（每侧约 0.6m）；
- 屋面换成**暖棕色瓦纹**（RoofTex #6a4a3c），不再是近黑色；
- 两端加**山墙封板**、沿斜边的**博风板**，入口上方封闭；
- 檐口木梁 + 椽头 + 柱顶横梁，屋顶与木构连接清晰；
- 保留木色顶棚（从桥下看不是黑色底面）。
