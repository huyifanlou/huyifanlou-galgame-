# 28 · 坡屋顶重做与树木硬排除

作者反馈：神社前仍有树；所有三角屋顶的侧面镂空、与建筑衔接不正常；河面有浮空树。

## 一、坡屋顶（通用 + 神社）
根因：两片屋面绕 X 轴的旋转符号写反，屋脊处变成“凹谷”；山墙三角片又只贴在墙顶、比屋面小，屋檐与墙体之间留有缝，所以侧面看是镂空的。

重写后的做法（通用 gable 与神社深檐共用同一套算法）：
- **檐口低、屋脊高**：屋面中心放在 (檐口+屋脊)/2，南坡绕 X 正角、北坡负角；两坡在屋脊严丝合缝。
- **山墙端封**：三角片从墙顶一直封到屋脊，底宽 = 进深 + 两侧出檐，不再悬空。
- **博风板**：两端沿斜边加板，收住屋檐外缘。
- **檐口封板 + soffit**：前后各一条水平板，封住屋面与墙顶之间的空隙。
- 出檐从 1.5m 收到 1.2m（神社）/0.7m（普通坡顶），比例更接近实际建筑。

实拍（神社）：[town-shrine-roof.png](img/town-shrine-roof.png)

## 二、树木硬排除
之前数据层过滤仍可能漏掉边界林带等批次。现在加双保险：
- `TownBuilder.Tree()` 渲染入口硬排除：神社前庭/参道口（x 79±13、z -57±16）与河面（距河道中心线 <10m）**任何来源的树都不渲染**。
- 边界林带生成后过滤掉河道 12m 内与神社前庭的树。
- 实拍河面（无浮空树）：[town-river-no-float.png](img/town-river-no-float.png)
