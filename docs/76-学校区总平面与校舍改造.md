# 76 · 学校区总平面重排与校舍改造

本轮任务：把学校区按真实大学校园重排、扩大边界；每栋校舍做出可辨认的样式；补齐广场、生活区、运动区与夜间照明，并逐项截图验收。

## 一、规划依据（联网）

- 大学校园常见结构：**主校门—图书馆/行政楼主轴**，教学组团与实验组团分列两侧，围合中央方院；生活区（宿舍/食堂）独立成组团，运动区靠近生活区但与教学区隔路；礼堂/活动中心作公共节点。
- 建筑语汇按功能区分：学院派红砖 + 石材门楼 + 钟山墙；图书馆新古典柱廊 + 采光钟亭；实验楼现代玻璃体量 + 横向遮阳；宿舍外挑阳台 + 空调机；礼堂柱廊 + 山花校徽。
- 校园道路分级：主轴 5m 步行道，次轴 3–4m；生活区 3m 支路；校门内留缓冲广场。

## 二、总平面（TownData.cs）

### 1. 边界与校门

- 校区由原来的小院扩至 **x −98…−49.4 / z −98…−25.6**（约 48.6m × 72.4m）。
- 围墙为 0.6m 矮墙沿边界一圈；**东墙留两个口**：
  - 正门 z −65…−55（门卫室 `s_gate` 在门内侧）；
  - 东侧门 z −44…−34，接操场/礼堂。
- 西北角随世界圆形边界做阶梯收分（x/z 各 3 段），避免矩形墙角伸出可行走区。

### 3. 道路与广场

- 主轴：校门 → 图书馆柱廊，5m，z=−60；
- 横轴：教学楼 ↔ 实验楼，4m，x=−70；
- 北环路 3m（z=−82.2）、东侧路 3m（x=−54）、生活道 3m（z=−38）；
- 宿舍、食堂门前各加 2.5m 支路，解决食堂正面压住宿舍门的问题；
- 校门内广场 7.6×12、礼堂前庭 8×14、活动中心前庭及篮球场入口支路；
- 篮球场入口改到 x=−61，与场地中心对齐。

### 4. 场地与配套

- 操场 24×12（跑道）在中央街东侧 (−28,−37)，看台 24×5 在操场北侧 (−28,−29)；
- 篮球场 14×8 在生活区东侧 (−61,−32)，两个篮架分列东西端；
- 方院 (−70,−60) 草坪+步道留空；日晷放在方院西南 (−77,−65)；
- 校门内：旗杆 (−56,−55.8)、公告板、两组 3×1.2 绿植花坛；
- 校区共 12 张长椅、3 个垃圾桶、5 组自行车架、2 块公告板、6 个花坛、18 盏路灯；
- 夜间：校舍标牌按样式抬到门楼/柱廊上方，亮窗按 `cols/rows` 生成。

### 5. 碰撞与植被留空

- 建筑 blocker 改用旋转后的 `HalfWX/HalfWZ`；
- 新增道具 blocker：长椅、垃圾桶、公告板、花坛、篮球架、日晷、校门门柱、自行车架；
- KeepOut 增加四段围墙、方院、校门广场、礼堂前庭、活动中心前庭；
- 行道树/边界林避让新校区范围与场地。

### 6. 小地图（Minimap.cs）

- 建筑按旋转后占地绘制，操场/篮球场叠加绘制；
- 传送点改到建筑正面（`FrontOffset`），新增「活动中心」。

## 四、精修记录（本轮发现并修掉的问题）

1. 图书馆柱廊台阶压住花坛/长椅 → 移走花坛；长椅移到 (−82.5,−67)，路灯移到 (−78.5,−56.5)。
2. 食堂正面挡住宿舍门 → 食堂南移到 z=−30.8，宿舍/食堂门前各加支路，宿舍门净空恢复。
3. 篮球场贴食堂 → 移到 (−61,−32)，入口路重排，篮架分列两端。
4. 校门花坛像粉色花床 → 新增 `kind:"green"`（绿篱色），校门/方院/活动中心花坛统一绿植。
5. 校门内侧看不到校名 → 增加朝内的 `sign_gate` 面。
6. 建筑旋转后碰撞/小地图/树排除仍按未旋转尺寸 → 统一 `HalfWX/HalfWZ`。
7. 图书馆钟亭在街面看不见 → 加大钟亭并抬到屋脊上方，校门轴线可读到钟面。
8. 宿舍阳台被食堂遮挡 → 从生活道正面补机位验证，阳台/空调可见。
