```bash
# 编辑器（路径按实际安装版本调整）
EDITOR="D:/AI/Unity/Editor/2022.3.62f3c1/Editor/Unity.exe"

# 1) 初始化：贴图导入设置 + 生成 Main 场景（只跑一次）
"$EDITOR" -batchmode -quit -projectPath "D:/AI/GLM/.zcode/workspace/Unity开发galgame/Game" -executeMethod Bootstrap.SetupProjectBatch

# 2) 构建 Windows 播放器（截图与演示用）
"$EDITOR" -batchmode -quit -projectPath ".../Game" -executeMethod Bootstrap.BuildWindowsBatch

# 3) 截图验收（与 web 版 URL 参数一一对应）
"Game/Build/Win/Campus.exe" -time 18.5 -px 0 -pz 4 -shot "shots/night_spawn.png"
"Game/Build/Win/Campus.exe" -time 12 -px 0 -pz 4 -at -21,7.5 -shot "shots/day_playground.png"

# 4) WebGL 构建（部署）
"$EDITOR" -batchmode -quit -projectPath ".../Game" -executeMethod Bootstrap.BuildWebGLBatch
```

## 参数对照（web 版 → Unity 版）

| web（URL 查询参数） | Unity（命令行） |
| --- | --- |
| `?time=18.5` 定表并暂停 | `-time 18.5` |
| `?px=&pz=` 出生点 | `-px 0 -pz 4` |
| `?at=x,z` 视角对准 | `-at -21,7.5` |
| `?yaw= &pitch= &dist=` | `-yaw -pitch -dist` |
| `?freeze=1` 冻结朝向 | `-freeze 1` |
| （无对应） | `-sim d,40` 前 40 帧模拟按住 D（移动方向/动画自动验证） |
| 无头 Edge 截图 | `-shot out.png [-frames N]` |
