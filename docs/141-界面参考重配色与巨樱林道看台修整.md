# 141 · 界面参考重配色与巨樱、林道、看台修整

2026-11-16。作者要求重设计设置/任务 UI，清理操场悬空栏杆，扩大巨樱与周围树木密度，重构小路及大小路接口。中途指出首版色彩搭配有问题，明确要求找参考，最终界面以下述参考重配色为准。

## 参考与最终界面

实际检索了《原神》设置/任务和《崩坏：星穹铁道》任务画面：

- [原神设置画面，HoYoLAB](https://www.hoyolab.com/article/25311816)
- [原神任务画面，HoYoLAB](https://www.hoyolab.com/article/24637260)
- [星穹铁道界面截图集，Interface In Game](https://interfaceingame.com/games/honkai-star-rail)

采用中性底色承担大面积、选中状态统一、强调色集中于行动与进度的方式；没有复制图标、贴图或整张界面。首版大面积粉紫/青绿拼色已撤掉。最终为暖灰内容底、象牙页眉、石墨文字、灰蓝选中条，少量金色强调；主线与支线只在标记与详情纸面有轻微暖冷差。

`GameUI.Folio/Tab` 统一页眉、边线和导航，`LightSheet` 仅包围设置与任务手记的绘制范围，在结束时还原；对白和人物页保持原字体与主题。设置新增浅色按键行、按键帽及画面设置分组，天气抽屉同步主题，Y 调雨雪功能保留。任务手记保留主线/支线、追踪、前往与回看，HUD 主支线卡分开，统一深灰半透明底，金/灰蓝小标记区分，修正支线卡高度与鼠标遮挡范围。

最终界面图片为 `reference-main/side/weather.png` 和 `approved-settings.png`；最初的 settings/quests/sidequests 图片是作者否定后的旧配色过程图，不能当作本轮最终稿。

## 看台与树群

操场看台旧后栏杆横杆处于台阶以外且无支撑。删除原横杆坐标，在第五阶后缘重建横杆和九根立柱，柱脚按该阶实际顶面 1.82m 接地；跑道数据保持。

巨樱使用独立 Landmark 构建，四根主枝再分侧枝、细枝，三层共 445 组花簇，加垂落花缘和枝端簇，冠幅约26×24m、高约14m。取作者所指《初音岛》标志性巨樱的宽阔尺度方向，并非声称逐帧复刻动画模型；未把树冠恢复为整块球壳。第一轮枝条放射过于整齐，已重排为四组分叉并以侧枝花簇遮断直线。普通近景树增加主/侧枝和末端叶簇，樱花周围树群同步加密；远林低细节路径不追加精修。

树位和近地碰撞保持，曲线路面触发的植被避让会清理冲突点，近景树由65变64（含巨樱）。近景枝叶总约653万三角形，不是单树数量；仍按每棵/材质合批。

## 林道与大小路

`GardenPaths.Rebuild` 在 TownData 初始化时替换旧樱花林五段折线和校区到公园的直步道：Catmull-Rom 曲线采样、宽度由入口向林内渐收。主街改偏冷石色，小路保持暖石/细卵石色。大小路接口新增渐宽铺装，统一送入原 PavingUnion 求并集，不用叠一张装饰平面遮旧路。

所有新步道、接口写入 W.PROPS，植被避让、路灯规划和草地接壤遮罩读取同一份数据。后续俯视检查发现短段拐弯处有锯齿缺口，增加采样段的纵向搭接，重新求并集修复。保留主街路网和既有入户通道，不宣称全城每条道路都改为曲线；主要重建樱花林与校区通园步道。
