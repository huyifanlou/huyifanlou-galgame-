# 15 · 照明预设第二版：压曝光、收高光（2026-10-18）

作者反馈：**这版光影太亮、晃眼，写实感不够**。

## 诊断

上一版（docs/11）为了"写实"把白天直射提到 1.00、环境 0.20，同时泛光阈值还是 0.72、泛光强度 0.28 ——
结果是面积最大的浅色面（铺装/墙面/天空）被推到接近纯白，再叠上泛光：**实测 2.5% 的画面像素 > 217（近白）**，
整体均值 113/255，属于"过曝的白天"。

## 新预设

| 项 | 上一版 | 本版 |
| --- | --- | --- |
| 白天直射强度 / 颜色 | 1.00 / #fff4da | **0.72 / #ffeecd**（略暖） |
| 白天环境光 | 0.20 | **0.155** |
| 天空补光 | 0.14 | **0.11**（冷色阴影保留） |
| 白天雾 | #cfe3f4，62~158m | **#bccad8，52~142m**（空气透视更明显 → 层次） |
| 天空穹顶亮度 | ×0.50 | **×0.42** |
| 泛光强度（昼/夜） | 0.28 / 0.60 | **0.14 / 0.55** |
| 泛光阈值（昼/夜） | 0.72 / 0.72 | **0.86 / 0.72**（白天只让灯/窗发光，路面不再"发白"） |
| 暗角（昼/夜） | 0.56 / 0.68 | **0.60 / 0.70** |
| 色彩分级 | 饱和 1.07 / 对比 1.00 | **饱和 1.04 / 对比 1.06**（去糖、补层次） |
| 夜晚直射 / 环境 | 0.58 / 0.34 | **0.52 / 0.28**（同步压暗，靠路灯/窗户发光撑可读性） |

## 实测对比（同一机位 12:00）

| 指标 | 上一版 | 本版 |
| --- | --- | --- |
| 画面平均亮度（0-255） | 113.1 | **78.7**（−30%） |
| 近白像素占比（>217） | 2.5% | **0.1%** |
| 纯白像素占比（>240） | 0.7% | **0.0%** |

夜晚均值 40.1/255，路灯与窗户的泛光、地面光池仍然清楚（没有回到"夜景过暗"）。

## 说明

- 这一版是"略阴/偏傍晚"的写实取向：亮度压低、高光收敛、雾更重。如果作者想要更暖的夕阳感或更清透的晴天，
  改 4 个常量（DAY_DIR_I / DAY_AMB / DAY_DIR / DAY_FOG）即可，不用动结构。
