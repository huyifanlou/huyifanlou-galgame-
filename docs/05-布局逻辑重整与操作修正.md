# 05 · 布局逻辑重整与操作修正（2026-10-16）

作者反馈：「鼠标转视角方向反了，需要改改，场景布局不太符合现实逻辑需要更改」。

## 一、鼠标转视角方向修正

**根因（两轴都反）**：Unity 与 three.js 有两处系统性差异——

1. 左手系下「相机方位角 → 屏幕左右」映射与 three.js 相反（同移动横移那次同源）；
2. Unity 的鼠标 Y 轴**向上为正**，web 的 `clientY` 向下为正。

**修复**：`_yaw += d.x * 0.005`（向右拖 = 视角右转）、`_pitch -= d.y * 0.004`（向下拖 = 相机升高俯视），
与 web 版手感一致（PlayerRig.cs 内有注释说明）。

## 二、布局逻辑重整（v3 分区）

### 原布局的不合逻辑处（自查清单）

| # | 问题 | 说明 |
| --- | --- | --- |
| 1 | 值班室孤悬北区路边 | 保安值班室旁边没有门——它应该在校门口 |
| 2 | 东西两个同款「正」校门 | 都挂校名牌、都是一样形制；一所学校通常只有一个正门 |
| 3 | 体育设施两处分离 | 体育馆在北区，篮球场/网球场在南区，隔了整个校区 |
| 4 | 二号宿舍在最北端 | 与一号宿舍（宿舍区）之间隔着图书馆，宿舍应成片 |
| 5 | 实验楼在西侧边缘 | 实验楼属教学区，应靠近教学楼/图书馆核心 |
| 6 | 家属区与校区无过渡 | 主角家在主路南端，和教学区之间缺少分区标识 |

### 新分区（v3）

- **东 = 入口区**：正校门（华清大学匾）+ 值班室（55,7）+ 活动中心 + 艺术楼
- **中 = 教学区**：教学楼（-16,-12）/ 图书馆（0,-22）/ **实验楼（-24,-23，自西缘迁入）** / **二号宿舍（16,-24，与一号宿舍同片）**
- **西 = 生活后勤**：生活服务楼（-46,9）
- **北 = 体育区**：体育馆（-20,-42）+ **篮球场（-2,-44）** + **网球场（-40,-42）** 三块相邻
- **南 = 家属区**：主角家（0,34）+ 小卖部 + 花园；主路上新增**「家属区」拱门（0,22）**作为校区/家属区的分界

配套改动：西侧校门改为**侧门**（无匾、双柱+红白挡杆）；二号宿舍/实验楼/值班室转向各自门前的道路并补三条岔路（可达性）；
原南侧球场位置改用补植树成林；路灯/行道树随分区微调。
