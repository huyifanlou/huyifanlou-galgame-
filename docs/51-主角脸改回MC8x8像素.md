# 51 · 主角脸改回《我的世界》8×8 经典像素

作者（2026-10-27）：

> 不需要这么写实的，按照我的世界的那种头部和脸部建模做就行

## 一、改了什么

docs/50 的 64×64 男版脸（写实眉毛/鼻影/唇形/下颌/亮眼高光）被判定太写实；
本轮把脸收回到**经典 MC 8×8 脸**，头部仍是 8×8×8 方块头，
脸贴图 8×8 直接 1:1 贴到头正面，每个 texel = 1 个 MC 像素。

- 脸贴图：`64×64 → 8×8`；
- 删除：写实眉毛、鼻梁/鼻头阴影、唇形/下唇、下颌阴影、腮红、亮眼高光、
  外眼角/睫毛、64×64 的皮肤渐变；
- 脸材质自发光：`0.32 → 0.15`，只保证背光可读，不再做“人像打光”；
- 删除额前 3D 发片/发丝高光条，只保留头顶发盖、短后发 + 后颈、两侧短发、鬓角；
- 男主人设与服装不变：短金发、蓝眼、藏青西装校服 + 白衬衫红领带 +
  深蓝长裤 + 黑鞋。

## 二、8×8 脸怎么画

`PlayerAvatar.FaceTexture()`（8×8，Point/Clamp）：

| 部位 | 像素布局 |
|---|---|
| 短金发 | 顶部 2 行；右侧留 2px 额头做斜分，两侧鬓角各 1px |
| 眉 | 左右各 2px 直线眉，深金棕 |
| 眼 | 左右各 2×2：外侧眼白、内侧深蓝/浅蓝虹膜（参考皮的画法） |
| 鼻 | 中央 1px 淡肤色阴影 |
| 嘴 | 中央 2px 宽、1px 高，低饱和唇色 |

脸贴片仍用 `BoxUV(size, size.x, size.y)` 做 1:1 UV，中心 z=4.03px、厚 0.10px；
Point 过滤，近看是清晰的方块像素，不是写实贴图。

## 五、教训

- 作者说“我的世界那种”时，就用 **8×8 经典皮肤脸**；64×64 会被读成“写实/HD 皮肤”；
- MC 脸的辨识度靠“大像素块”而不是细节：2×2 眼、2px 眉、2px 嘴已经足够；
- 保持男主锚点：短金发、蓝眼、藏青西装校服、白衬衫红领带、深蓝长裤、黑鞋；
- 参考皮肤只借“发色/瞳色/眼型的像素排布”，不借分辨率，更不借角色身份；
- 近景看脸仍用 `-facing 0 -freeze 1 -dist 2.4`，先 `-dumpface` 导出 8×8 PNG 再改。
