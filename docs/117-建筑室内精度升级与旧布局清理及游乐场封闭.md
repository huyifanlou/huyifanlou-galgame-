# 117 · 建筑、室内精度升级与旧布局清理，游乐场暂时封闭

2026-11-14。作者要求提高全城建筑、室内出口门、家具与墙地面的精度，按区域检查旧布局残留，游乐场暂不制作并封闭。本轮完成一遍共用模型与材质升级、分区实机检查；这是向精品模型质量推进的基础轮，尚不是逐件独立制作的 AAA 成品资产。

## 区域与建模

| 区域 | 本轮处理 |
| --- | --- |
| 学校 9 栋 | 实体分段墙壳、凹入窗洞、窗框窗台、门扇五金、檐口、屋面、门廊、落水管；保留图书馆/礼堂台阶与柱位 |
| 居民区 19 栋及主角家 | 共用精细立面、窗洞、双门五金、门廊；多层住宅加实体阳台栏杆，保留家门前院及入户路 |
| 老街 6 栋 | 退出旧贴图立面，接入实体门窗、店牌、屋檐、砖墙和屋顶设备 |
| 车站 2 栋 | 站房实体门窗；站台专用地台、支柱和顶棚，避免套普通建筑门窗 |
| 公园/神社 | 音乐亭和手水舍重建为开放柱梁、屋盖、座凳/水盆；神社木石瓦面接细材质，钟楼改石作细材质和实体门 |
| 游乐场 | 保留原设施供将来制作，外围封闭；本轮不细化内部 6 栋建筑 |

新增 `PrecisionMesh`：实际尺寸圆角盒、平滑法线与 24 边圆杆，网格按尺寸缓存。主要家具圆角采用 3 段，细部采用 2 段；结构墙与薄片仍使用简洁网格，避免无意义加面。室内桌椅重做木作接合、金属脚帽、靠背柱、连接螺钉；沙发改软包坐垫、靠垫与包边。柜、货架、床、灯、设备等共用部件通过 `Part/PartC` 提升圆角精度，保留原功能布局与通行尺度。

`DetailSurface` 缓存 512×512 程序化纹理和高度图，覆盖砖、瓷砖、拼木地板、连续木纹、织物、墙纸、抹灰、石材、金属和屋瓦。家具/门木纹与地板拼板独立，避免门面出现地板缝。`Campus/Toon` 新增可选世界坐标贴图、微表面高度法线、柔和高光；旧人物材质默认值不变。保留现有风格化渲染，本轮没有擅自重启整套写实渲染迁移。

13 间室内全部使用新墙地材质与出口门组件：家、教学楼、图书馆、餐厅、超市、食堂、宿舍、礼堂、实验楼、奶茶店、照相馆、书店、便利店。出口有木框、密封缝、门槛、上下嵌板、玻璃、踢脚金属板、门把、铰链、绿色出口牌和门灯；宽门洞中央双门、两侧固定玻璃。碰撞是一整条实际出口边界，F 仍负责场景切换，并未制作推门动画。

室内完成后按房间/材质合批并上传网格，删除旧逐零件 Renderer 和 MeshFilter，保留碰撞、文本、灯光；避免加细之后继续保留重复渲染实体。各房间顶高在构建该房间时立即记录，修复之前被最后一间房顶高覆盖的问题。

## 清理与连接修复

- 删除 WorldBuilder 的旧通用贴图立面、夜窗覆盖生成路径及 TimeOfDay 对应更新路径；`WindowFXRoot` 改为只承担实体标牌的 `SignRoot/Signage`。夜间在实际玻璃材质上改变发光，不再盖另一层窗。
- 学校南墙的旧墙纸原本横穿出口侧窗，踢脚线也跨过门洞；两者均按真实门洞切断。门后增加不漏光背板，修正双门反向时把手位置。
- 外门门头与墙洞高度对齐，消除门扇上方可见空缝。
- 门厅碰撞改中央 2.5 米宽；同时修正 PlayerRig 和 TownData 两处历史数据，移除整栋立面前方的空气墙。
- 开放亭舍同时移除整栋 BoxCollider、PlayerRig 建筑 AABB 和 TownData 旧整块 Blocker，改柱子、座凳、水盆对应阻挡。实际行走测试发现并清除了第三处遗留，不能只检查画面。
- 手水舍门外还遗留一份旧独立 `temizuya` 水盆，堵在新亭舍入口；删除其 TownData 布点，水盆统一放在亭舍内，避免重复实体和入口阻挡。
- 建筑 id、交互点名字、13 间入口映射均保留；未知室内不再显示错误的入内提示。

## 游乐场封闭

`ClosedAreas` 是围挡、碰撞、地图、传送与旧档迁移的共同边界：X=7.8…96、Z=27.5…52.5。外围金属围挡 1.86 米，附封条和“设施维护 · 暂停开放”牌，保留外围街道/河岸通行。地图对区域做维护标示，删除其目的地与交互点。步行不能穿越；自由地图和直接传送拒绝进入；原来存于封闭区的旧档迁到西侧安全点 (6.5,40)，保留其他进度。
