# 17 · 桌面快捷方式与应用图标（2026-10-18）

作者需求：**需要在桌面随时打开查看**。

## 做了什么

### 1. 游戏图标（用游戏自己的美术生成）

草地纹理铺底 + 主角站立帧（1.5× 最近邻放大）+ 脚下椭圆影子 + 30px 圆角透明边：

- 源图：`Game/Assets/icon.png`（256×256，进版本库）
- 多尺寸图标：`Game/Build/icon.ico`（16/32/48/64/128/256）
- `Bootstrap.SetAppIcon()`（菜单「Campus/1c. 设置应用图标」）把图标写进 PlayerSettings 的**8 个平台图标槽位**
  → 重新构建后 **exe / 窗口 / 任务栏** 都显示游戏图标

**踩坑**：`PlayerSettings.SetIconsForTargetGroup`（旧 API）在 2022 的 batchmode 下**完全不落盘**；
`PlayerSettings.SetIcons(NamedBuildTarget, [1 张], Application)` 只回读 8 个槽位里的 1 个、也不持久。
**必须把 8 个槽位都填上**（16~256 各一份，同一张图即可，Unity 会缩放），配 `AssetDatabase.SaveAssets()`，
`ProjectSettings.asset` 里才会真正出现 icon 的 GUID（本次已验证 8 处引用）。

### 2. 桌面快捷方式

`桌面\校园叙事 RPG.lnk` → `Game/Build/Win/Campus.exe`

- 工作目录 = 构建目录；图标 = `Game/Build/icon.ico`
- **指向构建产物本身**：以后每次我重新构建，双击拿到的就是最新版本，不需要重做快捷方式

## 用法

- 桌面双击「校园叙事 RPG」即可（已验证可从快捷方式启动）
- 游戏内：WASD 移动 / F 交互 / V 视角 / Q E 转视角 / 0-3 时间速度 / T 切昼夜 / [ ] ±1h / **Y 切天气**

## 复现（仓库搬家或快捷方式丢失时）

```powershell
$target = 'D:\AI\GLM\.zcode\workspace\Unity开发galgame\Game\Build\Win\Campus.exe'
$ico    = 'D:\AI\GLM\.zcode\workspace\Unity开发galgame\Game\Build\icon.ico'
$ws = New-Object -ComObject WScript.Shell
$sc = $ws.CreateShortcut("$env:USERPROFILE\Desktop\校园叙事 RPG.lnk")
$sc.TargetPath = $target
$sc.WorkingDirectory = (Split-Path $target)
$sc.IconLocation = "$ico,0"
$sc.Save()
```

## 验证

- `ProjectSettings.asset` 的 `m_BuildTargetPlatformIcons` 中 8 个槽位都指向 `icon.png` 的 GUID ✓
- 快捷方式回读：`TargetPath` / `WorkingDirectory` / `IconLocation` 均正确，目标文件存在 ✓
- 通过快捷方式启动 → 进程与窗口标题「校园叙事 RPG」正常 ✓
