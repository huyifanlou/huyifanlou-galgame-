## 四、室内系统的关键设计（改之前先懂这些）

1. **建在世界之外**：家 `x≈900`、教学楼 `x≈1060`，封闭盒子。进场只 `SetActive(true/false)`，
   不另开 Scene。地面只有 620×620，x=900 处什么都没有，所以房间必须六面封闭。
2. **碰撞是自写 AABB + 楼层掩码**：`Solid{X1,Z1,X2,Z2,Mask}`，bit0=一层 bit1=二层。
   `Interior.Collides()` 只测当前层。**不是物理引擎**，没有 CharacterController。
3. **地面高度是函数**：`FloorAt(x,z,curY)`，楼梯区按坡度插值，其余按当前层。
   ⚠ **楼梯两侧必须有挡墙**，否则从侧面走出去会瞬间跳层（穿进二楼楼板）。
4. **墙皮 `RoomSkin(rect, 材质, 门洞...)`**：给矩形房间四面内墙贴 4cm 薄片，不参与碰撞，
   所以改墙面不影响走位。门洞按 `(墙号, 起, 止)` 三元组，墙号 0=南 1=北 2=西 3=东。
   ⚠ **坐标系规则（踩过两次）**：
   - 墙号 0/1（沿 X 走）→ 门洞用**世界 X**（`ox - 1.0f` 这种）
   - 墙号 2/3（沿 Z 走）→ 门洞用**世界 Z**（就是房间 z 值，**不要加 ox**）
5. **相机**：室内 `dist 5.2 / pitch 0.26`；贴墙时（探测 <2.8m）自动把 pitch 抬 0.45 改俯视，
   否则窄走廊里满屏墙纸。相机距头部 <2m 时自动隐藏角色精灵。
6. **第一人称**：`V` 切换，锁鼠标 + `Input.GetAxis("Mouse X/Y")` 直接转视角，
   灵敏度 `FP_LOOK_SENS = 1.4`（度/轴单位）。`Mouse Y` 向上为**正**，所以是 `+ my`。
   `Esc` 手动解锁光标（点小地图时需要）。

```bash
# 3. 模拟行走，读坐标判断通不通（比截图可靠）

#   → Player.log 里 [Sim] f=150 pos=(899.40,0.04,1.19) moving=True
```

**穿模自动校验**：每次建完室内跑 `Validate()`，问题逐条 `Debug.LogWarning`。
正常输出：

```
[Interior:home]   校验完成：80 个碰撞盒，问题 0 处
[Interior:school] 校验完成：94 个碰撞盒，问题 0 处
```

抓的是：家具越出外墙内表面、家具插进同层墙体。**不抓**家具之间的重叠（正常）。
