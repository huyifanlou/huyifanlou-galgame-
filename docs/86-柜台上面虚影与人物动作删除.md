## 一、柜台背后闪面（docs/85 收尾）

docs/85 把台面板与柜顶的共面修掉了，但**柜台背后**仍有一条闪面缝：`BarCounter` 的内侧踏板后沿正好等于柜体背面（z=2.15），两种材质共面 → 从操作面看过去一条缝在闪。改成踏板内缩 2cm（z 2.18~2.48）。

按同一标准再扫了一遍新铺的柜台类构件，又找到一处同类共面：便利店冷柜带的玻璃门后沿正好压在柜体正面上（`z + 0.02` 且门厚 0.04 → 背面正好 = 柜面）→ 改成离柜面 1cm。

## 二、柜台上那个展示柜的虚影（作者附图）

作者截图指认的是**吧台上的展示柜**。它是 5 块板拼的：背板、两侧板、顶框、底框 —— 而这五块的边**正好都在同一批平面上**（z=2.26/2.94、x=±0.87 处板面齐平），板与框又是两种颜色（#cfd8e2 与 #8d949c），所以从后面/侧面看整条棱都在闪，就是图里顶面那道斜缝。

重做成"一个实心柜体 + 外凸的顶底框 + 前面两层深色橱窗格"：

- 柜体 1.8×0.5×0.68 一整块（不再有背板/侧板对缝）；
- 顶框、底框比柜体每边外凸 2cm；
- 前面两层橱窗格从柜面前凸 1.5cm，甜点摆在格前 1cm；
- 所有面两两至少错开 1cm，且整柜仍收在台面板范围内（台面 z 2.12~3.08）。

顺带把同类判据记下来：**同样材质共面看不出来（超市 `Cooler` 就是多块同色白板拼的，不用改）；不同材质共面才会闪**。本次奶茶店展示柜、冷柜门、内侧踏板三处都是"异色共面"。

## 三、人物动作（跳跃 / 蹲下）：实现过，作者否掉，已整体删除

按作者要求加了 **空格跳跃**（跳高约 0.5m、0.5 秒一次，上升收腿抬臂、下落前伸）与 **C 蹲下**（速度降到 48%、相机压低；蹲法是腿整体缩短 + 身体等量下降，脚不离地不插地），姿态复用既有骨骼，还配了 `-pose jump|crouch` 截图参数。

作者看过后判定「效果不好」，要求删除。按「删干净」约定整体移除，不留并行代码：

- `PlayerAvatar.Tick` 恢复原 4 参数签名与姿态计算；
- `PlayerRig` 删除 `JUMP_V/GRAV/_vy/_airH/_crouchBlend/_poseArg`、空中/蹲的输入与积分、速度系数、相机压低、`-pose` 参数；
- HUD 操作行去掉「空格 跳 ｜ C 蹲」；AGENTS.md 去掉 `-pose` 截图示例。

**为什么效果不好（下次做动作的教训）**：本项目的碰撞是 2D AABB（`Collides` 不看高度），跳跃既不能越障也不能钻洞，动作只是"表现层"——人物腾空时与地面、桌沿的关系没有玩法支撑，看着就像贴图在上下飘。真要做动作，得先给碰撞加高度层（或至少让跳跃能真的跳过/钻过某类低障碍），否则动作再多也只是动画演示。

保留下来的部分是有效的：**F10 帧率三档**（锁 60 / 垂直同步 / 不锁帧）与地图 OnGUI 样式缓存（docs/85），这两项针对的是作者提的"一卡一卡"，未删除。
