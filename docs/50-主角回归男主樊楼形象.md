## 一、先读人设，再动模型

从剧本 `D:\AI\galgame-美化版.docx` 核对出的主角信息：

- **樊楼**，男高中生，下个月才满 15 岁；一个人住，会点外卖、收留镜荧还收房租。
- 性格：冷静、适应力强、嘴上有点损但靠谱；原话「生活总是充满惊喜和意外……冷静面对」。
- 镜荧对他的第一印象：「长得真好看」「帅哥」，即外形是清秀好看的男生。
- 他的觉醒能力是**身体完全女体化**：变身后「金发变长了，胸前也有了起伏，小樊楼不见了」。
  也就是说，**金发长发、女性身体是觉醒形态**；默认形象仍是男生。
- 原 2D 精灵的男主配色（docs/47）：金发 `#eccb5a`、藏青校服 `#46567f`、
  白衬衫 `#f4f1e6`、红领带 `#b23a44`、深蓝裤 `#2e3550`、黑鞋 `#23262e`。
  这与「金发变长了」对得上：男主本来就是金发，变身后只是变长。

所以 docs/49 的金发长裙造型被判定为**觉醒后的女体形态**，不是默认主角；
作者给的 LittleSkin 参考只借「64×64 脸的五官精度/高光/发丝处理」，不照搬角色身份。
默认男主回到原精灵的短金发校服形象。

## 二、男主默认形象（本轮）

### 脸（重点）

`PlayerAvatar.FaceTexture()` 改为 64×64 **男版**：

- 短金发：左侧低、右侧高的斜刘海，四绺短碎发，鬓角只到耳下；
- 直线眉，外低内高，压近眼睛；
- 窄长眼型：14×8 眼白，8×6 深蓝虹膜，3×4 瞳孔，小高光；
  平直上眼睑，不做女版外眼角上挑、下睫毛和腮红；
- 鼻梁/鼻头阴影、12px 宽轻微上扬的嘴角、下颌与下巴阴影；
- 肤色沿用原精灵的暖肤色 `#f8dfb9`，脸贴图自发光 `(0.32,0.30,0.28)` 保证背光可读。

### 头发与身体

- 短金发：头顶发盖、短后发 + 短后颈、两侧短发、鬓角；**删除**长发、发尾、红发带。
- 标准 Steve 比例：头 8×8×8、身 8×12×4、臂/腿 4×12×4，1px=0.05625m，总高 1.8m。
- 校服：藏青西装 + 白衬衫 + 红领带 + 领带夹 + 腰带/银扣 + 校徽 + 西装扣 +
  深蓝长裤 + 黑鞋；**删除**裙片、白袜、棕靴、白手套、泡泡袖、皮束带。
- 走路 ±42° 摆腿、±36° 摆臂；短发动画不再有后发摆动。

## 六、教训

- **参考图 ≠ 角色身份**：参考只借画质和五官处理，人物形象必须回到剧本人设；
- 动主角前先读剧本：樊楼是男主，金发长裙是觉醒后的女体形态，默认男主是短金发校服；
- 男版脸不要照搬女版的元素：去掉外眼角上挑、下睫毛、腮红、亮唇和大瞳；
- 短金发/蓝眼/藏青西装/红领带/深蓝长裤是男主的识别锚点，换脸时保留；
- 64×64 脸贴图技术对男女版都适用，`-dumpface` + `-facing` 仍是脸部验收的最快路径。
