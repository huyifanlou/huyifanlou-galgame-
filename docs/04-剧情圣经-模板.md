# 剧情圣经 v0（模板，待用户填写 / 拍板）

> 双重作用：① 游戏的剧情骨架；② **LLM 动态事件导演的上下文约束**（角色卡 / 世界规则 / 禁区），
> 导演生成内容时必须以此为边界——这是「意图控制」策略在剧情层的体现。

## 1. 世界观

- 学校：名称 / 性质 / 氛围（示例：一所普通综合大学，"旧校舍"即将拆除）
- 奇幻规则：允许什么 / 禁止什么（**必须写死，防止 LLM 前后矛盾**）
- 悬疑主线：核心谜团一句话 / 真相一句话（玩家不会一开始知道）

## 2. 主角

- 姓名 / 性别 / 背景 / 初始属性（可支持玩家自定义名字）

## 3. 角色卡 ×3-4

每人必填：姓名 / 身份 / 性格 / 口头禅 / 秘密 / 好感度阈值事件（如"好感 ≥60 触发天台谈心"）

## 4. 三幕结构

- 第一幕（第 1-2 周）：日常建立 + 首个异常
- 第二幕（第 3-4 周）：谜团深化 + 关系升温 + 代价显现
- 第三幕（结局周）：真相 + 分支结局（角色线 × N + 真相线 + 平凡结局）

## 5. 场景清单（W1 建模用）

教室 / 宿舍 / 图书馆 / 食堂 / 社团活动室 / 操场 / 旧校舍 / 校园小径
（初版先做 4 个：教室 / 宿舍 / 图书馆 / 食堂；其余 W3 追加）

## 6. 三个概念种子（选一个或自创）

- **A《昨日重现》**：图书馆闭馆后，借阅记录里出现"明天"的日期；主角每天能"重演"前一日并改变一个小事实。
  悬疑 + 奇幻；天然适配 LLM 每日事件生成；双人感情线（帮你查记录的人 × 阻止你篡改的人）。
- **B《第七位成员》**：六人社团的合照里永远有第七个模糊身影，"它"只对新加入的主角说话。
  群像 + 社团日常恋爱；与日程经营的结合最紧（社团活动即主线）。
- **C《许愿池的债》**：旧校舍许愿池有求必应，代价是"记忆"；主角许过愿但忘了内容，只留下一条线索。
  奇幻 + 恋人线（TA 记得你忘了的事）。
