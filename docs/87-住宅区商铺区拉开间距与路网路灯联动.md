# 87 · 住宅区与商铺区拉开间距（扩边界 + 路网路灯联动）

作者要求：优化住宅区与商铺区，**允许扩大边界、把间距拉开**，联网参考建筑设计规范，**道路与路灯一起联动改**。

## 一、采用的规范数值（联网查证）

| 主题 | 数值 | 出处 |
| --- | --- | --- |
| 住宅正面日照间距 | 多层 1.1~1.5H（地方常用 1.5H），高层 ≥1.2H 且不小于 24m | 《城市居住区规划设计规范》GB50180 及各地技术规定 |
| 住宅侧面间距 | 条式多层之间 ≥6m；高层与多层之间 ≥13m | GB50180 |
| 住宅视线卫生 | 南北向住宅对视间距一般不宜低于 18m | GB50180-2018 条文说明 |
| 小区路 / 组团路 / 宅间路 | 路面分别 6~9m（建筑控制线间 ≥14m）、3~5m、≥2.5m | GB50180 8.0.2 |
| 路灯间距 | 6m 杆 15~18m、8m 杆 20~24m（居住区/人行）；主干路 30~50m；次干 25~40m；支路 15~25m；高:距 ≈1:3 | CJJ45-2015《城市道路照明设计标准》与实践数据 |
| 灯杆距路缘 | 主/快速路 0.75~1.0m；次干/支路 0.5~0.75m | 城市道路照明安装要求 |

本项目路灯模型杆高约 6m → 居住区取 **13~16m**（沿街商业人流密，取偏密值）、主街/中央街取 **20m**、西环路单侧 **14~16m**，灯杆统一推到**缘石外 0.8m**。

## 二、边界扩大与连带修正

`TownData.BOUND` 128 → **150**。原来住宅区南/西两个方向都被 128 的圆边界卡住（单元楼前排到 r≈124），没有拉开间距的余量。

连带修正（都是"边界写死"留下的坑）：

- **边界林带半径原来写死 116~122**，扩边界后会插进可行走区（校验规则要求边界植被 r ≥ BOUND−14）→ 改成 `BOUND − 12 + rnd*6` 跟着边界走，一次改对，不再随边界变动爆 80 条违规；
- 保留区里"铁路道床"的 z 写死 92（铁路实际在 z=104）→ 修正为 104，宽度按 236m 道床的半长 108 补齐。

## 四、商铺区：骑楼老街

- **老街商街**：路面 8m → **10m**（车行 6m + 两侧骑楼前各 2m），街道高宽比 D/H ≈ 10/8 ≈ 1.25，落在 1~1.5 的舒适区间；
- 北排（绸缎庄/茶楼）z=18.5 保持（再往北就顶到河道 8m 退让线），退界 2m；
- 南排（杂货铺/药铺）z=36 → **39.5**，退界 5m；戏院 z=38 → **39**（原来压到住宅北街退让），邮局 z=36 → **39.5**；
- 山墙缝：原来 2m 贴死 → **5~8m**（保留连排骑楼的街墙感，但每段之间留缝与采光）；
- 商街路灯：15m 双侧、灯臂朝街心，并避开中央街车行道与各铺面正门。

## 六、校验器小改进

`ValidateTown` 的「建筑×步道净距」「建筑×河道退让」两条原来只报建筑名字，同名建筑（4 栋单元楼、5 户两层小楼）根本定位不到。现在把建筑坐标与步道中心/长度/朝向、以及河道退让的允许区间一起打出来 —— 本轮就是靠它一次定位到"face=±2 的建筑 hw/hd 会互换"这个隐藏点。
