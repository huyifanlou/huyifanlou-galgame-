# 123 · 实景角色对话与开放世界主线指引首轮

2026-11-15。作者要求剧情期间看到对方的模型，任务追踪向热门二游和开放世界靠拢。本轮把实景角色镜头与探索指引接入现有剧情，不改原剧本内容，未提交或推送。

## 实景对话

新增 `ConversationStage`，在 PlayerRig 更新相机后接管对话镜头：六位角色现有模型中，为非玩家对话人物创建临时演出角色，站到玩家前方约 2.3m 的安全位置并面向玩家。室内检测当前房间边界及家具碰撞，室外走现有安全落点查询；视线有墙体遮挡的候选点放弃。

镜头在玩家眼部附近略偏侧，直视对方上身。对话时隐藏玩家自身模型，避免第一/第三人称的身体挡住镜头；实景模型存在时不画大立绘，降低世界压暗。旁白或玩家台词保持上一位对话人物的镜头；章节卡结束镜头占用。没有支持模型或没有可用站位时保留原有回退展示。

退出、暂停或分场返回探索时销毁临时角色，恢复探索相机参数。玩家世界位置没有被移动，临时演出位置不写入存档；读档期间释放演出镜头不覆盖新读入的视角。探索 NPC 原有提示继续保留，对话期间由临时演出角色显示，避免重复站两个人。

这仍是首轮演出：现有六角色模型可切换，没有给无名 NPC 虚构模型；未实现口型、表情、多人同时站位、完整动画分镜或过肩反打。

## 主线追踪

- 常驻任务卡加入行动动词与距离：前往地点、进入建筑、离开当前室内，靠近后变为“与角色交谈”或继续剧情。
- 探索画面加入主线地点的投影标记；目标在镜头后方时显示“目标在身后”。在错误房间中不画远在世界外坐标的假距离，引导先离开室内。
- 一段剧情结束后自动保存并返回探索，不再自动弹出整页任务手记；新目标通过常驻卡衔接。
- 原主线/支线分类、任务前往、地图传送与存读继续使用。当前世界空间标记针对主线，支线仍显示在独立追踪卡；本轮没有承诺已完成寻路路线、罗盘、多层导航或完整开放世界任务系统。
