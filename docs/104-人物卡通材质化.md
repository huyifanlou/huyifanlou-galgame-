## 二、做了什么

### 1. 脸部贴片去描边（**最关键的一处**）

**问题**：`Build()` 里脸是一块 `S(8f, 8f, 0.10f)` 的薄盒子（`FacePlate`），贴 `FaceTexture`。
反向外扩描边把**六个面**的顶点全沿法线在屏幕上推开，于是脸周围糊出一圈**黑色矩形框** ——
基线图 `shots/210-baseline-fanlou.png` / `210-baseline-jingying.png` 里脸四周那道黑边就是它。

**修法**：新增 `FaceMat()` 工厂，脸片材质强制 `_OutlineWidth = 0`、`_RimStrength = 0`。
脸的轮廓交给**头块自身的描边**去勾（头块是 8×8×8 的实心方块，描边干净），脸片只负责画五官。

> 这也是任务书里「脸部贴图材质不要描边（反向外扩描边会沿 UV 边界炸开）」那条的实装。

### 2. 描边分三档（解决「小配件被描边吃掉」）

方块人身上有大量 0.3~1px 的小件（纽扣、勋章、校徽、领带、宝石、鞋带、帽徽）。
统一用粗描边时，这些件本身在屏幕上只有几个像素，描边比它还宽 → 直接糊成黑点。

| 档位 | 宽度（NDC） | 1600px 宽下约 | 用在 |
|---|---|---|---|
| `OutlineBold` | 0.0060 | ≈4.8px | 身体、头、发盖/发冠、四肢、裙摆、鞋 —— 大块面，靠它立轮廓 |
| `OutlineMid` | 0.0040 | ≈3.2px | 领子、腰带、围裙边、肩章、腰带、深发收边 |
| `OutlineFine` | 0.0018 | ≈1.4px | 纽扣、勋章、校徽、领带、宝石、鞋带、薄发片 |

对应工厂：`ClothMat` / `ClothMid` / `ClothFine`，全部经由 `CharacterMat(c, shadow, outline, spec, rim)`。

### 3. 发壳分「厚壳 / 薄片」两套材质

**问题**：`sideShell` / `backShell` / `sideHead` 这几片发壳只有 **0.6~0.9px 厚**。
粗描边在脸两侧外扩 → 叠成一道**黑竖条**，黑发角色（景楠、瑶清寒）最明显。

**修法**：厚壳（`hairCap` / `hairCrown` / `hairBrim`）用 `_hair`（粗描边），
薄片（`sideShell*` / `backShell` / `sideHead*`）用新增的 `_hairThin`（细描边）。
`HairMat(tex, tint, outline)` 增加第三个参数，三处调用点各取所需。

### 4. 人物专属 `_ShadowTint`：更暖、更浅

世界默认暗面是冷紫 `(0.52, 0.55, 0.78)` —— 用在**皮肤**上会发青发紫，脸像尸斑。
人物单独设三套暗面色（`MatLib` 的全局值不动，只在人物材质上 `SetColor("_ShadowTint", ...)`）：

| 用途 | `_ShadowTint` | 理由 |
|---|---|---|
| 皮肤 `SkinShadow` | `(0.86, 0.72, 0.68)` 暖粉 | 皮肤暗面绝不能发青；暖粉暗面 = 卡通脸 |
| 衣服 `ClothShadow` | `(0.74, 0.68, 0.76)` 中性微暖 | 保留一点冷调做对比，但压不到脏 |
| 头发 `HairShadow` | `(0.72, 0.70, 0.80)` 偏冷浅 | 白发/金发/黑发的暗面都要保住「亮阶」，纯压黑会糊掉发丝纹理 |

### 5. 皮肤 / 脸片加少量自发光（**保亮阶**）

卡通渲染的暗面是一整块色阶，不像写实有连续过渡。人物一旦站在**帽檐阴影**或**背光**里，
整张脸会塌成一块灰、五官直接看不清（docs/99 记的「紫薇帽檐在正脸投阴影」就是这个）。

修法：`SkinMat()` 与 `FaceMat()` 开 `_EMISSION`，用主贴图调制（shader 里是 `albedo * _EmissionColor`），
所以只是**抬暗面**、不改色相：

- 皮肤本体 `SkinGlow = 0.085`
- 脸片 `0.13`（脸比身体更需要保亮）

### 6. 描边颜色改「深靛蓝」而非近黑

`MatLib.LitColorBold` 默认描边 `(0.09, 0.07, 0.13)` 接近纯黑，方块人相邻部件的分件线会糊成一片死黑
（尤其躯干 + 手臂 + 腿的接缝）。人物改用 `CharOutlineColor = (0.15, 0.12, 0.22)`：
带一点色相的深靛蓝既能勾轮廓，又和暖色皮肤形成「冷边暖面」的卡通对比。

### 7. 六人调色板提亮提纯

卡通渲染的亮面由 `albedo × 太阳` 直接给足，暗面由 `_ShadowTint` 统一压成色阶。
上一版写实口径的调色板整体偏灰偏暗，在卡通下会显得脏。逐人调整：

| 角色 | 人设辨识位（**保持不变**） | 主要调整 |
|---|---|---|
| 樊楼 | 金发、蓝瞳、水手校服 | 金发 `#e7bc55`→`#f0c74e` 提纯；校服藏青 `#46577f`→`#4a63a2` 提亮；红领巾 `#c84450`→`#e0455a` |
| 镜荧 | **白发**、**红眼**、黑礼服血族 | 白发提亮至 `#eef2f8`；红眼 `#a8323e`→`#d4303f` 提纯；礼服 `#1b2438`→`#2c3652`（纯黑在 3 阶 ramp 下糊成一坨，看不出结构） |
| 景楠 | **黑发**、棕瞳、立领夹克 | 黑发 `#23262e`→`#2b2f3a` 抬明度；夹克 `#2f3e46`→`#3a5560`；白鞋提纯至 `#eef0f2` |
| 莉莉雅 | **绿发**、蓝瞳、精灵尖耳、女仆 | 绿发 `#9fbf8f`→`#93d18c` 提饱和；女仆黑裙抬至 `#3a3e48`；红领结提纯 |
| 瑶清寒 | **黑长直**、紫瞳、校服 | 黑发同景楠抬明度；藏青背心 `#3a4a6a`→`#43588a`；紫瞳 `#7a5aa0`→`#9166c8` |
| 紫薇 | 灰白发、大檐帽、藏青军装 | 灰发提亮至 `#c9ced8`；军装 `#2a3450`→`#36466e`；金饰 `#c9a24a`→`#e8bb52` |

### 8. 紫薇胡茬改「暖褐低对比」

男性脸用 `Lerp(skin, hairD, 0.5f)` 画胡茬，卡通渲染下会压成一块脏灰。
改成 `Lerp(skin, #8a7058, 0.26f)`：只做「这个人有胡茬」的色块暗示，不抢五官。

### 9. 白发压一档留高光余量（镜荧）

**问题**：`shots/214-char-jingying.png` 里镜荧的头发过曝成**一片纯白**，发丝纹理完全丢失。

**根因**：卡通亮面是 `albedo × 太阳(1.15) × ramp + 环境光 + 边缘光`，是**直接相加**的。
白发上一版是 `#eef2f8`（≈0.93），乘 1.15 后已过 1.0，被截断成纯白；
再叠加环境光与边缘光，整片头发变成死白，`hairL` 与 `hairD` 三档层次全部被压平。

**修法**：三档整体压一档、同时**拉开对比**（对比度比绝对值更重要 —— 卡通渲染靠色阶区分层次）：

| 档位 | 改前 | 改后 |
|---|---|---|
| `hair` 主色 | `#eef2f8` | `#dde5f0` |
| `hairL` 亮部 | `#ffffff` | `#f4f8ff` |
| `hairD` 暗部 | `#c8d0dd` | `#aab5c8` |

> 这条经验对后续所有**高明度部件**都适用：白衬衫、白围裙、白手套同理。
> 之所以只改镜荧，是因为其余角色的白色件（樊楼白衬衫、莉莉雅白围裙）面积小、且有描边和相邻色块夹着，
> 过曝不明显；白发是**大面积连续**的，一旦过曝整颗头就没有结构了。

### 10. 肤色 albedo 压余量（**暖调丢失的真正根因**）

这是本轮最后一个、也是最隐蔽的问题，单独记一节。

**现象**：六人脸颊采样全部是 `(255,255,23x)` —— **R 和 G 双通道都顶到 255**，`R−G = 0`，
暖肤调被冲成近白，脸显得没血色（像过曝照片）。

**排查过程**（值得记下来）：

1. 一开始判断是「自发光太强」，把 `SkinGlow` 从 0.085 降到 0.050、脸片 0.13 降到 0.075 →
   **重新构建后实测 R−G 仍然 = 0，几乎没变化**。
2. 用「最高频色」统计取代平均值，发现脸颊的众数是 `rgb(255,255,231)` —— **两个通道同时饱和**。
3. 反推有效系数：旧脸片 albedo `#ffead8 = (255,234,216)`，实测输出 `(255,255,231)`。
   B 通道未被截断（216→231），得 **k_eff ≈ 1.07**；G 通道 234×1.07=250 已超 255 → 截断。
4. **结论：根因是 albedo 本身贴着 255，而不是自发光。**
   自发光是把三通道**一起**推高，只会让 G 更早顶格，降自发光治标不治本。

**修法**：把皮肤 albedo 压下来，给光照留余量。六人统一：

| 字段 | 改前 | 改后 |
|---|---|---|
| `skinBody` / `skinFace` | `#f9e3cd` / `#ffead8` | `#e0cab6`（R=224） |
| `skinFaceD` | `#f2d8bf` | `#c9b39e` |
| 紫薇（略暖） | `#f2ddc6` / `#f8e2cc` | `#e2ccb2` |
| `SkinGlow` | 0.085 → 0.050 | **0.040** |
| 脸片 `_EmissionColor` | (0.13,0.12,0.12) → (0.075,0.070,0.066) | **(0.030,0.028,0.026)** |

**为什么是 `#e0cab6` 而不是更亮的 `#f2d8c0`**（Lead 曾建议后者）：
`#f2d8c0` 的 R 本身就是 255，乘 k=1.07 得 273 → 截断 255，G=247，**R−G 仍只有 8，不达标**。
必须把 R 也压下来。按 k=1.09（实测档）验算 `#e0cab6` → 输出 (244,220,198)，R−G=24。

### ⭐ 判据（本轮最重要的可复用结论）

> **肤色是否过曝发白，看 `R−G ≥ 10` 且 `G ≤ 245`。**
> **R 顶到 255 本身不是问题**（皮肤本来就该亮），**关键是 G 不能顶格**：
> 一旦 R、G 同时到 255，两通道都被截断，R−G 差必然被抹平成 0，暖调彻底消失。
>
> 采样方法：取脸颊区域（避开眼眉嘴）求平均，或统计最高频色。
> 这条比肉眼判断可靠得多 —— 肉眼觉得「脸有点白」时，量化往往已经 R−G=0 了。

## 三、为什么这样（设计取舍）

1. **描边是卡通渲染的灵魂，但方块人的薄片结构让它变成负担。**
   本轮的核心判断是「描边按**部件厚度**分档，而不是按部件重要性分档」：
   厚块面配粗描边，薄片配细描边，小配件几乎不描边。这样既保住了卡通轮廓，又不产生黑条黑点。
2. **暗面暖化是「脸不脏」的唯一解。**
   世界用冷紫暗面是对的（建筑、地面需要冷暖对比），但皮肤用冷紫暗面一定发青。
   所以人物单独设 `_ShadowTint` —— 这也是任务书「头发/皮肤/衣服的 `_ShadowTint` 调得更暖更浅」那条的实装。
3. **自发光用来「保暗面亮阶」，不是用来「发光」。**
   卡通渲染只有 3 阶，一旦掉进最暗一阶就是一整块死色。少量自发光把最暗一阶抬起来，
   视觉上仍读作「阴影」，但五官保得住。
4. **调色板提亮不是「换风格」，是「补回卡通渲染吃掉的那一档」。**
   写实口径的深色在卡通 ramp 下会直接落到最暗阶，等于把所有深色部件糊成同一块黑。
   抬明度后各部件重新分得开，同时色相不动、人设辨识位全部保留。
