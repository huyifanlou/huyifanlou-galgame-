# 80 · 教学楼门斗裙板、校名横匾与宿舍值班牌

作者第三轮反馈：**教学楼的门下半部分被挡住、学校名字直接改为「学校」、宿舍楼内部门前的值班牌子放反了**。

## 一、教学楼门下半截被挡

`WorldBuilder.CollegiateFront()` 在门斗外立面有一条 8.4×0.9m 的整条石质裙板，正压在门扇平面上（z = front+bayD+0.03，门在 +0.035），把 1.5m 宽的门扇下方 0.9m 全部遮住。

改为左右两段裙板，中间留 2.3m 门洞：

```csharp
const float doorGap = 2.3f;
float segW = (bayW + 0.4f - doorGap) / 2f;
foreach (int sx in new[] { -1, 1 })
    Box(grp, new Vector3(sx * (doorGap / 2f + segW / 2f), baseY + 0.45f, front + bayD + 0.03f),
        new Vector3(segW, 0.9f, 0.14f), ColMat(b.plinth));
```

现在门扇从门槛到门楣完整可见，裙板只保留在门洞两侧。

## 二、校名改为「学校」

校门横匾不是程序化文字，而是 `Game/Assets/Resources/tex/sign_gate.png`（320×80）。保留原牌匾的深蓝底、双层米色描边和奶油字色，只重绘中间文字：

- 清空内部文字区，用 Microsoft YaHei Bold 56px 居中写「学校」；
- 牌匾尺寸、边框、导入设置（可读/最近邻）不变；
- `WorldBuilder` 注释与 `docs/77` 里的旧校名同步改成「学校」。

## 三、宿舍值班牌

「宿管值班」原来是单面文字，只朝门厅一侧；从走廊一侧看是一块空白的棕色板。现在牌板正反两面都放文字：

- 南面（门厅侧）保持 `SignText(..., z=6.37, 180°)`；
- 北面（走廊侧）新增 `SignText(..., z=6.31, 0°)`；
- 从门厅进、从走廊回都能正读「宿管值班」。
