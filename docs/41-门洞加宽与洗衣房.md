# 41 · 家里门洞加宽 + 浴室右边的房间改成明确的洗衣房

作者反馈（2026-10-26 晚）：

> 家里各房间的门口太窄，还有浴室右边的房间是干嘛的，有问题就修改一下

## 一、各房间门洞 1.2m → 1.8m

北带四间房都从 z=2 的横墙进出，原来门洞只有 **1.2m**。
层高 4m，门口通到顶，1.2m 的开口远看就是一条竖缝；第三人称相机 5.2m 距离下更明显。

把横墙五段重新排布，门中心不动，仅加宽到 **1.8m**：

| 房间 | 门中心 x（相对家中心） | 原门洞 | 新门洞 |
|---|---|---|---|
| 主卧 | -12.2 | -12.8 ~ -11.6 | -13.1 ~ -11.3 |
| 书房 | -5.8 | -6.4 ~ -5.2 | -6.7 ~ -4.9 |
| 卫生间 | +0.6 | 0.0 ~ 1.2 | -0.3 ~ +1.5 |
| 家务间 | +6.0 | +5.4 ~ +6.6 | +5.1 ~ +6.9 |

墙纸洞口同步改成门洞两侧各留 0.18m 安装余量。

保留通到顶的开口（不做门楣）：这是单层开放布局，加门楣反而会让第三人称相机在门下穿模；
只加宽、不改高度，观感与相机都安全。

模拟通行（120 帧，从 z=0.5 直走）：

```
浴室门 x=900.6： z 0.5 → 1.76 → 2.86 → 3.95 → 5.08   （穿过 z=2 未卡）
家务间门 x=906.0：z 0.5 → 1.76 → 2.85 → 3.94 → 5.03
```

## 二、浴室右边是「家务间」，但看起来像空房

原始布局里洗衣机×2、洗衣池、储物柜放在 **z=3.5、贴着南墙 1.4m 的位置**，
从门口看全部在家具视线的两侧/背后，房间里 80% 是空地板——作者自然认不出用途。

改成明确的**洗衣房 / 家务间**：

1. **洗衣机×2 + 洗衣池移到北墙**，进门正对；补机门、控制面板、皂液瓶。
2. **吊柜 + 开放搁板**（洗涤剂三瓶），吊柜加门缝和把手，避免读成一块白板。
3. **晾衣架**（金属杆 + 4 件挂着的衣服）、**熨衣板 + 熨斗**、**洗衣篮**。
4. **热水器**（东墙南段，带立管）、**拖把 + 水桶**、**两个储物箱**、**折叠整理台**（门东侧，放叠好的衣物）。
5. **地面改瓷砖**（与厨房/卫生间一致），北侧补一盏顶灯。

碰撞盒同步：57 个，0 问题。

## 三、顺手修正：餐椅碰撞盒还是旧坐标

docs/39 把餐桌椅从 6 把改成 4 把时，`Reg` 循环没跟着改——
玩家会在空地处撞到看不见的椅子。现在按照实际四把椅子注册：
`(0,-5.05) / (0,-3.35) / (±1.55,-4.2)`。

## 五、教训

- 住宅的净门洞小于 1.6m 时，在 4m 层高 + 第三人称相机下会明显读成"窄缝"；**1.8m 是舒适下限**。
- 家具如果贴着**远离视线的墙**摆，等于没摆；先站在门口看一遍，再决定朝向。
- 改家具数量/位置时，`Reg` 碰撞盒必须同步——否则留下看不见的墙。
