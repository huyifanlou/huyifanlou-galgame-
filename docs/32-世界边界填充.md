# 32 · 世界边界填充：缓丘 + 密林 + 远景山脊 + 铁路收口

作者反馈：站在铁路边往外看，草地是一块平板，一刀切到天上，世界外的边界不合理。

## 一、问题定位（三个数值互相打架）

| 参数 | 改前 | 后果 |
| --- | --- | --- |
| `TownData.GROUND_SIZE` | 260（±130m） | 草地到 130m 就没了 |
| `TimeOfDay.DAY_FOG_FAR` | 142m | 雾在 130m 处几乎没起效，遮不住切边 |
| `W.BORDER_TREES` | 96 株单圈 r=116~122 | 周长约 750m，平均间距 7.8m，是一圈稀树不是林带 |

结果：从边缘看出去，草地平面在 20~130m 处直接结束，草地与天空相接的那条线就是"世界没了"的证据。

## 二、做法（三层遮挡，各自管一段距离）

### ① 地面铺大 + 雾拉远
- `GROUND_SIZE` 260 → **620m**（±310m），雾 `DAY 70/300`、`NIGHT 60/230`（原 52/142、44/132）。
- 天空穹顶 170 → **420m**，相机远裁 320 → **560m**（必须覆盖穹顶 + 玩家偏移，否则走远出现黑幕）。
- 效果：地面边缘落在雾的完全遮蔽距离之外，永远看不到"地的尽头"。

### ② 边界缓丘（地形真的抬起来）
- 新增 `RimH(x,z)`：r ≤ 128m 全平（可行走区必须平），128m 起抬升，198m 外继续加高，配合 Perlin 噪声出起伏。
- 地形网格由平的 `Strip` 换成新的 `MeshFactory.StripH`（带高度场的条带，260×90 网格）。
- 两处必须压平，否则会把水和铁轨埋掉：
  - **河谷**：距河 13m 内压平、37m 外恢复 → 河在一条山谷里流出去；
  - **铁路走廊**：z≈104 两侧 9m 内压平 → 铁轨不会陷进山坡。

### ③ 边界密林（视觉挡墙）
- `ForestBelt()`：134~262m 环带撒点，内圈（<166m）三层次树冠、外圈单锥，**合并成 3 个网格**（3 个 draw call，不参与碰撞、不参与近距隐藏）。
- 内圈按角度噪声留 **林窗**（径向对齐），能透过缺口看到第二圈和山丘——边界才有纵深，不是一堵墙。
- 排除：河谷 13m、铁路走廊、隧道口 15m 半径内不种树。

### ④ 远景山脊
- `Ridges()`：222m / 285m 两圈环形剪影，高度按两层 Perlin 起伏（18~52m / 26~68m），只做朝内单面。
- 颜色 `#3d4854` / `#4a5764`，靠雾做空气透视，填充树林之上的天际线。

### ⑤ 铁路收口（最刺眼的一条线）
- 铁轨 250 → **236m**（±118m），两端各加一座**石砌洞门 + 洞内暗腔 + 翼墙 + 压檐**，山体在洞门后 6m 起坡把轨道"吃"进去。
- 洞门上方挂一盏常亮暖光（`#ffcf8a`，range 17）：东侧洞口常年背光（太阳固定在 +X+Z），没有这盏灯石券是纯黑的。

### ⑥ 边界改圆形
- 玩家 clamp 由方形（±128 的方框，四角到 155m，会跑进山体）改为**圆形**（`ClampRound`），与圆形小地图一致。
- 半径取 128m：最远的可交互建筑是车站站台（r≈124），必须留在可达范围内。
- `TryTree` 的散布检查同步改成圆形，避免树被种到抬升的山坡上（y=0 会陷进地里）。

## 四、第二版：树种多样性与山形（作者反馈"树只有一种、山偏写实、高低一样"）

### 4.1 七种树，每种合并成一个网格
原来整条林带只有一种锥形松，远看是一排绿锥子。现在按比例混交：

| 种 | 形态 | 占比 | 颜色 |
| --- | --- | --- | --- |
| 松 | 三层锥 | 30% | `#4a8250` |
| 阔叶 | 主干 + 三球冠 | 24% | `#5f9c63` |
| 杉 | 细高单锥 | 20% | `#3a6a44` |
| 樱 | 矮冠球簇 | 6%（神社一带翻倍） | `#cf94ad` |
| 落叶 | 细高干 + 小球冠 | 8% | `#6aa06a` |
| 灌木 | 贴地双球 | 林缘独立一层 | `#4a7a4e` |
| 秋色阔叶 | 阔叶形 | 12% | `#c08a45` |

- 新增 `MeshFactory.Sphere`（低面数球，朝外法线）做阔叶/樱/灌木的冠。
- 每种树一个合并网格 → 7 个 draw call，仍然不参与碰撞、不参与近距隐藏。

### 4.2 山：从"一圈等高的土坡"改成高低不一的峰群
- 新增 `PEAKS` 表：**12 座峰，角度、距离、峰高、影响半径各不相同**（12~44m 高、204~268m 远），高斯叠加在基础缓坡上。
- 地形网格改**块面法线**（`StripH(..., flat: true)`，每格独立顶点 + 面法线）：低面数块面山体，跟像素风一致，不再是写实的平滑曲面。
- **林线**：`RimH > 13m` 不再长树，山顶留空，山形才露得出来（树只长在山腰以下）。
- 删掉上一版的 `Ridges()` 远景剪影——真山地形已经够用，两套山会打架。

### 4.3 隧道口山体放缓
上一版洞门背后 4m 就拔起 17m，是一堵绿墙。改成洞门后 2m 起坡、12m 坡长堆到 10m，读起来是"铁路钻进山脚"而不是"撞墙"。

## 五、遗留

- 山体最高 44m，贴地视角仍会被近处树线挡住；山峰主要在林窗、河谷和俯视时露头。要让它稳定可见得把山做到 60m 级真山尺度。
- 太阳固定在 +X+Z：向南/西看是背光面，整条林线接近剪影，树种与秋色只在受光面（北/东）分辨得清。要两面都好看，得给树冠加轻微自发光或抬环境光——会影响整个场景，等作者定。
