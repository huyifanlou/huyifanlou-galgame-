# 72 · 巨樱沿树干分三层树冠

作者（2026-10-30）：

> 树干只有树干没有任何实体，应该是三层分布的樱花，现在只有顶部有

> 注：三层冠后来先改为上窄下宽并做错位（docs/73），随后又按《我的世界》
> 大型樱花重建为「粗干 + 多枝 + 宽伞冠」（docs/74）。当前以 docs/74 为准。

## 一、改动

### 1. 三层树冠（WorldBuilder.cs `GiantLeafBlocks`）

原先巨樱只有顶部一团冠，14.4m 树干中下部全裸。现在沿树干加两层，
与顶冠合成三层，冠幅逐层放大：

| 层 | 冠底高度 | 冠幅 | 结构 |
| --- | --- | --- | --- |
| 下层 | 4.0m（y5） | 13.6m（17 格） | 7×7 中央 + 四向端冠 + 四角叶团，+2 层内收 |
| 中层 | 8.8m（y11） | 15.2m（19 格） | 同上，端冠外移一格 |
| 上层 | 15.2m（y19） | 16.8m（21 格） | 原六层收分主冠，冠顶 26.4m |

- 新增局部函数 `Tier(by, arm)` 生成下、中两层，避免两段重复代码。
- 树干从下层冠中间穿过，生成后挖掉与 3×3 树干同格的叶块，
  避免叶块和原木共面闪烁（`set.Remove`）。
- 三层之间分别留 0.8m、2.4m 裸干，站在空地里能明显数出三层。

### 2. 三层主枝（WorldBuilder.cs `BuildGiantBark`）

- 主枝由只在 y18 一圈，改为 **y4 / y10 / y18 三圈**，
  长度分别伸到 7 / 8 / 9 格，随冠幅递增，托住每层叶团。
- 四角阶梯短枝同样复制到三层，避免角部叶团悬空。

### 3. 叶块明暗改为按相邻叶块判断（WorldBuilder.cs `BuildVoxelMesh`）

- 旧规则：全局最低一层最深、最高一层最亮，中间全用主色——
  三层冠只有最底下和最顶上变色，中层和下层冠底都是主色，层次分不开。
- 新规则：**下方没有叶子的块用暗色（冠底），上方没有叶子的块用亮色（冠顶），
  其余用主色**。每层冠的底面都有暗边、顶面都有亮边。
- 小樱树也走同一函数，冠底/冠顶仍然一暗一亮，造型语言不变。

- 巨樱总尺寸仍是 docs/71 的 3 倍规格：3×3 粗干、16.8m 主冠幅、26.4m 冠顶。
- 三段树干之间留裸干，不再是从头到脚一根光杆，也不是一整团大冠。
- 远景林带/远山仍是 docs/62 基线，未动。
