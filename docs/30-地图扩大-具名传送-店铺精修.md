# 30 · 地图扩大、具名传送（二次确认）、店铺立面精修

本轮针对：墙体/区域连接突出、居民楼间距过紧、路灯在门前、单元楼压铁轨、指定建筑传送、商铺千篇一律。

## 一、地图扩大与间距
- 用地：**220×220 → 260×260m**，可行走半径 95 → **110m**；河道延伸到 ±130，边界林带外移到半径 116~122。
- 河东住宅第 4 排（单元楼）南移到 **z=93**，与第 3 排（z=78）之间留出约 8.5m。
- 铁路南移到 **z=104**，单元楼（z 89.5~96.5）与道砟（101.8~106.2）之间留 5.3m，不再压轨。
- 车站整体南移：站前广场 68→78、站房 76→86、站台 84→**98**，车站路延长到 96。
- **路灯避开门口**：生成后移除距任一建筑门口 2.8m 内的路灯。
- 校验器复核：46 栋建筑 / 12 条道路，零违规。

## 二、墙体与地面连接
- 学校支路矮墙的端部收在中央街/环路之外，路口留口加大到 ±(宽/2+2.2m)，门口留口 ±1.8m；中央街/环路墙上单独为三条支路开口——不再出现墙头探进路口。
- 钟楼广场由 18×20 矩形改为**圆形广场（半径 11m）**，带石沿，消除矩形突出的四角。
- 移除石桥/廊桥下的“深色阴影矩形”——从上方看会像盖在水面上的黑块。

## 三、小地图：具名传送 + 二次确认
- 地图上新增 8 个可点击地标：**家、学校、神社、车站、游乐场、钟楼、公园、老街**（白框标记）。
- 点击地标弹出确认框「传送到「X」？」→ 确认后传送到该建筑/区域**门前**；取消则留在原地。
- 点击空白处仍是原来的直接传送；圆形地图、M 放大/缩小保留。

## 四、商铺立面精修
参考京都町家店面类型（格子店、出格子窗、装饰展示窗、看板建筑）后按店铺类型区分：
- **茶楼 / 餐馆**：二层挑台 + 木栏杆 + 两盏红灯笼。
- **绸缎庄 / 药铺 / 书店 / 照相馆**：一层两侧展示橱窗 + 木格栅 + 竖向招牌。
- **超市 / 便利店**：一层上方通长横招牌（看板建筑）。
- 原有雨棚、悬挂小招牌保留，颜色按店铺不同。
