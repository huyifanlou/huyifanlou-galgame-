# 14 · 建筑配件与矮墙写实化 + 树木净距（2026-10-18）

作者要求：**建筑物、矮墙和各种和建筑一起的装饰物更写实**；**部分树木和建筑贴太近**。

## 一、矮墙（贯穿全场的 56 段）

之前是三块纯色板拼起来的"纸片墙"：墙体 `#cfc9ba`、压顶 `#b8b0a2`、立柱 `#c9c3b6`，没有任何贴图。

现在：新增 **`concrete`** 程序化贴图（128px / 覆盖 0.8m = **160px/米**）——
骨料颗粒（深浅三色）、气孔麻点、低频细裂纹、**墙脚潮痕**与苔点；
墙体 / 压顶 / 立柱全部改用 `MeshFactory.BoxUV(size, 0.8f)`，**四面同密度**（和立面的做法一致），
压顶与立柱只做轻微提亮，保留"石材"层次。

## 二、建筑配件（和楼一起的那些东西）

| 配件 | 之前 | 现在 |
| --- | --- | --- |
| 门前绿篱（每栋楼两丛） | 纯色绿方块 | **叶簇贴图**（与树冠同材质体系）+ 世界尺度 UV |
| 门前石阶 | 纯色 `#b8b0a2` | **铺装（path）同材质** + 世界尺度 UV → 和广场铺装一个石材质感 |
| 雨落管（两侧） | 纯色（勒脚色） | 带 0.22 光滑度的漆面（受光有细高光） |
| 屋顶水箱 / 通风管 / 排风帽 / 天线杆 | 纯色 | **金属件**（`MatLib.Metal`，受光出高光） |
| 雨棚（食堂/艺术楼/小卖部） | 条纹贴图（无受光响应） | 加 0.10 光滑度（布面轻微反光） |
| 矮墙 | — | 见上 |

## 三、树木与建筑贴太近

实测（树心到建筑轮廓的最近距离）：最近的一棵是**池畔柳树 × 教学楼西墙 1.30m** —— 柳树冠 2.8m 宽，
等于树冠插进了立面；其余树大多在 2.5m 以上。

修法两层：
1. `CampusData.NudgeTreesFromBuildings(2.25m)`：树生成完之后，把离建筑（**含教学楼东侧翼**——之前侧翼不在保留区里）
   不足 2.25m 的树沿最短方向推开。**只做局部修正、不改 RNG 序列**，其他植被布局完全不动。
2. 点景柳树从 (-22.3, -10.5) 挪到 (-23.5, -9.5)：既离教学楼 2.5m，又不落进池塘保留区（原来那个位置的
   可用空间只有 1.5m，nudge 会把它推到池塘的方形保留区里）。
3. 校验器新增 **规则 7b**：树心到建筑轮廓（含侧翼）**≥ 2.15m**，违反即报错，防回归。
