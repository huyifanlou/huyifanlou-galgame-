# 107 · 六人立绘重新去白底与透明边缘修复

> 2026-11-11。作者要求「把立绘的白色背景图扣干净」。此前阈值流程已出现白发、衣物与脸部高光误扣，单纯降低白色阈值会继续扩大破洞。

## 做了什么

- 六张 `Game/Assets/Resources/Portraits/{id}-cut.png` 从原有 `*-dialogue.jpg` 重新求遮罩，保留 1024×1536 构图及瑶清寒原来的 0.8 缩放。
- 樊楼、景楠：清腿间与手臂空隙、鞋边与发梢的背景；白 T 恤、鞋和牙齿保持不透明。
- 镜荧、莉莉雅：以语义遮罩区别浅色头发与白底，清掉发卷中的背景，恢复先前被打穿的白发、高光、头饰、围裙和蕾丝。
- 瑶清寒：保护近白肤色，手工描出白袖口保护区，避免白衫与背景连通时被整片扣掉。紫薇另清肘部闭合白底。
- 仅抗锯齿边缘做白底颜色分离；人物内部 RGB 逐像素与原 JPG 一致。透明像素 RGB 清零，减少缩放白边。

## 管线与回滚

1. 内置 imagegen 先生成四张 Alpha 引导；只保存 Alpha，不采用重新生成的人物颜色。提示词和说明在 `tools/portrait-masks/README.md`。
2. 瑶清寒的图片工具输出被内容检测拦截，作者明确回复「允许用本地脚本处理」。最终六张均由本地脚本使用原图 RGB 合成，原图、人物设计和服装不改。
3. 新入口：`python tools/refine-portrait-masks.py` 仅生成审查图；`python tools/refine-portrait-masks.py --write` 才写入 Unity。依赖仅 Pillow、numpy。
4. 旧 `tools/matte-portraits.py` 默认停止覆盖；只有显式传 `--legacy-threshold` 才运行历史算法，防止再次打穿白发和白衣。
5. 开工前版本备份：`shots/portrait-matte-before-20261111/`（包含当时工作区的六张 PNG 与旧脚本，不依赖 Git HEAD）。

## Unity 导入

`Bootstrap.SetupPortraitTextures` 在每次 Windows/WebGL 构建前统一处理六张透明立绘：无压缩、无 mipmap、保留原尺寸、Bilinear、Clamp、Alpha Is Transparency。原先默认的有损压缩和 NPOT 缩放会影响 UI 轮廓。
