# 34 · 室内系统：家 / 教学楼（可交互建筑第一版）

## 一、要解决的问题

世界已经完整（620m 地面、46 栋建筑、128m 圆形可行走），但 `F` 键是个空壳：
`PlayerRig.cs` 里站在交互点按 F 只弹一句「XX 内部将在后续迭代开放」。
这一轮把**家**和**教学楼**的内部真正建出来，形成「走到门口 → F 进入 → 室内走动 → 到门口 F 出来」的闭环。

剧情、立绘、存档都还没接——这一轮只做空间与玩法骨架。

## 二、做法

### 2.1 室内建在世界之外

室内不是独立 Scene（那要重新生成一套资产、还要处理场景加载），而是在世界外的空地上
（家 `x≈900`、教学楼 `x≈1040`）用同一套程序化管线建**封闭盒子**，进场时把玩家瞬移过去。

- 地面只有 620×620（±310），x=900 处什么都没有；房间六面封闭，看不到外面。
- 天穹（半径 420）也照不到这里，相机 clearColor 是 `#10141c`，室内封闭所以无感。
- 好处：一套材质/贴图/网格工厂复用，不用维护第二个场景；坏处：室内外同时存在于场景里，
  进场时只 `SetActive(true/false)` 切换，内存里常驻。

### 2.2 分层碰撞：AABB + 楼层掩码

室外碰撞本来就是自写 AABB（`PlayerRig.Collides` 遍历 `BUILDINGS/TREES/FENCES/...`），
室内沿用同一思路：

```csharp
public struct Solid { float X1, Z1, X2, Z2; int Mask; }   // bit0=一层 bit1=二层
```

查询时只测 `Mask & (1 << 当前层)`，所以一层的墙不会挡住二层的路。
家具（沙发、餐桌、课桌）同样登记 AABB；课桌间距按「列 2.3m / 排 1.8m」留出 0.56m 过道，
0.32m 的玩家半径能穿过去，不会卡死在桌椅阵里。

### 2.3 楼层与楼梯：地面高度是函数

室内没有物理，脚底高度仍由函数给：

```csharp
public float FloorAt(float x, float z, float curY) {
    // 楼梯区优先：按坡度插值
    foreach (var s in Stairs) if (s.Contains(x, z))
        return Mathf.Lerp(FloorY[s.From], FloorY[s.To], s.T(x, z));
    return FloorY[LevelOf(curY)];   // 否则按当前高度判断在哪层
}
```

楼梯在几何上是 14 级实心踏步（视觉），走上去靠 `Stair` 插值（手感）。
二层楼板按「整块减去楼梯洞」拆成 3~4 块 `Slab`，洞口就是上下层的通道。

### 2.4 进出与联动

`InteriorManager` 负责：

| 项 | 进入 | 离开 |
|---|---|---|
| 玩家 | 瞬移到房间 `Spawn`，脚底 = 一层地面 | 回到进门前的位置 |
| 相机 | `dist 4.4 / pitch 0.32`（室外 13 / 0.38） | 还原 |
| 小地图 | `enabled = false`（室内没有意义） | 恢复 |
| 天气 | `Weather.Indoor = true` → 粒子停发（状态保留） | 恢复 |
| 提示 | `NearLabel` 给整句「按 F 离开「家」」 | 还原 |

相机的穿墙问题靠已有的 `Physics.Raycast` 避障——室内墙体保留了 `BoxCollider`
（只给相机射线用，玩家移动仍是 AABB，不受物理影响）。

### 2.5 新增贴图（仍走程序化）

`TextureLibrary` 加了 5 张，沿用 `Px` 画布 + `C(hex)` + 固定种子的写法：

| 名字 | 用途 | 尺寸 |
|---|---|---|
| `in_floor` | 木地板（横向长条 + 错缝 + 木纹） | 320² |
| `in_wall` | 壁纸（米色 + 细竖条 + 噪点） | 256² |
| `in_tile` | 瓷砖（64px 方格双色） | 256² |
| `in_ceil` | 天花板（白 + 板缝） | 256² |
| `in_board` | 黑板（深绿板面 + 木框） | 320×160 |

几何一律用 `MeshFactory.BoxUV(size, 米数)`：尺寸烘进网格、贴图按米平铺、缩放保持 1，
碰撞体尺寸才好直接算。

## 三、房间内容

### 家（20 × 14m，两层，净高 3.2）

- **一层**：玄关（鞋柜、穿衣镜）｜客厅 10×14（沙发、茶几、地毯、电视柜、书架）｜厨房餐厅 10×14（L 台面、冰箱、餐桌 + 4 椅、吊灯）
- **楼梯**：东侧 x 7.6~9.6 / z 5.6 → 0.4，16 级升 3.4m，西侧挡墙 + 斜扶手
- **二层**：起居厅（沙发区 + 书架，8×20）｜主卧 9×6（双人床、双床头柜、衣柜、书桌 + 椅）｜浴室 5×6（浴缸、洗手台、镜子、马桶）｜书房 6×6（书桌、书架、单人沙发）
- 灯：一层 3 盏、二层 4 盏暖白点光（不投影）

### 教学楼（34 × 16m，两层，净高 3.8）

- **一层**：门厅（值班台、公告栏）｜走廊 33.8×3.2 贯通｜教室 A/B/C（各 20 套课桌）｜办公室｜楼梯
- **楼梯**：走廊西段，宽 2.0m，x -9.4 → -14.8 升 4.0m，直上二层走廊
- **二层**：走廊｜教室 D/E/F（同布局）
- 每间教室 10.8×8.5：黑板 + 讲台 + 5×4 课桌 + 侧墙板报 + 2 盏灯；走廊每 6.4m 一盏

## 四、验证

1. 走到「家」门口（小镇西南 `-35.5, 70`）按 F → 进入玄关，WASD 走到楼梯上二层，卧室/浴室可进
2. 走回门口按 F → 回到室外原位置，小地图与天气恢复
3. 走到「教学楼」门口按 F → 门厅，走廊进教室，楼梯上二层
4. 室内第三人称镜头不穿墙（贴墙时相机会自动拉近）

截图：`shots/34-home-*.png`、`shots/34-school-*.png`、`shots/34-entry-*.png`

### 截图验收参数（新增）

```
Campus.exe -shot out.png -indoor home|school [-floor 1] [-px X -pz Z] [-dist D -pitch P]
```

`-indoor` 直接开在室内，`-floor 1` 站二层，`-px/-pz` 指定室内坐标（世界坐标，家 x≈900 / 教学楼 x≈1040）。

### 踩到的坑（都已修）

| 现象 | 原因 | 修法 |
|---|---|---|
| 镜头钻进墙里，满屏墙纸 | 相机避障的「最小 1.2m」比墙还远，`safe` 直接把镜头推过墙 | `safe` 再夹一次 `hit.distance - 0.1` |
| 二层满屏是地板 | `LookAt` 用的是绝对高度 `y=1.1`，人在 3.02m 的二楼等于往地板下看 | 注视点改 `p.y + 1.5` |
| 二层地板是白色天花 | 楼板上下共用 `in_ceil` 贴图 | `Slab` 增加 `topMat`，楼板上再贴一层地面 |
| 课桌/椅子伸进走廊 | 教室中心与深度取错（cz=-2.8 / d=6.2，实际 z -5.6..0.4），最后一行排到墙外 | 按 `zBack/zFront` 推桌椅位置，行距 1.6 |
| 站在家门口提示「平房小院」 | 交互圈重叠时按数组顺序取第一个 | 改成取**最近**的交互点 |
| 贴墙时角色后脑勺糊满屏 | 镜头被挤到 1m 内 | 相机距头部 < 2m 时隐藏角色精灵 |

## 五、扩容与穿模修正（第二轮）

第一版房间偏小（家 12×10、教学楼 24×12），相机臂放不开、家具也容易顶到墙。这一轮：

- **放大**：家 20×14（净高 3.0→3.2）、教学楼 34×16（净高 3.6→3.8）；教室从 2 间变 3 间，每间 10.8×8.5。
- **加自动校验** `InteriorBuilder.Validate()`：建完逐个检查非墙碰撞盒
  ① 是否越出外墙内表面 ② 是否与同层墙体重叠超过 6cm，问题逐条 `Debug.LogWarning`。
  跑一次就能拿到清单，不用靠肉眼找穿模。当前：家 44 盒 / 校 159 盒，**问题 0 处**。
- **家具补碰撞**：原来只有墙和椅子挡人，床、沙发、餐桌都能穿过去。现在大件都登记了 AABB。
- 顺带修掉：教室后墙板报正好压在走廊门洞上（挪到侧墙）；走廊墙段与外墙之间留 28cm 缝；
  玄关隔墙正对大门（隔墙起点从 z=-4.5 退到 -1.5）。
- 机位：室内 `dist 5.2 / pitch 0.26`（净高 3.2 下镜头抬 1.34m，不会顶穿天花板）。

## 六、楼梯修正（第三轮）

作者反馈「楼梯被墙堵住」「栏杆没贴合、超出二楼平面一大截」，逐条查下来是三个独立问题：

1. **二楼横墙横穿楼梯口**：家的二层隔墙 `z=1.0` 那一段一直画到 `x=10`，正好压在楼梯洞（x 7.6~9.6）上。
   碰撞是 2D AABB + 楼层掩码，人爬到 z=1.0 时高度已经 3.01m（算二层），就被这堵墙挡住上不去。
   → 删掉 `x 7.4~10` 段，改成 `x=7.4` 的竖墙（书房东墙 = 楼梯间西墙），楼梯口从北侧敞开进起居厅。
2. **栏杆是悬空斜杆**：`Rail()` 画的是从 (1.10, 5.6) 到 (4.50, 0.4) 的一根细杆，比楼梯面高 1.08m，
   顶端 4.50m 比二楼地面（3.40）还高一截，看上去就是根飘着的木条。
   → 楼梯三面本来就是墙，栏杆多余，**直接删掉**两处 `Rail()`。
3. **厨房台面堵死楼梯入口**：北侧台面画到 x=8.5、东侧台面又占 x 9.21~9.79，
   把楼梯口（x 7.6~9.6）北侧的落脚带挤得只剩 0.07m。
   → 北台面缩到 x 0.5~7.2，东台面整条挪到楼梯南侧（z -6.5~-1.5）。

另外楼梯间原来没有灯，进去一片黑 → 家里/学校各补一盏。

**验证方式**（新增可复用的手段）：`-sim w,N` 模拟按住 W，`PlayerRig` 每 30 帧打一次坐标：

```
[Sim] f=30  pos=(908.60,0.27,4.94)     ← 起步
[Sim] f=150 pos=(908.60,3.15,0.33)     ← 爬到顶
[Sim] f=210 pos=(908.60,3.43,-1.85)    ← 已在二楼平面
```

学校楼梯同样：`y 0.05 → 4.02`，一路到二层走廊。两处都能走通。

## 七、遗留

- 只有「家」「教学楼」两栋有内部；其余建筑按 F 仍弹「暂未开放内部」。
- 室内没有 NPC / 剧情触发点，`F` 在室内只用于出门。
- **窄房间镜头会贴脸**：外墙通高 6m、天花板 3m，相机臂放不到 5m 以上，
  小房间（卧室 6.5×4.2）里常被墙挤到 1~2m，此时角色精灵自动隐藏。
  要彻底解决得走「切屋顶 + 矮墙」的娃娃屋俯视，属于下一轮的量。
- 家具是纯几何拼装，没有可交互物件（抽屉、灯开关、电视）。
- 二层走廊尽头、门厅西侧有未定义空区（结构上存在，暂时空着）。
