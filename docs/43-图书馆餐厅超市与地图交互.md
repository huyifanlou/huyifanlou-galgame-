## 二、联网参考的现代设计要点

- **图书馆**：暖木色 + 木格栅吊顶 + 整墙书墙 + 长阅读桌 + 休闲沙发角 + 绿植，
  用「书墙包围」而不是一排排空书架。
  参考：开放式书吧、阅读区灵感图集（3d66）。
- **餐厅**：卡座 / 固定座 + 开放厨房/吧台 + 吊灯 + 酒架 + 暖木与深绿，
  桌面照明压低到人眼高度，形成暖色就餐区。
  参考：现代日式餐厅设计指南、Pinterest «Fixed seating / banquette»。
- **超市**：入口直达生鲜、烘焙/冷藏/收银明确分区，货架成列、动线清晰，
  用线性灯带 + 暖色点光源；商品包装比书架书脊更小、更密。
  参考：超市设计灵感图集（3d66）、大型卖场设计（300.cn）。

## 三、图书馆（library）

- 22×14m，木地板、木格栅吊顶 + 线性灯带，南北大窗 + 东西高窗。
- **书墙**：西墙 8m 通长、东墙 4.7m、北墙两翼各 2.5m，再加北墙中央 4.8m 主书墙
  （从入口正对，解决第一版「进门只看到空墙」）；4 层彩色书脊。
- **阅读区**：两张 3.8×1.1m 长桌，每桌 6 椅，桌面书堆 + 阅读灯 + 吊灯；中央长毯。
- **休闲区**：东侧双人沙发对坐 + 茶几 + 地毯 + 落地灯。
- **服务区**：西南 L 形借阅台（带「借阅台」牌）、还书箱、书车；入口东侧新书展示台。
- 窗下阅读长凳、挂画、挂钟、四角绿植；碰撞 32 盒 0 问题。

## 五、超市（supermarket）

- 18×12m，入口正对**生鲜岛台**（第一版货架像书墙、后墙空白，已推翻重排）。
- **分区**：入口中央生鲜岛 + 西侧生鲜台；西墙烘焙玻璃柜 + 后架 + 暖光；
  东墙 3 台冷藏柜；中央两组双面货架（商品 0.62 尺度、密排）；南墙「新鲜每一天」品牌墙 +

## 六、大地图：拖拽 / 滚轮缩放 / 双击传送

`Minimap` 从「512 圆图 + 点击任意位置直接传送」改成：

1. **底图与视图分离**：1024×1024 完整底图 + 512×512 当前视图；缩放/平移时只重采样
   视图，圆形遮罩固定加在视图上，所以圆形地图边缘不会跟着缩放跑。
2. **拖拽平移**：大地图圆内按住左键拖动，视图中心按像素换算世界坐标；中心自动夹在
   世界边界内。可见 `shots/43-map-zoom.png`（-mapzoom/-mapx/-mapz 验收参数）。
3. **滚轮缩放**：1×~4×，以鼠标所在点为中心缩放（滚轮向上放大）。
4. **空白处单击不传送**：
   - 单击空白：只记录点击时间/位置，不传送；
   - 0.36s 内同位置第二次点击（双击）：才调用 `PlayerRig.Teleport()`；
   - 单击建筑点：弹出「传送到『建筑』？」确认框（保持原交互）；
   - 室内：地图可拖拽/缩放查看，但任何点击传送都被禁用。
5. **建筑级传送点**：27 个（25 个建筑门口 + 钟楼/公园两个地标），
   包括 家、教学楼、图书馆、食堂、实验楼、礼堂、宿舍楼、餐厅、超市、奶茶店、照相馆、
   书店、便利店、绸缎庄、茶楼、杂货铺、药铺、戏院、邮局、神社、车站、游乐场、鬼屋、
   茶座、音乐亭、钟楼、公园。主点常显标签，次点在地图放大 ≥2× 或鼠标悬停时显示；
   标签加半透明底条，重叠时自动避让。
6. **避免相机抢输入**：大地图打开时，第一/第三人称的鼠标视角、滚轮镜头距离全部让位；
   否则拖地图会同时转镜头。

## 八、教训

- 从入口视线决定第一眼内容：图书馆必须有正对的主书墙，超市必须有正对的生鲜岛；
  只把家具堆在侧墙，玩家进门仍会觉得空。
- 超市商品不能复用书脊尺寸：商品块一大就像书墙；缩小到 0.62 尺度并把排距从 0.17m
  收到 0.13m，才像货架。
- 圆形地图缩放不能直接缩放贴图矩形（圆形遮罩会跟着跑）；用「底图 + 当前视图 + 固定遮罩」。
- 每帧重采样地图视图要用预分配的 `Color[]` 和自写双线性采样，避免 `GetPixelBilinear`
  的逐像素原生调用与 GC。
- 地图打开时不仅要解锁鼠标，还要让 PlayerRig 跳过鼠标视角与滚轮——否则拖地图会转镜头。
- 室内地图禁传送要在 `HandleClick` 和鼠标松开两处都拦住，不能只靠 UI 文案。
- 建筑改名只改显示名（餐馆→餐厅），纹理仍按 id 生成；传送点按建筑 id 取坐标，避免坐标硬编码。
