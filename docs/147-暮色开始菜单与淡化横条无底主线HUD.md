# 147 · 暮色开始菜单、淡化横条与无底主线 HUD

2026-11-17。作者要求开始 UI 适配女主暮色背景、确认每个入口可进入；游戏内取消块状卡片，恢复条状淡化背景，主线块不再有背景。

## 开始界面

四项操作取消不透明矩形按钮，采用浮动文字、细线和香槟金选中标记，保持女主、坐姿与背景完整。鼠标悬停/移动可选择，也支持↑/↓切换、Enter确认；Esc进入设置，新游戏确认中Esc取消确认。图像、原立绘和字体均不改。

开始/继续、新游戏、设置、退出都走同一个 Entry/Activate 分发，避免画面按钮与测试调用分成两套行为。无有效存档时第一项显示开始并回家开启首章；有档时继续最近有效档。新游戏仍需确认并保留手动档，设置关闭后返回开始界面。

## 游戏内 HUD

顶部标题、时间天气和操作按钮取消独立色块，使用连续的深色渐隐横条。顶部按钮改为透明文字+悬停下划线；底部按键提示也改成向上消隐的横条。进出建筑提示取消实体底板，提示和通知用文字阴影保证可读性。

左上主线与追踪支线完全删除填充底板，仅保留章节字、标题、目的地、细引导线、轻量进度线；文字加轻阴影，以兼顾明亮天空与室内墙面的对比。点击任务文字仍可开手记，支线点击定位到对应条目。地图、字体选择、任务重置等已有功能保留。
