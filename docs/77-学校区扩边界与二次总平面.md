# 77 · 学校区扩边界与二次总平面

本轮针对作者现场反馈：**校舍挤在一起、朝向不对、不要门牌、边界可以扩、礼堂前国旗太近**。在不改校舍样式的前提下，重做总平面，并同步围墙、道路、场地、留空、路灯、点景树和碰撞。第二轮反馈（升旗台朝向不对、离礼堂太近）的处理：**取消校门内广场的独立旗杆，把升旗台并入操场看台中央，踏步朝跑道**。

## 一、结论先看

- 校区包围盒从 **约 48.6×72.4m** 扩到 **约 70.6×84m**（西北侧随世界圆边界阶梯收分，实际可用约 4.8k㎡，原约 3.5k㎡）。
- 教学/实验之间留出 **29m 深方院**；图书馆独立压在西轴端；宿舍/食堂移到西北生活园；活动中心移到北侧服务带；门卫回到校门旁。
- 礼堂中心改到 **z=−60**，与校门、图书馆同一条轴；礼堂到跑道 **14m**、到篮球场 **10m**，不再贴在一起。
- 升旗台并入 **操场看台中央** `(−28,−23)`：5m 宽、1.2m 高、三级踏步**朝跑道**，旗杆立在台面中央；礼堂前与校门广场均不再有旗杆，升旗台距礼堂约 **37m**。
- 校舍（`s_` 前缀）不再生成白天的名称牌和夜间发光牌；只保留校门「华清大学」横匾。

## 八、已知取舍

- 校区已顶到世界圆形边界，西北/西南不可再大扩；要再拉开只能压缩建筑或把生活区移到校外。
- 图书馆南侧离阶梯围墙 3m、宿舍/食堂离北墙 2–3m，属于边界退让；若作者希望更大，可再整体内移建筑或进一步缩小宿舍/食堂。
- 礼堂朝西，午后西立面受自身柱廊与周边遮挡偏暗；如需亮立面，建议在 17:00 后观察，或再单独做泛光照明。
- 升旗台并入看台后，从跑道方向看旗杆正前方是钟楼（`−17,−12`），形成“旗—钟楼”的背景构图；如果作者想要别的背景（例如让旗对着礼堂或校门），只能整体旋转看台/换位置，代价是跑道北侧构图要重排。
