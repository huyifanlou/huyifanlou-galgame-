# 13 · 操场与花坛：颗粒对齐地形、去除「贴上去的方片」（2026-10-17）

作者反馈：**花和操场的像素和周围不太一致，操场和跑道贴合不合理**。查下来是同一类问题：

- **操场**：跑道贴图把「内场草 + 外圈草」也画进了自己的 2048px 里（内场草是 12.5cm 的粗格），
  而地形草是 5.2cm 细格 → 内场与外围**两种绿色、两种颗粒**，整块 16×10m 的方片边界清晰可见。
- **花坛**：1.7m 花坛贴图的草格也是 10.6cm（比地形粗一倍），且是不透明方片 → 硬方边。

## 做了什么

| 对象 | 之前 | 现在 |
| --- | --- | --- |
| 操场跑道 | 实心贴图（自画草，12.5cm 格，方片边界可见） | **透明底 + 内场挖空**：只画跑道面/道线/场地线，草全部透出地形草（5.2cm 同颗粒、同色调、无接缝） |
| 花坛 | 64 逻辑 / 4px 草格（10.6cm）+ 不透明方片 | **透明底、只画花与茎叶**：草完全透出地形（同颗粒同色调）；花头 6 逻辑 px ≈ 8cm，中心略密边缘略疏 |
| 材质 | 操场/花坛用普通不透明材质 | 新增 `MatLib.Cutout`（Standard Cutout，alphaTest 0.4，Trilinear 采样）：只渲染实心部分，边缘不出现方片 |

实现细节：
- `Px` 新增 `ClearRound` / `Clear`（把像素擦成透明）——操场用 `ClearRound` 挖空内场（48,48,416,224,r=64），
  跑道面只保留「外缘 → 内道线」的环带；中线/中圈在挖空之后画，保证留在地形草上。
- 花坛改为**透明底**：不再自画草地（第一版只把草格减半，实机仍是一块浅色方片 —— 颜色/层次和地形草是两套）；
  现在只保留花头、花瓣、叶丛与茎影，配合 cutout 材质直接长在地形草上。
- 操场的密度仍是 128px/米（16m 宽撞 2048 上限），但**颗粒与周围一致**——因为草不再由跑道贴图提供。

## 验证

- 校验器：✓ 零违规（跑道贴图不在「贴地基准组」，其草已由地形提供，密度按地形算）。
- 贴图对拍：`track` 2048×1280 内场透明；`flower` 256×256、5.3cm 草格。
- 实机对比（左=改前｜右=改后）：
  - `docs/img/ground-track.png`：内场草与外围完全连续，跑道只剩红色环带与白线；
  - `docs/img/ground-flower.png`（4× 放大）：花坛不再是粗格方片，花朵直接长在与周围同颗粒的草地上，边缘毛化。
- 原始大图：`shots/px_track_c.png` ↔ `px_track_d.png`、`px_villa_c.png` ↔ `px_flower_d.png`。

## 说明

- 这条思路可以推广：以后凡是「地形上的贴片」（球场之外的临时场地、铺装、落叶区）都应走
  **只画贴片本身 + cutout + 透出地形**，避免"自带一套草/土"导致颗粒打架。
