# 111 钟楼门口两处虚影修复

2026-11-11，作者截图指出钟楼门框左下与右上两处白色毛刺；先处理此处，再进行居民区检查。

## 原因

钟楼底层塔身宽/深均为 4.6m，正面在局部 z=2.30。旧门洞底片也在 z=2.30，和石墙完全共面；门板只向前 2cm。视角、分辨率变化时，石墙与底片争夺深度，露出白色碎片。属于具体模型的共面冲突，不是场景内残留了两个重复钟楼。

## 处理

- 删除两张旧门洞平面，改用 `ClockTowerDoor()` 的实体背板、门板、门框、玻璃与把手。
- 背板中心 z=2.38、厚 0.10，最近处为 2.33，离塔身前脸至少 3cm；门板中心 z=2.485、厚 0.11，门框再向外。各层靠厚度与遮挡构造，不靠共面贴片。
- 钟楼石材使用独立材质关闭外扩描边与边缘光，保持原石纹，避免修改所有桥梁共用材质。
- 保留钟楼位置、轮廓、广场与交互点。

## 验证

`shots/111-clocktower/before/entrance.png`、`after/entrance.png`、`after/left.png`、`after/right.png` 固定机位对拍，正面和两侧未再出现门边白色毛刺；构建成功并已打开实机检查。居民区阶段继续带着此修复构建，见 docs/112。未提交 git。
