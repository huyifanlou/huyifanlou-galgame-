# 108 · 城镇配色、虚影与室内外入口统一修整

> 2026-11-11。作者要求地图美化、修 bug 和虚影、改善室内与外部建筑连接，审美方向由本轮自行判断。延续现有卡通渲染，调整成低对比暖石铺装、灰绿草地、浅木与米灰室内，让门窗和街道的主次更清楚。

## 美术与建筑

- 草地降低饱和与草簇密度；石路收窄亮边、压低黑白格对比，维持原有贴图尺寸和 160px/米密度。
- 全局后处理白天饱和度从 1.20 收到 1.02；室内壁纸改低对比竖纹，木地板和通用木家具统一为浅胡桃色，去掉满墙花点与亮黄木色。
- 主角家重做为清楚的双层窗、真实门扇、窗台、基座、简洁四坡屋顶与壁挂绿植。原来的 villa 贴图只有素墙，外部实际上没有可识别门窗。
- 通用入口补实体门套、门槛与把手；沿街店铺加壁挂花槽。所有新增壁挂件的外挑控制在既有建筑碰撞垫内，中央入口保持净空。
- 建筑坐标与数量维持现状；家仍在当前模型位置 (-34,70)，没有再搬一次。

## 查出的根因与修复

| 问题 | 根因 | 修复 |
|---|---|---|
| 家门交互错位、旧址空气墙 | 模型已在 (-34,70)，SPOTS/部分树木避让/额外 BLOCKER 仍用 (-35.5,66) | TownData.Home 成为共用数据，入口、碰撞、植被与门前路灯净空一起推导 |
| 教学楼/实验楼门口提示偏移 | 交互点没算门厅 EntranceExtra | BuildingDef.Door/FrontNormal 与 SPOTS、校验器统一 |
| 门牌隔墙可见 | TextSign shader 源丢失，回退字体材质没有正常遮挡 | 恢复 Resources/Shaders/TextSign，沿用原 shader GUID 修复占位材质引用，启用 ZTest/裁切深度 |
| 雨天旧属性警告 | 天气仍读写 Standard 的 Glossiness | 按实际 shader 选 SpecularStrength 或 Glossiness |
| 薄板浮边、远处灰描边 | 薄片也画外扩壳；远处把轮廓涂成灰色且没有正常雾化 | 薄片关闭壳与边缘光；轮廓随距离收细、应用雾，并按屏幕比例校正宽度 |
| 路口两套砖纹叠加 | 纵横道路的面片重叠 | 纵向道路在交叉口裁开，交叉位置由横向路面连续覆盖 |
| 夜间窗片像悬浮黄色方块 | 窗片还按旧版 256 像素格定位，当前墙面贴图已改成 128 像素格 | 窗户绘制与亮窗 UV 共用同一个矩形定义，四片亮玻璃避开窗框，亮灯选择使用稳定字符哈希 |
| 脚陷进门前石阶 | 台阶几何与 GroundY 脱节 | 台阶、门前砂石与人行道按可见最高表面取落脚高度 |
| 室内入口近景被灯具填满 | 入口镜头靠墙收近后钻到没有相机碰撞的门灯前 | 通用门灯增加相机碰撞；角色按家具碰撞寻找更靠室内的安全落点 |
| 镜头越过吊顶导致入口白屏 | 天花板只有可见网格，没有相机碰撞 | 共用 CeilingSlab 增加相机碰撞；验收额外断言机位在房间边界与吊顶以内 |

## 进出门与相机

- 只有实际门外正面的区域可触发入口，避免隔侧墙按 F 入内。
- 进门朝房间内部；出门人物朝向街道，恢复原室外镜头距离、俯角与方向，并寻找门外无碰撞落点。
- 进出增加约 0.36 秒遮挡过渡，使用真实时间，不受游戏内时间暂停影响；过渡期间锁移动和切人，防止重复触发。
- 镜头轨道改为围绕视线目标计算高度，探测与实际机位使用相同高度。常规跟随与切房吸附共用避障函数，球形探测替代单条射线；第一人称也在切房时立即放到正确位置。
- 室内仍使用现有独立坐标房间；本轮统一其出入口行为，保留现有室内平面与家具布局。

## 实机查看路线

启动停在主角家门前：按 F 进门，观察朝向、门灯与相机；走回门边按 F 出门，检查门槛与落点。按 M 传送教学楼、实验楼、图书馆和商铺区，靠近实际大门按 F；V 可切第一人称检查门牌与墙面；T 可切昼夜，Y 切天气。
