## 一、参考（联网后采用的结论）

- 圆形广场做法：圆心放视觉焦点（喷泉/雕塑/大树），中环用树阵或矮景墙半围合，外缘通过台阶/
  坡道/铺装过渡与周边道路衔接；广场铺装与道路交接处必须专门处理，否则会出现"直边切断圆盘"的
  生硬效果。
  - 百度百科「圆形广场」：<https://baike.baidu.com/item/%E5%9C%86%E5%BD%A2%E5%B9%BF%E5%9C%BA/0>
  - 《园林景观铺装形式和材料的设计及应用》：<https://wk.baidu.com/view/b1c7426b336c1eb91a375ddb>
- 环岛俯视参考（圆盘完整、道路贴环不切入圆心）：
  <http://lgpic.3d66.com/linggantuRes/linggantu/b8b6/fd296612964d73ddcc01aa6207fa3db1.jpeg>
- 喷泉地标参考：纽约中央公园 Bethesda Fountain（大水盘 + 中央台座 + 雕塑主景）；
  以及莲花/花瓣式喷泉雕塑（国内酒店景观案例）。
- 樱花林参考：北京北小河公园樱花谷（入口广场留白 + 花瓣铺装 + 绿化组团）、
  合肥园博园 Blooming Garden（之字路 + 高低两层空间 + 花田/花池），采用"中央巨樱 + 环形林下
  花带 + 汀步"的孤植构图。

## 二、钟楼广场接壤修复（本轮核心）

### 问题定位

- 原圆盘：圆心 `(-15,-12)`、半径 `11`。主街在 `x=0`、宽 `11`，西侧还有 0.18m 路缘 + 1.3m
  抬高人行道，人行道外缘在 `x≈-6.98`。圆盘东缘到 `x=-4`，**压进人行道约 3m**；圆盘比路面高
  3cm，但人行道高 12cm，于是人行道以一条直边把圆盘切掉。南侧校道（`z=-23.5`，宽 3m）也被圆盘
  南缘（`z=-23`）压住约 1m。
- 证据截图：`shots/68k-clock-overlap.png`（修复前，左侧直边切断圆盘）。

  - 东缘 `x=-7`，正好贴人行道外缘，不再压车道/人行道；
  - 南缘 `z=-22`，与校道北缘 `z=-22` 相切，不再压路。
- 钟楼同步移到 `(-17,-12)`，保持塔在圆心；keep 区、交互点、出生点、小地图传送点、广场两盏
  路灯全部跟着改：
  - `TownData.cs:164` 广场与钟楼、`:228` keep、`:682` 广场路灯、`:751` 交互点
  - `WorldBuilder.cs:839` 出生点、`Minimap.cs:232` 传送点
- 同心圆铺装逻辑不变（外圈石带 + 4.9/6.6m 石环 + 8 条放射线），半径 10 下放射带长度 2.1m，
  仍成立。
- 证据截图：`shots/68l-clock-overlap-fixed.png`（修复后俯视，圆盘完整、贴人行道但不被切）、
  `shots/68l-clock-wide.png`（玩家视角，F 提示正常）。

## 三、公园喷泉地标

- 位置：池塘中心 `(34,-40)`，三层石盘喷泉 + 水池/水柱/水盘落水串。
- 地标选型过程：
  1. 展翅仙鹤（两次）：近看可辨，远看/侧看只剩几条黑翼板，像风车，放弃；
  2. 最终采用**「樱之冠」五瓣樱花雕塑**：石柱托起 5 片带缺刻的花瓣（3 段盒体拼成），中心金色
     花蕊 + 7 根金蕊，花瓣用带自发光（0.30）的樱花材质，保证从地面仰视时底面仍是粉色；
     雕塑高约 8m，周围有粉色花瓣粒子缓缓飘落。
- 代码：`WorldBuilder.cs:2464 Fountain()`、`:2510 FountainPetals()`。
- 截图为证：`shots/68k-fountain-top.png`（俯视，五瓣+缺刻清晰、水面有花影）、
  `shots/68j-fountain-north.png` / `-south.png`（地面视角）。
