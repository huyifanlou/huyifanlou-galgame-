# 82 · 校验口径修正 + 四间商铺室内 + 全量室内虚影审计

本轮三件事：① 把校验器改成真正校验**当前世界**并修掉规则自身的错误；② 新增 4 栋商铺室内；③ 逐个检查所有室内的虚影与牌子朝向。

## 一、校验器口径修正（重要）

**发现的问题**：`WorldValidator.RunBatch`（菜单「校验世界布点」）校验的是 `CampusData` —— 旧校园专用数据集（12 栋建筑），而游戏默认构建的是 `TownData`（46 栋）。也就是说 docs/77~81 里写的「零违规」验的不是玩家实际玩到的世界。

**改动**：

| 项 | 改法 |
| --- | --- |
| 校验对象 | `Run()/RunBatch()` → `TownData.Build()`；旧数据集保留在 `RunCampus()` |
| 建筑占地 | 全部改用 `HalfWX/HalfWZ`（`ValidateTown` 与 `Validate` 都改），朝 ±X 的建筑不再算错 90° |
| 门前走廊 | 新增 `DoorOf()/DoorCorr()`：按 `face` 求正门点与外法向，「围栏阻断门前」「路灯挡门」不再只对 ±1 有效 |
| 可达性 | 门口 1.5m 内有步道（plaza 条带，含斜向）即算连通；公园/神社/看台属开放地面，显式豁免 |
| 池塘 | 由矩形改椭圆判定（`HitsPond`，rx=r+0.6、rz=0.7(r+0.6)），否则东西两侧草坪被误判成水面 |
| 主角家 | 院落矩形只向正门一侧扩 2.3m（前院木篱在 d/2+3），背面不再虚扩 4.6m 误判邻街铺面 |
| 建筑间距 | 校园栋距 ≥5m；小镇沿街骑楼是连排，只要求 ≥0.5m |
| 设计性重叠 | 显式豁免并注明理由：步行街上摆市集摊位、提灯串/幡架空、手水舍敞亭下的净手盘/绘马架/长凳、旗杆在看台升旗台上、圆形广场/停车场内的设施 |
| 报错去重 | 沿路径 1m 采样会重复报同一条，`Err()` 去重 |

**结果**：`RunBatch` 与 `TownBatch` 均 **零违规**（此前分别报 183 / 60 处）。
