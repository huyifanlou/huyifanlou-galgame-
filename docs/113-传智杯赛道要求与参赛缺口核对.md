## 官网确认的要求

- 赛项：AI创新应用挑战赛，个人赛；列有“智能游戏原型与交互式叙事工坊”方向，技术栈不强制限定。
- 报名与作品提交段落写明截止 2026-11-18，未给出具体时刻。
- 仓库：GitHub/Gitee，公开或给予评审访问权限；完整、细粒度 Git 历史，不能一次性 initial commit 包含全部功能。
- AI过程：导出对话，不支持导出则截图/录屏；至少三个核心功能迭代的完整 Prompt 链，包括提问、AI建议、引导修复过程。
- README：10分钟复现指南，含完整环境说明、依赖清单、环境变量模板。
- 视频：5～8分钟，MP4、1080p；其中至少2分钟展示 AI 协同过程复现，不能全部只是游戏功能展示。
- 技术文档：PDF，不超过30页，重点讲意图控制、架构约束、可复现性论证。
- 评分：过程可复现与演进25%，解题有效性/实用价值25%，方法创新/意图控制20%，工程架构15%，用户体验15%。
- 学籍和组别需符合规定；报名、缴费及提交入口需本人登录个人中心核实。

公开页存在混排/矛盾：同页又称11月18日为“作品指导提交”，预计2027年1月底反馈、之后另发省赛提交链接，国赛却写2026年12月；推荐方向表也有标题和描述错位。奖项比例也有不同口径。准备工作按11月18日安排，最终提交批次、入口、具体时刻以个人中心及组委会最新通知核实，不能据此假定延期。

## 从代码确认的功能状态

- `ScenarioData.cs` 有8章加载和BGM/sfx字段；`DialogueManager.cs` 负责线性播放。全脚本检索未找到实际 AudioSource/AudioClip 播放实现，音乐/音效标签不等于声音已落地。
- 未检出剧情持久化的 PlayerPrefs、persistentDataPath 或 SaveGame/LoadGame；GameState的“存档数据”仍标注后续接文件，且没有接进当前世界启动流程。
- LineType只有 Dialogue/Narration/Thought/Direction/Card，没有选项/分支执行类型；C菜单是换玩家模型，不是NPC互动。
- 第一卷末尾 Advance 将 `_ci` 增至章节数后关闭；再次B打开会调用SeedSlots，以该索引访问章节，存在越界风险。这是静态代码发现，尚未在本轮跑通全卷复现，应优先补结尾状态、重新开始与回主界面验收。
- 最小建议：进入一个地点→遇到角色→读一段剧情→选择或收集一条线索→返回探索→存档退出→读档恢复→清楚的试玩结束页。选项、线索、存档和音频是针对游戏体验的建议，不是官网逐项硬性功能要求。
