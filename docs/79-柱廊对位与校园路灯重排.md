# 79 · 柱廊对位、教学楼门前浮空与校园路灯重排

接 docs/78 的第二轮现场反馈：**踏步左右超出、柱廊与门位置不对等、教学楼门前浮空、学校区域路灯需要重新布局**。

## 一、踏步与柱廊对位

`WorldBuilder.Portico()`：

- 三级踏步原来比柱廊平台宽 1.3–1.8m，左右各凸出约 0.7–0.9m；现改为
  `porticoW − 0.4 + i × 0.2`（图书馆 7.6/7.8/8.0m，礼堂 10.6/10.8/11.0m），
  与平台同宽或略窄，不再出头。
- 台阶高度维持“贴平台一级最高、向外逐级降低”（0.48 / 0.35 / 0.22m）。

`GroundY()` 的可走台阶宽度同步收窄到平台半宽，避免站在台阶外侧也被抬高。

## 二、门与台面齐平

图书馆/礼堂的门原来按地面高度开（门底 0.03m），而柱廊台面高 0.45m——门的下一截埋在台面里，看起来“门和柱廊不在一个高度”。

现在：

- `porchLift = 0.45f`（仅 library / hall）；门面与门灯整体抬高 0.45m，门底 0.48m，与台面平齐；
- 这两类建筑不再生成门口地面石阶（原本就被台面遮住）；
- 台阶、平台、门、柱列仍在同一中轴（x=0），截图里已对齐。

## 三、教学楼门前浮空

两处：

1. **雨棚前立柱**：`CollegiateFront()` 的两根前柱原来从 y=0.55m 起，悬空 0.55m；改为 `baseY+1.72、高 3.44m`，柱底落地。
2. **入口石阶与铺装断开**：教学楼的门口石阶在 z≈−79.0，而南北步道只铺到 z=−78，石阶像一块孤岛。步道改为 `PL2(−68,−79.5 → −68,−48.2)`，两端分别接到教学楼门斗和实验楼玻璃门厅，石阶落在铺装上。

## 四、校园路灯重排

原 18 盏中有一批立在步道、校门广场铺装、图书馆柱廊台面上，转角灯还顶着侧门。现改为 **20 盏**，统一规则：

- 全部退到铺装外 1–2m 的草边（校门广场两盏放在广场南北草边，不在铺装上）；
- 灯臂朝向所照的步道/广场；
- 成对布置在主入口与主轴上，篮球场、跑道、生活街、活动中心各成一组；
- 不再有灯立在柱廊台面、步道正中或紧贴建筑门口。
