## 三、入库处理

1. **盖水印**：检测右下黑框（暗像素 `max<120`，区域 `x>0.62w, y>0.80h`）取 bbox 外扩 6px 填背景色。
   ⚠ 第一版区域放宽到 `x>0.55w, y>0.70h` 会把深色裤腿并进 bbox、误擦腿；收紧后框为 (1351,1741)-(1945,1945)，与人物不重叠。
2. **裁切补白**：按人物 bbox（与背景差 >14）外扩 3% 裁切，缩放到高 1536、居中补白到 **1024×1536**（与其余四张同规格），覆盖
   `Portraits/fanlou-dialogue.jpg`、`Portraits/jingnan-dialogue.jpg`（同名覆盖，GUID 不变）。
3. **重抠**：`python tools/matte-portraits.py`。景楠这张背景是 242 灰白、低于默认阈值 240 导致整张没抠掉（kept 84.1%），
   按现成逐张阈值机制加 `OVERRIDE["jingnan"]=234` → kept 25.6%（樊楼 21.2%）。透明版目视无破洞（鞋/白T/拇指完好）。

## 四、浏览器自动化踩坑（本轮新增）

- 内置 Browser 面板不可见时指针操作报 `NATIVE_BROWSER_VIEWPORT_UNAVAILABLE`；`navigate_page`/`evaluate_script`/`take_snapshot` 仍可用。需作者手动打开面板并登录。
- Slate 提示词框：fiber 上溯拿 live editor 后 **`selection` 为 null 时 `insertText` 静默 no-op**；先设 `selection={anchor,focus}` 再插入、`onChange()`，下一拍 send 才亮。
- 发送后 composer 重建：**file input 节点被替换**，旧快照 uid 上传会落空；滚到底还会出现**第二个（底部）输入框**，顶部 input 随之失效。`upload_file` 必须紧跟新快照。
- 「做同款」只在刚生成完的结果视图渲染，且回填提示词＋参考图；历史列表里不出现。
- OSS 结果图签名**包含 `x-oss-process`**，删缩放参数即 `SignatureDoesNotMatch`；全分辨率地址要点开大图后取 `naturalWidth>1000` 的那个 img（异步加载，需等 ~1.5s）。
- 结果卡是虚拟列表，滚出视口就不在 DOM；`evaluate_script` 的 Promise 超过 15s 会被工具掐断，轮询要拆短。
