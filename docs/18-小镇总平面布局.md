## 五、近代风格要点（落地时按这个做材质/造型）

- **砖石**：青砖、红砖、灰石三种基本墙面；拱形窗/拱廊（比现有方窗更"近代"）
- **屋顶**：灰瓦坡顶为主，工厂为锯齿顶 + 烟囱，教堂尖塔
- **铁艺**：站台雨棚、桥栏杆、路灯用铁艺细杆 + 球形灯罩（替换现有方灯头）
- **街具**：煤气灯式路灯、木电线杆 + 电线、石板人行道、雨棚招牌
- **配色**：砖红 / 青灰 / 米白 / 深木，整体比现在更沉稳（配合 docs/15 的照明预设）

## 六、与现有工程的关系

- 这是**全新布局**：现有 `CampusData` 的道路/建筑坐标不再适用，学校区相当于把现有 12 栋建筑"搬"进新网格
- 建议分四期实施：
  1. **地形与水系**：地形/河床/两岸驳岸 + 三座桥（几何 + 碰撞）
  2. **道路网**：主轴/生活街/河滨路/小巷 + 铺装
  3. **地标建筑**：钟楼、车站、教堂、纱厂（新增程序化立面；骑楼拱廊用新的拱形窗格）
  4. **街区与软景**：学校区搬迁、住宅排、树木/芦苇/码头/街具 + 天气联动
- 校验器需要新增：河道与桥的通行校验、拱桥坡度、街区退距

## 七、等你确认 / 修改的点

1. **学校要不要保留**？现在按"小镇里的学校区"处理（北岸西北角）；也可以把学校挪到南岸或缩小
2. **风格细分**：偏江南水乡（白墙黛瓦、石拱桥多）还是民国通商口岸（红砖洋楼、车站、教堂）？我按后者排的
