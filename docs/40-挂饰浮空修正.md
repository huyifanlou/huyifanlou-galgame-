# 40 · 挂饰浮空收尾：玄关镜 / 教室侧墙绿板 / 门楣门牌 / 公告栏

作者反馈（2026-10-26 晚）：

> 教室有浮空挂画，家里也有浮空物

四个物体，四种不同的"悬空"原因。定位方式都是先开第一人称到现场拍图，
再回到 `InteriorBuilder.cs` 对照坐标。

## 一、家里：玄关镜悬在半空

```csharp
// 旧
Part(p, new Vector3(ox + 3.62f, 1.0f, -6.8f), new Vector3(0.06f, 1.4f, 0.8f), C("#b8c6cc"), 1f);
```

单层开放布局重建时拆掉了玄关隔墙，镜子却没跟着搬——留在走道中间，
镜面中心 y=1.0、高 1.4，**底边离地 30cm**，背后空无一物。

修法：挪到北墙鞋柜台面上方，加木框、贴墙安装。

- 木框：`(ox+2.9, 1.95, -9.82)`，1.0×1.5×0.04
- 镜面：`(ox+2.9, 1.95, -9.78)`，0.86×1.36×0.03
- 鞋柜台面高 1.1，镜底 y=1.2，留 10cm 空隙

北墙墙纸中心 `z=-9.86`、外表面 `-9.835`；木框背面 `-9.84` 嵌入墙纸 5mm，
正面凸出 3.5cm，不会共面闪。

## 二、教室：侧墙绿板 + 墙裙整片悬空

`Classroom()` 里贴侧墙的东西用的是：

```csharp
float sx1 = cx - w * 0.5f + 0.05f, sx2 = cx + w * 0.5f - 0.05f;
```

但 **`cx ± w/2` 是课桌网格宽度，不是墙面**。四间教室的墙位各不相同：

| 教室 | 网格边到真实墙纸面 |
|---|---|
| A（西） | 约 0.36 m |
| B（中） | 约 0.31 m |
| C（东中） | 约 0.09 m |
| D（大间，东侧） | 侧墙裙最远差了约 0.6 m |

于是侧墙那块 4.2×1.3 的绿色挂板、1.1m 高的墙裙，全都吊在离墙几十厘米的空中。
远看就是"浮空挂画"。

修法：`Classroom()` 增加 `westFaceX / eastFaceX` 两个参数，由调用方传入**真实墙纸面**
（外墙 `±27.86`，教室隔墙中心 `∓0.11`），贴面中心放在墙纸外 5.5cm 处，
板厚 5cm → 内表面离墙 3cm，既不埋进墙纸也不悬空。
四间教室的调用同步更新。

黑板、讲台、课桌布局没动——只换贴墙面的定位基准，不动 `cx/w`。

## 三、教室门牌悬空：门洞没有门楣

走廊北墙是**分五段**建的（为了留四个 2m 门洞），每段都从地面通到 4.2m，
门洞上方根本没有墙。上一轮把门牌从 `y=2.75` 挪到"门上方"，但那里是空的。

修法：给四个门洞补视觉门楣，从 2.5m 到顶 `W`，并贴墙纸：

```csharp
Part(..., new Vector3(db - da, W - 2.5f, WALL_OUT), wall, 1.7f);
WallDeco(..., ZC0 + 0.11f, 2.5f, W, ...);
```

门牌改挂在门楣表面 `ZC0 + 0.17`。

> 门楣**没有加碰撞盒**：室内碰撞是纯 2D AABB、不看高度，加了会把门整个堵死。

## 四、公告栏悬空：上一轮文档说改了、代码没改

## 六、教训

1. **贴墙物的坐标基准必须是真实墙面**，不是家具/课桌网格的包围盒边。
   建房间时把 `westFaceX/eastFaceX` 显式传进去，比事后目测可靠。
2. **门洞上方没有墙时，门牌、指示牌一定会浮空** → 先补视觉门楣（不加碰撞）。
3. **文档/提交信息与代码不一致** 比没写文档更糟。写"已改"之前先 `git diff` 确认。
