# 81 · 钟面虚影修复

作者反馈“学校钟上的虚影”。排查到两处：

## 一、教学楼钟面与底座共面（z-fighting）

`WorldBuilder.CollegiateFront()` 里钟面 Face 的 z 是 `front + bayD + 0.07`，而背后 2.4×2.4 的底座前脸正好也在 `+0.07`——两个面完全共面，深度测试互相打架，钟面出现闪烁/重影。

- 底座前脸：`front + bayD + 0.02`，厚 0.1 ⇒ 前脸 `+0.07`；
- 钟面前移到 `front + bayD + 0.09`（前移 2cm）；
- 钟楼四面钟面由 ±1.66 前移到 ±1.70、图书馆钟亭由 1.37 前移到 1.39，留出安全距离。

## 二、钟面贴图是整块不透明奶油底

`TextureLibrary.ClockFace()` 原来先铺满 192×192 的奶油色，再画圆盘。钟楼和图书馆钟亭上看到的是**一个方形浅色底板套着圆钟**，远看像虚影。

- 去掉整块底色，只画圆形表盘（圆盘外 alpha=0）；
- 钟面材质统一改走 **Cutout**（`ClockMat()`：Standard `_ALPHATEST_ON`，cutoff 0.4）；
- 现在钟楼的圆钟直接贴在石塔上，教学楼圆钟贴在深棕底座上，图书馆钟亭同理，都没有方形“虚影”。

## 三、验证

- 构建：`[Bootstrap] 构建 StandaloneWindows64：Succeeded`。
- 截图：
  - `shots/81-tower-clock-round.png` —— 钟楼圆钟，方形底板消失；
  - `shots/81-teach-clock-round.png` —— 教学楼钟面，圆钟贴在棕色底座上，无重影。

## 四、备注

- 钟面贴图是程序化生成，改表盘样式只需改 `ClockFace()`；材质裁切由 `MatLib.CutoutTexture` 负责。
- 圆盘外的边缘是像素硬边（Point 采样），与整体像素风一致；如果想要平滑圆边可把采样改成 Bilinear。
