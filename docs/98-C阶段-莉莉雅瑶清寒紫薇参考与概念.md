- 交互踩坑（浏览器自动化）：
  - 参考图：先**点「图片」按钮**才会把 `input[type=file]` 配成 `accept=.jpeg,.jpg,.png,.bmp,.webp`，再 `upload_file` 才注册（直接对未点开的 input 上传无效）。
