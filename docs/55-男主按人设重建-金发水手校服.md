## 四、男版水手校服（A 版）

白衬衫 + 藏青海军领 + 红领巾 + 藏青长裤 + 黑鞋。为丰富细节加了：

- **海军领**：后披肩 8×4.2 + 两道白条；前 V 领两条斜领带 + 白边；肩部整圈藏青领圈；

- **袖口**：白袖 + 藏青袖口 + 一道白条；
- **腰部**：藏青腰带 + 银扣；
- **裤子**：藏青长裤 + 外侧裤缝 + 前裤线；
- **鞋**：黑鞋 + 灰银鞋带 + 黑鞋底；
- 背部：领披白条、后中缝。

## 五、金色短发（3D）

- 发色：`#ddb04f` / 高光 `#efd58e` / 暗部 `#c99a3e`，自发光 0.08；
- 结构：锥形发盖 + 前后错层发顶 + 额前发际碎发（只在发际线以上，不压脸）
  + 每侧三束尖尾侧发 + 短鬓角 + 锥形后脑整发 + 三束后颈尖尾；
- **不再用整排等长后发束**：上一版 7 束等长发束从背后看像羽毛冠/木箱，
  改成整块后发 + 3 束短尖尾，轮廓有层次但不成排；
- 侧发收窄到 0.9~1.1px，避免正面看成「金色翅膀」；
- 无猫耳。

## 八、教训

- 64×64 脸上嘴宽 6px 即可；2 格（16px）会读成张嘴或口红；
- 白衬衫在背光场景会压成灰绿，需要低自发光（约 0.26）才读得出白色；
- 领巾飘带必须比领口白条窄，否则白条被完全盖住；
- 整排等长发束从背后看像羽毛冠/木箱：用整块后发 + 少量短尖尾打散；
- 侧发过宽会在正面形成「金色翅膀」，男式短发侧面收在 1px 左右；
- 先出皮肤图再动 Unity，能避免在 3D 里反复试错。
