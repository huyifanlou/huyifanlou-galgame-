# 65 · 树冠与灌木改回方块造型

> **已回退（2026-10-28）**：作者认为这一系列改动效果不好，代码已恢复到 docs/62 状态；本文仅作历史记录，见 [66-回退远山与林带优化](66-回退远山与林带优化.md)。

作者（2026-10-28，docs/64 之后）：

> 不要冠状，给我改回方块状，灌木也是方块状

docs/64 把林带/远山做成了圆冠、伞冠、椭圆冠，作者要的是**统一的方块造型**：
树冠、灌木、松树都必须是盒子，和镇内原来的方块树一致。

## 一、改法

### 1. 新增方块批处理（`MeshFactory.BoxMeshBuilder`）

树量 1/4 后仍有上千棵，不能一棵树几个 GameObject。新增批量箱体构建器：

- 每个面 4 个独立顶点（`RecalculateNormals` 得硬边，正是方块造型要的）；
- UV 按 `面尺寸 / TexScale` 写进网格，**贴图密度与方块大小无关**；
- 一次 `Build()` 出一个 Mesh，同树种/同色共 1 个 draw call；
- `BoxUV(size, texU, texV)` 改为调用它，行为不变。

### 2. 林带七树种全部方块化（`ForestBelt`）

| 树种 | 方块形态 |
| --- | --- |
| 松 | 树干 + 三层递减方块塔（0.66/0.48/0.30h 宽） |
| 阔叶 | 主方块 + 两块错位小方块 |
| 杉 | 窄高三层方块塔 |
| 樱 | 宽扁方块 + 低侧块 |
| 细高落叶 | 竖长方块 + 顶块 |
| 伞松 | 高干 + 三层宽板方块 |
| 秋色 | 主方块 + 两块错位小方块 |

- 绿篱改为 4~5 个**方块叶团**，每团独立偏角、宽高、`FootMinH` 贴坡；
- 冠块不再旋转（轴对齐），贴图 UV 世界尺度铺叶簇。

### 3. 远山方块林（`MountainDetail`）

- 贴坡小灌丛：双块丛 / 竖块灌 / 压扁单块，全部方块；
- 主林毯：方块松（两层方块塔，有干/无干两版）、伞状方块冠（20%）、竖方块、方块云团（主块 + 侧块）；
- 乔木仍有树干，冠块抬到树干上；
- **落地采样半径扩到覆盖方块边缘**（方块灌 `rad×1.2`、绿篱 `rj×1.4`、方块松 `cw×1.15`），下坡侧不露空。

### 4. 镇内树（`Tree`）

- 0~5 常规树恢复三层方块冠（暗底/主色/亮顶）；
- 8 大树、9 柳树、10 桃花恢复方块冠；
- 6 松 / 7 柏 由锥体改为**方块塔**（松三层、柏三层窄塔）；
- 删除 `LeafCone`。

### 5. 室内盆栽（`InteriorBuilder.Plant`）

圆冠换成两层方块叶团（0.62m / 0.40m），与室外方块树一致。

### 6. 删除圆冠网格

`MeshFactory.Canopy` 已无任何引用，整段删除，防止后续再混入圆冠。

## 二、验证

```bash
Campus.exe -px -80 -pz 27 -at -200,27 -fp 1 -pitch 0.02 -shot shots/65-hill-80.png
Campus.exe -px -100 -pz 27 -at -262,55 -fp 1 -pitch 0.16 -shot shots/65-peak-day.png
Campus.exe -px 55 -pz 10 -at 240,10 -fp 1 -pitch 0.10 -shot shots/65-east-ridge.png
Campus.exe -px 8 -pz 20 -at 80,-20 -fp 1 -pitch 0.08 -shot shots/65-town-trees.png
```

- 林带、远山、镇内树、室内盆栽全部为方块造型；松树也是方块塔；
- 坡面方块按足迹最低地面落位并下沉，截图中无浮空；
- `-fps 1`：渲染器 4206 / 顶点 8.858M / 灯光 107
  （圆冠版 4175 / 9.419M；方块顶点更少。渲染器 +31 来自室内盆栽由 2 件变 3 件）。

## 三、取舍

- 方块树冠按轴对齐，不做随机旋转，轮廓重复感靠“树种比例 + 大小/错位”打散；
- 远山部分方块冠较大（7~9m），远看是粗颗粒方块林；若嫌块太大，可把 `rad` 上限从 7.2 降到 5.5；
- 背光面（河东 8:00）方块侧面偏暗，叶材质 6% 自发光保持不变。
