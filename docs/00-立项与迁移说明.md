# 00 · 立项与引擎迁移说明（2026-10-15）

## 背景

作者反馈：「现在做的还是太简陋了，我需要加引擎进行优化」，随后明确：
**新开一个工作区做新引擎做出的游戏，命名为「Unity开发galgame」。**

## 决策

### 1. 引擎：Unity（中国区可获取的最新 LTS 中国版 2022.3.62f3c1）

实测（2026-10-15，本机网络）：

- 国际版编辑器所有 6000.x 版本在 `download.unitychina.cn` 镜像上均 404（中国 IP 被导向该镜像，而镜像只提供「中国版」c1 构建）。
- 镜像上可获取的最新版为 **2022.3.62f3c1**（Unity 2022.3 LTS 中国版）：编辑器 3.76GB + WebGL 模块 588MB，均可直接下载。
- 结论：使用 Unity 2022.3.62f3c1 中国版。功能上具备本游戏需要的全部能力（URP 后处理：Bloom/暗角/色彩分级/ACES、级联阴影、WebGL 导出、中文界面）。

备选保留：Godot 4.7.2（已下载便携版至 `D:\AI\Godot`，可作后备方案，无需账号即可运行）。

### 2. Web 版处置：冻结、不删除

`chuanzhibei-game` 仓库打 tag `web-v1.0-frozen-20261015`（v0.40 / 88 提交）作为：

1. 历史作品与「AI 协同开发」全程留痕的一部分；
2. 本工作区的资产配方与视觉基准来源（导出的 PNG 即来自它）。

### 3. 迁移策略：同配方重建，不是从零重画

| 来源（web 版 v0.40） | 去向（本工作区） |
| --- | --- |
| `src/game/textures.js`（程序化像素贴图） | `tools/export-assets.mjs` 一次性导出 `assets/tex/*.png`（固定种子 20261015，画稿自此冻结、可复现） |
| `src/game/campus.js`（世界数值） | `assets/world.json`（同一份数值：4 栋建筑 / 26 栋远景 / 90+ 边界树 / 路灯 / 交互点……） |
| `src/game/CampusScene.jsx`（场景配方：几何尺寸、材质密度、昼夜参数、相机与移动手感） | `Game/Assets/Scripts/*.cs` 逐条对位（WorldBuilder / TimeOfDay / PlayerRig / Hud / ShotMode） |

### 4. 验收管线

沿用 web 版的截图验收思路：Unity 版内置 ShotMode，命令行参数
`-shot <png> -time <h> -px/-pz <pos> -at <x,z> -freeze 1` 跑出确定性截图 → 对比验收。
