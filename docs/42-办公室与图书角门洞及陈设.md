## 一、南带两扇门 1.2m → 2.0m

办公室（x 7.5~16.5）与图书角（x 16.5~28）都从 z=2.5 的走廊南墙进出，
原来门洞只有 **1.2m**，且通到 4.2m 顶；在 5m 走廊里远看就是两个墙洞。

门中心不动，向两侧各扩 0.4m：

| 房间 | 门中心（相对学校中心） | 原门洞 | 新门洞 |
|---|---|---|---|
| 办公室 | +13.0 | +12.4 ~ +13.6 | **+12.0 ~ +14.0** |
| 图书角 | +21.6 | +21.0 ~ +22.2 | **+20.6 ~ +22.6** |

同时补齐门的「可读性」：

1. **门楣**：2.5m 以上补墙到顶（厚 0.24m）。只做视觉，**不加碰撞盒**——
   室内是自写 2D AABB、不看高度，加了会把整扇门堵死。
2. **门套**：两侧 0.14×2.5m 立梃 + 顶部横梁，深木色 `#7a6248`。
3. **门牌**：1.20×0.36m 深绿底板 + 0.98×0.24m 白芯 + 文字「办公室」「图书角」。
4. 墙纸 / 墙裙 / 踢脚线的洞口同步更新；房间内侧补上墙纸。

顺手修掉一个老问题：走廊南墙墙纸偏移是 **0.09m**，而墙厚 0.24m、墙皮厚 0.05m，
墙皮整个埋在墙里 5mm，这面墙一直是素墙。改回 **0.11m**（外露 15mm），
办公室 / 图书角内侧也按同样厚度补了墙纸。

## 四、门牌穿墙修复

Legacy `GUI/Text Shader` 是 **ZTest Always**：站在图书角里能看到门牌文字
穿墙透出来，而且是镜像的（看到的是字的背面）。

新增 `Game/Assets/Resources/Shaders/TextSign.shader`：

- Queue = AlphaTest，`ZWrite On`，`ZTest LEqual`；
- 字体图集 alpha 裁切（cutoff 0.42），顶点色 × 材质色，不参与光照；
- 放在 `Resources/` 下用 `Resources.Load<Shader>("Shaders/TextSign")` 取，
  避免运行时 `Shader.Find` 被构建剥离（同 docs 里 2026-10-19 的教训）。

动态字体新增字形时会重建图集，材质贴图由 `SignAtlasSync` 每帧比对并同步。
从图书角内看向门（`shots/43-sign-inside.png`）已看不到镜像文字。

## 六、教训

- 世界空间门牌不能用 TextMesh 默认的字体材质：它是 `ZTest Always`，必然穿墙，且背面文字是镜像。
- 自定义着色器要么放 `Resources/` 用 `Resources.Load`，要么进 Always Included Shaders；
  只 `Shader.Find` 会被构建剥离。
- 0.05m 厚墙皮贴在 0.24m 厚墙上，0.09m 偏移会整片埋进去 5mm（完全不可见）；
  安全值是 0.11m。墙面改完要两侧都检查。
- 大房间的家具必须落在「进门视线」上；没有书的空书架只会让房间更像杂物间。
- 门洞加宽后，门楣 / 门套 / 门牌是让人一眼看懂房间用途的最低配置；
  门楣只能做视觉，室内 AABB 不看高度。
