# 11 · 材质写实化 + 全场景像素密度审计（2026-10-17）

作者要求：**材质要更写实**；调整完再检查各处的像素密度是否一致（点名：花、土、树、操场等）。
本轮分四块做：光照 → 材质受光响应 → 贴图细节与树 → 全场景审计。

## 二、材质受光响应（MatLib）

按材质类型给光滑度（`SmoothnessOf`）：水面 **0.55**、石板路 0.13、铺装/石带 0.10、漆面门 0.16、
瓦面 0.20、木构 0.10、立面 0.05、树皮 0.04、草/土/花 0.02。灯杆等金属件改用 `MatLib.Metal`
（低金属度 + 0.34 光滑度，受光处出高光）。
**金属度一律保持 0**：本工程没有环境反射源（无天空盒/反射探针），高金属度会直接发黑。

## 四、树：从纯色块改为「叶簇 + 树皮」贴图

- 新增 **叶簇 `leaves`**（128px 覆盖 0.8m = **160px/米**，近白底 + 暗色叶隙 → 由材质 `color` 染色，保留三层双色调）
  与 **树皮 `bark`**（96px 覆盖 0.6m = 160px/米，竖向沟槽/裂纹/苔点，按树种染色）。
- `MeshFactory` 新增 **`BoxUV`**（世界尺度 UV 的立方体：六个面各自按「面尺寸 ÷ texMeters」平铺）与
  **`Cone` 的 UV 支持**（锥面按周长/高度展开）→ 树冠/树干**每一面**的像素密度都恒定，不随箱子尺寸变形。
  BoxUV 以已验证的 Quad/QuadZ 为模板逐面旋转（旋转保绕序，镜像面反转三角），避免绕序踩坑。
- 松/柏的锥形树冠、阔叶树的三层方块树冠、柳/桃花全部换用新材质。

## 五、全场景像素密度审计（新增，校验器每次运行都会打印）

**判定**：基准 160px/米，±6% 为「一致」；低于 150.4 记「偏低会糊」；横纵比 >1.15 记「横纵不等」。
（高于基准不算问题 —— 只会更清晰。）

## 六、结论与下一步

- **一致的**：全部贴地纹理（含花/土）、树冠/树干、门、招牌。
- **不一致的**：建筑立面（12 栋 + 侧翼 + 远景楼）—— 根因是立面贴图的「窗格单元」按正方形 256px 画，
  但它在世界里对应的格子是 1.67×1.25m（不方），于是横向/纵向密度差 ~1.75 倍；别墅同理（4:3 vs 1.56:1）。
  **修法 = 下一轮的「立面分块/重画」**：按每栋楼的 w/h/cols/rows 算出格子纵横比、把窗格改成世界方形，
  顺带冲 360px/米（撞 2048 就分块）。球场/操场/池塘同属「撞上限」，分块时一并处理。
- 人物 93px/米 是唯一低于基准但**有意保留**的（像素小人，作者要求不动）。
