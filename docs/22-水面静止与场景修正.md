# 22 · 水面静止、游乐场旋转修复与植被清理

作者反馈三件事：**水面换回静止**；**游乐场里建筑会带着另一个建筑动**；**很多植被分布不合理**（要求仔细检查几遍）。
本轮逐项处理。

## 一、水面改回静止

- `WaterSim.Animate = false`（默认）：不跑高度场模拟、水面网格为平面、`Current = 0`、细节贴图不滚动。
- 着色器保留：天光反射、太阳高光、岸边/桥墩静态泡沫仍在，只是完全静止。
- 浮力小船/漂木仍浮在水面上，但不再随波起伏或漂流（流场速度为 0）。
- 想恢复流动：把 `WaterSim.Animate` 设为 true（模拟、涌浪、雨滴扰动代码都还在）。

## 二、游乐场“建筑带着另一个建筑动”

根因：`Spin` 组件的默认轴是 `Vector3.right`（X 轴）。
- 旋转木马、旋转飞椅只设了 `DegPerSec`，没设轴 → 整组绕 **水平轴** 翻倒，带条纹棚顶旋转起来就像“一栋建筑拖着旁边的东西动”。
- 修复：两者都显式设为 `Axis = Vector3.up`；摩天轮保持 X 轴（轮面正确）。
- 顺带修了摩天轮吊舱：新增 `GondolaRing`，12 个吊舱随轮缘公转但保持正立（之前吊舱固定不动、轮缘从中间穿过）。

## 三、植被分布清理（三轮）

**第一轮：补保留区**
- 游乐场核心（x 8~94 / z 22~52）不放植被
- 6 间骑楼店铺的柱廊前（三条带）
- 神社前庭/鸟居/石阶
- 铁路道床（z=92 ± 3）
- 站前广场、三座桥面与引桥
- 夏日祭摊位底部

**第二轮：加大净距 + 保留区生效范围**
- 建筑净距：树 2.8m、灌木 4.2m、花 3.6m
- 公园里 8 棵点景树改为与其它树同一套检查（不再硬塞到池沿/步道上）
- 灌木/花不再沿建筑立面排成一线

**第三轮：成簇分布 + 更远净距**
- 灌木按 2–3 株一簇、花按 3–5 株一簇生成（避免均匀撒点）
- 灌木离建筑 ≥5.5m、花 ≥4.5m
- 门前绿篱由两块小方块改为沿立面加宽、贴墙的连续矮篱（中间留门洞）
- 校验日志（构建时）：`bushes=67 flowers=126 minBuildingDist=5.94 (k_haiden)`

检查方式：对住宅四排、老街柱廊、神社、游乐场、河岸各拍了近景与俯视，确认无植被压路/压桥/进水/挡门；
剩余“贴近墙根的绿色块”是门前绿篱（建筑构件），不是散布植被。
