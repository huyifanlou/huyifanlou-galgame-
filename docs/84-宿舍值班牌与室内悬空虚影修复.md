# 84 · 宿舍值班牌位置与奶茶店/宿舍虚影修复

作者实机反馈：**宿舍楼这里的牌子放置不正确**，**奶茶店、宿舍楼有虚影**（附图为宿舍门厅值班桌）。定位后是同一类毛病：**小件按"大概高度"摆放，没有真正落到支撑面上**，于是桌面/柜体旁边多出一层悬空薄板，看着就是虚影。

## 一、宿舍门厅值班桌（截图那一处）

| 件 | 原来 | 现在 |
| --- | --- | --- |
| 值班牌 | 1.1×0.30 的大牌，底边在 y=0.87，而桌面顶只有 0.78 → **悬空 9cm**，比例也像一块立在地上的招牌 | 0.8×0.24 的桌面牌，底边沉进台面 0.5cm（0.77~1.01）贴着桌面前缘，双面字 1.9cm 字高 |
| 牌子后面那块白板 | 0.9×0.30 的"纸"平放在 y=0.84~0.88，**离桌面 6cm 悬着**，从侧面看正好叠在牌子背后 → 作者看到的"虚影"就是它 | 换成 0.34×0.24 的登记本平放台面（底 + 页两层，落在 0.78 上），并挪到桌西段不挡牌 |
| 值班椅 | 在桌子西端朝东（等于坐在桌角侧面） | 移到桌子南侧朝北，正对来访者（`Chair` ry=0 人朝 +Z） |

## 二、奶茶店展示柜（虚影）

原来是「柜体 1.8×0.7×0.7」上面再套一个「Glass 盒 1.7×0.5×0.6」，两个盒子互相穿插；而 `Glass()` 是**不透明**浅蓝材质，商品放不进也看不见 → 远处看就是一个灰+白的双层块，边缘还错开，正是虚影。

改成小镇超市 `Cooler()` 的同款做法：**背板 + 顶底板 + 两侧板，前面留空**，里面摆两排甜点块。柜体坐在吧台台面（1.11）上、底框留 0.5cm 不共面。

## 三、吊灯发光面（同一类，全房间生效）

`Pendant` 的发光面板放在灯罩顶以上 1.5cm（`y + 0.13`），等于在罩子上又扣了一块白板——奶茶店、餐厅、图书馆、超市、礼堂的吊灯都有。改到灯罩**底面**并嵌入 1cm（`y - 0.115`），既符合"灯往下照"，也不再叠一层。

## 四、照相馆前台牌 / 图书馆借阅台牌（同类：两块牌叠成虚影）

截图核对时又发现同一类的"看起来像虚影"：**同一张桌上前后各立一块一模一样的牌**，从任何一侧看都能看到近处那块后面还露着远处那块的边 → 双重影像。

- 照相馆「前台接待」：原来南 5.99 / 北 6.81 各一块 1.1×0.30 的牌 → 改成**一块 0.8×0.24 立在桌面正中（z=6.4），两面各一次字**；顺带把原来立在桌子轮廓以外 2~9cm 的悬空问题一起去掉；
- 图书馆「借阅台」：两块牌 y=1.18、高 0.34，而柜台顶板只到 1.115 → 每块都高出台面 23cm，于是从一侧能同时看到两块牌的露头 → 改成贴柜台立面的**齐平铭牌**（y=0.87，顶到台面为止），并把朝书架那面的深色字改成浅色字（原来深绿底配近黑字，几乎读不出）。

## 五、同类排查

- 全 13 间室的 `Glass()` 用法逐个看过：除奶茶店展示柜是"盒套盒"，其余都是 0.02~0.05 的薄板贴在实体前面（冷柜门、化妆镜、防溅板、轻食柜门），不存在同类问题；
- 其余小桌牌：实验楼服务台牌嵌在柜台立面内、图书馆借阅台牌嵌在柜台立面（上下都进实体）→ 附着正确，未改；
- 共面检查：新摆的牌子/登记本与支撑面都留 0.5~1cm 嵌入，不做"正好贴合"，避免 docs/81 那类共面闪面。
