# 130 · 角色建模退役、固定第一人称与立绘立牌

2026-11-15。作者决定不再纠结角色建模：删除建模、强制第一人称、回归立绘对话，旧角色位置换成立绘立牌。本轮范围为玩家和 NPC 人物，建筑/家具/植被场景保留。

## 从工程移除角色三维系统

移出 Assets/Packages：全部 MMD 与 Characters 人物模型/动作/骨架/生成材质、脸部图集、Anime/MMD 播放与物理代码、三维生成编辑器、UMT 包及其依赖声明。旧生成代码从 PlayerAvatar 删除，CharacterDef 只保留六人 id/名字，PlayerAvatar 成为无 Renderer 的身份数据，用来兼容旧存档 avatar 字段。玩家自身和原假圆影均不再生成。

原件归档在 `tools/archive/retired-character-3d/`，在 Unity 工程外，当前构建不能加载，也不会被 Resources 带入游戏。旧 Windows 构建一并归档，从空目录重新构建，避免旧原生插件混进新包。未删除六张原始立绘及已抠图立绘，没有改剧本。

## 固定第一人称

启动、进出室内、传送、相机更新及旧档恢复均保持第一人称，旧存档 firstPerson=false 不生效，后续保存固定 true。删除 V 视角切换绑定；第一人称 FOV 62，眼高 1.45m。无玩家身体或手脚，无人物模型圆影。

鼠标直接环顾；Esc 释放鼠标且保持释放，点击非 HUD 区域后恢复环顾。剧情、地图、图鉴、设置与存档菜单继续释放鼠标、锁定移动，关闭后继续探索。

## 同位置立绘立牌

ProgressManager 在原有剧情角色 Anchor 放置 PortraitStandee，角色名对应既有 Portraits/{id}-cut，使用同一剧情互动与传送逻辑。每张立牌仅四顶点/两三角形，透明剪裁、写入深度与轮廓投影，竖直朝向相机；不生成可阻挡步行的碰撞体。预先读取 alpha 轮廓，裁掉图像透明留白，让底部贴地，避免图片边缘当成脚底。对应立绘有坐姿/半身时保留原画，不生成虚构身体。

玩家自身不在相机脚下放自己的立牌；原 NPC 身位替换立牌。剧情时继续使用原立绘/名字条/对白框。章节一个节点、章内连续、章末不自动弹目录的行为不变。

C 入口从“人物模型选择”改为“人物图鉴”，可查看六人的完整立绘，不再换玩家身体或改变剧情身份。设置文字同步说明固定第一人称。
