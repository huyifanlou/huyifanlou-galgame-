# 137 · 树木枝干、叶片重建与林带分区

2026-11-16。作者指出全图树木呈蘑菇状，要求提高精度或单独建模。

## 实现

原普通树由五个平底冠团叠成，樱花由椭球融合成整块闭合壳，远林另有球/锥体模板。新 `NaturalTree` 为阔叶、针叶、樱花分别生成枝叶结构，替换三处活动树木路径：

- 树干改分段弯折、逐段收细，有根部支撑、主枝、侧枝和末端小枝。
- 阔叶树使用折面叶片和立体叶簇，叶片有独立轮廓、中脊、不同朝向和明暗，不使用不透明树冠壳。
- 针叶树按高度减少枝长，叶片更细长，层间露出枝干；不再套多层锥帽。
- 樱花用五瓣花簇沿末端枝条分布，普通樱与巨樱同源；保留原粉色分型、巨樱位置、林道和落花。
- 叶簇手工指定柔化法线并提供正反面三角形，避免双面共用顶点自动求法线互相抵消。每棵近景树按材质合并，种子决定枝角、叶簇朝向及色差。
- 远林使用四套低细节枝叶原型，按 40m 网格和材质合并，以便视锥剔除，替换原跨整个林带合成的球帽/锥帽。第一轮过稀后增大远景叶量；旧背景球状灌木点缀一并退役。没有为全部远树套近景花叶精度。

树位、原碰撞/交互数据未改；普通树、樱花和巨樱的原树干碰撞尺寸保留。已有低矮灌木、花坛及非树木装饰网格继续保留，不将它们当作树冠路径。此轮为程序化分树种枝叶网格，不包含风动画、手工雕刻树皮或商业扫描资产。

## 验证

`shots/137-natural-trees/` 保存构建、三种树的实机截图与帧率日志。首轮清除 ForestBelt 旧 Ball 辅助函数时残留两条背景灌木调用导致编译失败，已删除那段退役点缀，最终构建成功。

`-treecheck` 校验实际 65 棵近景树的网格、法线有效性和旧壳体退役；当前近景枝叶共约 244 万三角形（不是单棵数量）。`-treepreview -treespecies 0|1|2` 在既有真实树中选最近的一棵，将玩家移到附近安全落点并朝向树冠，用于实机查看，不生成替代树。预览加 `-freeze 1` 防旧相机自动回正改变验收朝向。

三种树视角在 60 帧预热后采样 300 帧，测得 59.9～60.0 FPS（锁 60，仅为这些测试点，不代表全图下限）；运行日志无异常，树林位置/碰撞数据保持。最终正常打开游戏供作者看，不用静态截图代替实机。未提交、未推送。
