# 86 · 柜台背后闪面收尾 + 人物动作（跳跃 / 蹲下）

## 一、柜台背后还在闪（补刀）

docs/85 把台面板与柜顶的共面修掉了，但**柜台背后**仍有一条闪面缝：`BarCounter` 的内侧踏板（放杯子/出餐的小平台）后沿正好等于柜体背面（z=2.15），两种材质共面 → 从操作面看过去一条缝在闪。改成踏板内缩 2cm（z 2.18~2.48）。

按同一标准再扫了一遍新铺的柜台类构件，又找到一处同类共面：便利店冷柜带的玻璃门后沿正好压在柜体正面上（`z + 0.02` 且门厚 0.04 → 背面正好 = 柜面）→ 改成离柜面 1cm。

## 二、人物动作：跳跃（空格）与蹲下（C）

作者要求"给人物多加几个动作，跳跃和蹲下"。角色本来就是**分层骨骼**（`_body/_head/_armL/_armR/_legL/_legR`，走路摆动是程序化算的），所以直接在骨骼上加姿态，不需要新资产。

### 运动（`PlayerRig`）

- `JUMP_V = 3.15`、`GRAV = 9.8` → 跳高约 0.5m、一次 0.64s；`_airH` 逐帧积分，落地清零；
- 空中不能再蹲（`if (!grounded) crouch = false`），空中也不叠加走路小跳；
- 蹲下时移动速度降到 48%，且不能同时跑（`_crouchBlend < 0.5` 才算跑）；
- 相机跟着降：第三人称视点降 0.32m、第一人称眼高降 0.42m，蹲下时画面会压下来；
- 碰撞仍是 2D AABB（`Collides` 不看高度），所以**跳不过障碍、也钻不了矮洞**——这两个动作现在是表现层的手感，不是关卡机制。真要做平台跳跃得先给碰撞加高度层。

### 姿态（`PlayerAvatar.Tick`，新增 `air / vvel / crouch` 三个参数）

- **蹲**：腿节点整体按 `localScale.y = 1 - 0.32·crouch` 缩短，同时身体下降 `11.75·PX·(1 - scale)` —— 两者严格相等，所以**脚不会离地、也不会插进地里**（比"腿前伸 + 身体下沉"那种做法干净）；上身前倾 17°、头回抬 15° 保持视线朝前，手臂前摆 14° 像扶平衡；呼吸起伏在蹲下时关掉。
- **跳**：按速度分三段——上升段收前腿（`tuck`）、手臂大幅上摆（118°）；到顶两腿并拢；下落段前腿伸出准备落地（`kick`，随下降速度增大），手臂回落一半；身体轻微后仰 6°。
- 腾空时走路混合量 `_blend` 归零 → 空中不会残留迈步动作。

### 验收参数

新增 `-pose jump|crouch`：把人物钉在半空（0.36m）/ 蹲姿上，配合 `-shot` 可以稳定截图核对姿态（否则动作只有 0.6 秒，截图截不到）。

```bash
Game/Build/Win/Campus.exe -px 0 -pz 4 -at -21,7.5 -freeze 1 -pose jump   -shot shots/86-jump.png
Game/Build/Win/Campus.exe -px 0 -pz 4 -at -21,7.5 -freeze 1 -pose crouch -shot shots/86-crouch.png
```
