# 59 · 礼堂标牌修正与舞台可上人

作者（2026-10-28）：

> 礼堂里的出现字的地方有问题，有些是浮空的，门口的字是镜像的，上讲台的楼梯是不能上去的

## 一、标牌问题与修复

| 位置 | 原问题 | 修复 |
|---|---|---|
| 售票处 / 衣帽寄存 | `SignText` 放在柜台上方 y=1.45、z=26.10（没有底板，且朝北）→ 从门厅看是浮空 + 镜像 | 柜台正面（z=27.11）加 2.2/2.0×0.38m 底板，文字 y=1.12、ry=180 朝门厅（+Z） |
| 观众须知 | 底板在 z=29.80，文字 ry=180 朝墙内 → 从门厅看到背面 | 文字 ry=0（朝 -Z，面向门厅） |
| 观众厅 / 出口吊牌 | 单面 `HangingSign` 朝观众厅（-Z）→ 从门厅看是镜像 | 新增 `TwoWayHangingSign`：一块 0.06m 厚底板 + 两面白色内板 + 两面文字（+Z/-Z 都可读） |
| 男/女卫生间 | `WallSign` 放在门洞正中 y=2.5，而门洞高 2.6 → 牌子悬在门洞里 | 移到 y=3.0，贴在门楣上方 |
| 礼堂门牌 | Shell 的门牌在门内侧，外侧只能看到背面 | 门外侧 z=30.16 补一块 `WallSign`（face=+1，朝 +Z） |

> `SignText` 朝向约定：ry=0 面向 -Z，ry=180 面向 +Z；`WallSign(face=+1)` 朝 +Z、`face=-1` 朝 -Z。
> 门厅在礼堂南侧（+Z），所以门厅侧文字必须用 ry=180 / face=+1。

## 二、舞台楼梯可上人

### 原因

- 舞台是整块 25.8×9.8m 的 `Reg` 隐形碰撞盒，2D AABB 不看高度，玩家在台前直接被挡住；
- 台前三步只是视觉方块，`Interior.FloorAt` 永远返回 `FloorY[0]`（0.02m），没有台面高度。

### 实现

- `Interior` 新增台面/坡道字段：
  - `StageY`、`StageX1..StageZ2`：台面矩形与台面高度；
  - `RampX1..RampZ2`：台阶隐形坡道（RampZ2 低端、RampZ1 高端）。
- `FloorAt`：
  - 台面矩形内返回 `StageY`（礼堂 0.99m）；
  - 坡道内按 z 在 `FloorY[0]` 与 `StageY` 之间插值，玩家平滑走上去；
  - 其余区域仍返回 `FloorY[0]`。
- 礼堂：
  - 删除整块舞台 `Reg`；
  - 台口 z=-16 只留中央 6m 楼梯口，两侧补 `Wall(..., 0.02, 0.97, darkWood)` 挡墙；
  - 坡道 x=ox±3、z=-15.9..-14.4；台面 x=ox±12.9、z=-25.9..-15.9；
  - 视觉台阶保持原样，玩家脚底沿坡道上升。
- 舞台上的讲台/钢琴仍各自有 `Reg`，玩家可以绕开；台后两个演员出入口仍可下到后台（高度会平滑过渡回 0.02）。

### 验收

模拟行走（站在台前 z=-12.5，按住 W 300 帧）：

```
[Sim] f=150 pos=(1670.00,1.00,-18.12) moving=True
[Sim] f=210 pos=(1670.00,1.00,-20.30) moving=True
[Sim] f=300 pos=(1670.00,1.02,-23.57) moving=True
[Sim] f=360 pos=(1670.00,0.99,-23.57) moving=False
```

y 从 0.02 升到约 1.0，玩家已经站在舞台上；台口两侧挡墙生效，只能从中央楼梯上下。

## 四、教训

- 标牌必须挂在**实体墙段**上：门洞正中、门洞高度以内放牌会直接悬空；
  先查墙段/门楣坐标再放。
- 门槛两侧的单面文字牌要双面：`TwoWayHangingSign` 一块板 + 两面白板 + 两面文字，
  避免从另一侧看到镜像。
- 共享 `Shell` 的门牌在门内侧；要外侧可读，必须在门外侧补一块 face=+1 的门牌。
- 室内默认是一层平地面；要做“可上的台”，不要用整块 `Reg` 当台，
  改用 `StageY` + 坡道高度，并在台口留楼梯洞、其余边补挡墙。
- 台面高度和碰撞要一起改：只删碰撞玩家会从任意边“跳”上台；只留碰撞玩家上不去。
