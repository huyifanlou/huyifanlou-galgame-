# 57 · 学校剩余建筑室内（宿舍/体育馆/实验楼/活动中心/艺术楼/生活服务楼/小卖部/值班室）

作者（2026-10-27）：

> 学校区域剩余建筑的内部空间也搭建起来，联网搜索参考设计，空间大小和之前的建筑差不多或者更大

## 一、范围

学校区域原有 12 个建筑，此前只做了教学楼、图书馆、餐厅、超市、食堂。
本轮补齐剩余 9 个：

| 建筑 | id | 室内尺寸 | 主要分区 |
|---|---|---|---|
| 宿舍楼 | dorm | 34×22 | 中央走廊 + 4 间四人间 + 洗衣房 + 洗漱间 |
| 二号宿舍 | dorm2 | 34×22 | 同上，2 人间 + 冷色木作，作为二号宿舍差异化 |
| 体育馆 | gym | 60×36 | 28×15 球场 + 南北看台 + 门厅 + 更衣室 + 器材室 |
| 实验楼 | labs | 46×30 | 中央走廊 + 4 间实验室（物理/化学/生物/综合） |
| 活动中心 | center | 50×32 | 门厅 + 多功能厅（舞台/座席）+ 音乐社 + 棋艺社 |
| 艺术楼 | arts | 46×30 | 美术教室 + 音乐教室 + 2 间琴房 + 舞蹈房 |

## 三、实现

- 新增三个 partial 文件：
  - `InteriorBuilder.SchoolRemaining.cs`：通用 `Shell`（地板/天花/四墙/出口门/门灯/门牌/
    墙纸）+ 宿舍/小卖部/值班室；
  - `InteriorBuilder.SchoolFacilities.cs`：体育馆/实验楼；
  - `InteriorBuilder.SchoolCulture.cs`：活动中心/艺术楼/生活服务楼。
- 每个室内都走现有系统：
  - `Interior` 的 `X1..Z2 / Spawn / Exit / FloorY / ClearX1..ClearZ2`；
  - 出口统一 `DoorFrame`（门扇盖满门洞、门内侧暖光、门牌）；
  - 家具碰撞用 `Reg` / `SolidPart`；墙用 `WallX/WallZ`；
  - 室内家具统一避开出口净空（门内 6m、门宽 + 0.8m）。
- 新建室内放在世界外 x=1540~2060，依次排开，互不重叠。
- `InteriorManager.ToId` 新增 9 个映射：宿舍楼/二号宿舍/体育馆/实验楼/
  活动中心/艺术楼/生活服务楼/小卖部/值班室；建筑交互点现在都可进。
- 全部单层，出口仍按 `F` 离开；室内门为关闭状态。

## 六、教训

- 贴外墙的大件（床、储物柜、冰柜、水槽）要按 `WALL_OUT*0.5+0.02` 的内缩量再退 10~20cm，
  否则会被室内边界校验判“越界”；
- 大房间的门口净空要单独留：实验台/教师桌、舞蹈长凳、活动中心舞台都容易压到门内 6m 线；
- 体育馆看台要按“前缘 + 逐排后退”放，并在中间留出 5m 观众通道，否则进门先撞看台；
- 实验室教师桌不能正对门放，否则一进门就被桌子挡住；白板/通风柜贴墙、
  教师桌退到侧边；
- 活动中心/服务楼这类大空间只靠 1~2 盏吊灯会发黑，要按 4×3/3×2 的网格布点，
  并给舞台/门厅单独补光；
- 双开门中缝压条、门灯、门牌在九间室内继续沿用，门扇都盖满门洞。
