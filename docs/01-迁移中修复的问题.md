# 01 · 迁移中发现并修复的问题（2026-10-15）

## BUG-001：lcgRand 忽略参数 —— 边界植被为空 + 远景楼群退化

### 现象

导出世界数据（`node tools/export-assets.mjs`）后用 Node 校验，发现：

```
BORDER_TREES 0 | BORDER_BUSHES 0 | BORDER_ROCKS 0     ← 应为 90 / 100 / 22
distant r-range: 50,62,50,62,50,62 ...               ← 应为 50-60 / 62-74 随机分布
```

### 根因

`campus.js` 的确定性随机函数：

```js
function lcgRand(seed) {
  let s = seed
  return () => (s = (s * 1664525 + 1013904223) >>> 0) / 4294967296
  //       ^^ 闭包不接收参数，调用方 rndBorder(3600) 里的 3600 被静默丢弃
}
```

调用方全部按 `rnd(max) → [0, max) 整数` 的语义书写（`rndBorder(3600)` 取角度、`rndD(1000)/100` 取半径等），
实际得到的却是 [0,1) 小数，于是：

- **边界林带/灌木/环带石**：`r = 33 + rndBorder(1500)/100 ≈ 33 + 0.004`、角度 ≈ 0.0001·2π ≈ 0
  → 所有候选点堆在 (0, 33) 一个位置 → 被 `|x|<4.5 && |z|<44` 走廊排除条件整组拒绝 → 三组数组为空。
  （web 版 v0.40 的「90 棵边界树」从未真正渲染过——这是校界观感空旷的来源之一。）
- **远景 26 栋楼**：半径退化为恒定 50/62；`styles[rndD(2)]` 得到 `styles[0.44] = undefined`
  → 风格全部落入默认分支（平顶）→ 26 栋同尺寸方盒，且正好均布在两圈上（观感机械）。

### 修复

`lcgRand` 支持双模式：

```js
return (max) => {
  s = (s * 1664525 + 1013904223) >>> 0
  const v = s / 4294967296
  return max === undefined ? v : Math.floor(v * max)
}
```

- `scatter()` 内部按 `rnd()`（不传参）使用 → 校内植被（34 树 / 26 灌木 / 30 花 / 7 土斑）布局**与 web 版完全一致**，不受影响；
- 其余传参调用点全部恢复设计语义 → 边界林带 90 棵、灌木 100 丛、环带石 22 块、远景 26 栋四风格（内圈平顶/坡顶，外圈含塔楼/公共建筑）按 seed 20261015 确定性生成。

### 处置

- Unity 工作区：修复版快照位于 `tools/source/campus.js`，`world.json` 已按修复后数据重新导出。
- web 版仓库：保持冻结（tag `web-v1.0-frozen-20261015`）；如后续需要对照，可在 web 仓库单开一次修复提交（待办）。

### 经验

迁移/移植是发现"静默 bug"的绝佳时机——因为会把中间数据（world.json）真正拿出来校验一次。
任何"随机散布"逻辑，导出后都应做一次分布断言（数量 + 半径区间 + 风格枚举），不能只看截图。
