# 83 · 室内三处缺陷修复：椅子朝向 / 吊牌接顶 / 更衣室空气墙

作者实机反馈三件事：**内部椅子方向不对**、**悬挂牌子在空中没有和天花板接触**、**换衣间有空气墙**，并要求把这几处布局整理干净。三处都是"一类问题"，所以按类改到公共生成函数，而不是只补被点名的那一处。

## 一、椅子朝向（`Chair` 的朝向约定）

`Chair` 的靠背做在局部 −Z（[InteriorBuilder.cs:290](file:///D:/AI/GLM/.zcode/workspace/Unity%E5%BC%80%E5%8F%91galgame/Game/Assets/Scripts/InteriorBuilder.cs#L290)），所以 **ry=0 是"人朝 +Z"**：桌南侧取 0、北侧 180、西侧 90、东侧 270。这条约定以前没写在代码里，结果新铺的桌子有几组椅子正好反了 180°。已把这个约定补成注释，并逐处核对全 13 间室内的 30 个 `Chair` 调用点：

| 位置 | 原来 | 现在 |
| --- | --- | --- |
| 奶茶店 6 张方桌的东西两侧椅 | 0 / 180（背对桌） | 90 / 270（面对面） |
| 照相馆 选片区 2 桌的南北椅 | 180 / 0（背对桌） | 0 / 180（面向桌） |
| 实验楼 讲台椅（`LabTeacher`，dir 双向） | 背对讲台与白板 | 面向讲台与白板 |
| 家 书房贴北墙书桌的椅子 | 180（背对书桌） | 0（面向书桌） |

其余（礼堂吧台椅、售票处/衣帽寄存椅、餐厅卡座旁椅、教学楼阅览桌椅、宿舍上床下桌椅）核对后方向本来就正确，未改动。

## 二、吊牌 / 吊灯接顶（改成"跟着吊顶走"）

根因：`HangingSign` 的吊杆是**固定 0.7m**（`y + h/2 + 0.35`），而各房间层高不同（宿舍 3.6 / 奶茶店·便利店 4.2 / 照相馆·书店 4.5 / 图书馆 4.8 / 礼堂 8.5），牌子画在 2.9~3.45 就再也接不到顶；`Pendant` 的吊线同理，奶茶店还把它按 `W-0.1` 传参，等于把灯罩埋进吊顶里。

改法（都在公共函数，13 间室一起生效）：

- 新增 `CeilingSlab()`：铺顶板时顺手记录本房间吊顶底面高度到 `_ceilY`，7 处天花板（家/教学楼/图书馆/餐厅/超市/食堂/`Shell`）统一改用它；
- 新增 `HangRods()`：吊杆从牌顶接到 `_ceilY`；没有层高信息时退回原来的 0.7m 短杆；
- 新增 `HangY()` + `MAX_ROD = 2.8`：层高太大时把悬挂件**整体上抬**到杆长 2.8m，避免礼堂里出现一根五米细杆；
- `HangingSign`、`TwoWayHangingSign`、`Pendant` 全部改走这两个函数；`Pendant` 另加一条"灯罩至少离顶 0.75m"的下限，防止被埋进吊顶。

**验证时抓到的一个回归**：礼堂后墙 z=14 的门头 above 梁本身就在 y 4.0~8.5，按 8.5 吊顶上抬会把「出口 / 观众厅」三块牌**抬进梁里**（截图里直接看不见）。所以 `HangY/HangRods` 增加一个可选 `ceil` 参数，这三块牌显式按梁底 4.0 接顶 —— 牌仍留在 3.7/3.75 的视线高度，吊杆变成 3~13cm 的短吊挂件，贴在梁底。

奶茶店 4 块菜单屏原来手写的两根 1.2m 立杆（docs/82 里以为已经接顶，其实离 4.14 的吊顶还差 1.1m）也改成 `HangRods`。

## 三、照相馆更衣室：从"封死的箱子"改成开面隔间

原来两间更衣室是四面木板 + 整间体积登记成一个 2.6×2.7 的碰撞盒（`Reg(it, ox+11.2, fz, 2.6f, 2.7f)`）——人根本进不去，就是一块空气墙；而且中间还多横着一块把隔间切成两半的板。

现在（[InteriorBuilder.ShopRows.cs:222](file:///D:/AI/GLM/.zcode/workspace/Unity%E5%BC%80%E5%8F%91galgame/Game/Assets/Scripts/InteriorBuilder.ShopRows.cs#L222)）：

- 两间 1.7m 宽 × 1.76m 深 × **2.6m 高**的隔间贴东墙，**只登记背板 + 两侧板**三块薄实体，正面不登记；
- 正面只有帘杆 + 两片布帘（中间留 0.55m 空当，看得见脚也进得去人），门口加踏脚垫；
- 隔间内：背板内面一面**带木框的** 0.92×1.72 试衣镜、镜上一块小搁架、侧板一根挂钩；
- 服装挂通从"两根互相穿过去的横杆"改成一根挂杆 + 两端立柱 + 11 件样衣，并让到北段（z 1.0~5.0），与南段隔间不再重叠；
- 动线自北向南：前台/样片墙 → 选片 → 化妆（西墙）→ 拿衣服 → 更衣 → 后场拍摄。

实机验证（模拟向前走进隔间）：

```bash
Campus.exe -indoor photo -px 1990.6 -pz -1.0 -at 1994.6,-1.0 -fp 1 -sim w,260 -frames 320
# [Sim] pos=(1994.33, 0.02, -1.00)  ← 从走道（室内 x=10.6）走进隔间内（x=14.33），不再被挡
```

## 四、四间商铺布局整理

**奶茶店**（问题最多的一间）：

- 客座原来有 2 张桌子直接长在吧台里侧（吧台北缘 z=2.15~3.05，桌位 z=2.6）→ 客座重排成 3×2 网格（x −10.0/−6.6/−3.2，z 0.2/−3.5），排间留 1.2m 走道，既不进吧台也不贴后场隔断；
- 吧台的**顾客面改到北侧（朝门）**：菜单屏、展示柜、「点单台」「取餐口」吊牌都移到 z 3.15~5.0 一侧，封口机留在操作面（南侧），取餐台从吧台南侧折到东北端；原来「点单台」牌朝南、「菜单屏」在北，顾客面是反的；
- 「堂食区」「加料区」两块吊牌的 `face` 由 −1 改 +1 —— 原来字朝向没人站的那一侧；「外卖自取」由 (10.5, 4.0) 移到取餐台旁 (6.2, 4.4)；
- 后场隔断那段 `foreach` 单元素循环去掉，注释按实际写（东端留 8.6m 通道，不是原来写的 1.2m）。

**照相馆**：选片椅朝向（见第一节）、更衣室（见第三节）、服装架；拍摄区与化妆间未动。

**便利店**：报刊墙原来从 x −15 拉到 −10，与 15m 冷柜带（x −10.5 起）在同一 z 带里重叠 → 收到 x −15~−11.6。

**书店**：逐件核对无重叠、无悬空，只吃到第二节的接顶修正。
