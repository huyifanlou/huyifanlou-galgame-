# 78 · 台阶朝向、长椅布点与门口空气墙修复

作者现场反馈三处问题：**柱廊台阶反了（图书馆、礼堂）、长椅有的压在路上有的贴着建筑、各建筑门口有空气墙**。本轮逐项修根因，并用模拟行走验收。

## 一、台阶反了

`WorldBuilder.cs` 的 `Portico()`（图书馆/礼堂共用柱廊）：

- 三级台阶原来的 y 随“离建筑的距离”**递增**，最高一级落在最外侧，视觉上像倒扣的楼梯；
- 宽度也随距离**递减**，外沿比内沿窄。

改为：

```csharp
Box(grp, new Vector3(0f, baseY + 0.36f - i * 0.13f, front + depth + 0.25f + i * 0.4f),
    new Vector3(porticoW + 1.3f + i * 0.24f, 0.24f, 0.44f), ColMat(b.plinth));
```

- 贴柱廊平台的一级最高（顶面 0.48m），向外逐级降到 0.22m；
- 外沿逐级加宽，形成正常的外扩踏步。

## 二、门口空气墙

### 1. 碰撞盒没按朝向旋转（主因）

`PlayerRig.Collides()` 直接拿 `size[0]/2`、`size[2]/2` 当世界半宽半深，没有用 `HalfWX/HalfWZ`。
朝 ±X 的校舍（图书馆、宿舍、食堂、礼堂、活动中心）实际占地与碰撞盒正好转了 90°：

- 图书馆（22 宽 × 12 深，朝 +X）：碰撞盒按 22×12 摆，门口方向多顶出约 5m；
- 礼堂（16 宽 × 8 深，朝 −X）：多顶出约 4m。

结果是**还没走到柱廊台阶就被挡住**。现改为按 `HalfWX/HalfWZ` 计算，并按 `face` 在正门一侧加门厅凸出：

```csharp
float e = b.EntranceExtra;
if (b.face == 2) x1 += e;
else if (b.face == -2) x0 -= e;
else if (b.face == 1) z1 += e;
else if (b.face == -1) z0 -= e;
```

`BuildingDef.EntranceExtra`（`WorldData.cs`）：collegiate 1.04m、modern 1.16m，其余 0。门厅凸出的部分现在也计入碰撞，人停在**可见门口前 0.45m**，不会穿进门斗里再撞隐形墙。

`WorldBuilder` 里原来私有的 `EntranceExtra()` 删除，门的位置与碰撞共用同一个属性。

### 2. 柱廊台面可走（图书馆/礼堂）

`WorldBuilder.GroundY()` 增加柱廊高度：

- 台面（离主墙 0~3m）高度 0.45m；
- 三级踏步：内 0.48m、中 0.35m、外 0.22m；
- 只在 library/hall 两种样式生效。

人物走到门口时脚底会随台阶抬起（实测 y 0.05 → 0.49），不再陷进 45cm 高的石台里。

### 3. 校验器同步修正

`WorldValidator` 的建筑轮廓也从 `size[0]/2, size[2]/2` 改为 `HalfWX/HalfWZ`，否则布点校验对旋转建筑同样按错误占地计算。修正后仍 **零违规**。

## 三、长椅布点

原来 8 张校园长椅中：

| 原位置 | 问题 | 处理 |
| --- | --- | --- |
| `(−68,−66)` | 正在教学/实验楼南北步道正中 | 移到 `(−73,−66)`，草坪上、离步道 2.75m，面向步道 |
| `(−84,−66)`、`(−84,−70)` | 贴着图书馆柱廊踏步/西南角 | 删除；方院南侧改放一把 `(−62,−72)`，离建筑与步道均 ≥4m |
| `(−98,−39)` | 食堂南侧背街，位置无停留理由 | 删除 |
| `(−78,−56)` | 离主步道 1.5m | 微调到 `(−78,−55.6)`，留 1.9m 草边 |
| `(−40,−54)`、`(−40,−66)` | 在礼堂前庭铺装西缘，面向礼堂 | 保留（属广场边缘座椅，不压步道、距礼堂踏步 7.7m） |
| `(−24,−89)` | 篮球场北侧草坪 | 保留 |

现共 6 张，全部避开步道（plaza prop）和建筑可见轮廓；垃圾桶、花坛、车架、公告板未动。

## 五、已知取舍

- 柱廊可走，但柱子和檐部仍是装饰件、无碰撞，可以贴着柱子穿过去；如要严谨可给柱列加圆柱碰撞。
- 台阶只做了中间梯段，台面两侧直接是 0.45m 高差，从侧面上下会“跳”一下。
- `docs/77` 的表三把 `B(id,name,x,z,w,h,d)` 的 h/d 写成了「宽×深 | 高」，实际尺寸以本节代码为准（如礼堂 16 宽 × 8 深 × 12 高）；本轮未改建筑位置。
