# 64 · 树冠与灌木形态（七树种 / 伞松 / 冠形分型）

作者（2026-10-28）：

> 这些树和灌木都是球状的

第三轮把树量降到 25%、山体层次做出来之后，剩下的问题集中在**轮廓**：
近中景林带几乎全是“一个半球 + 三段球冠”，灌木是“三球一丛”，远山林毯是“一排排扁球”，
换树种只换颜色、不换形状，整体仍是一眼球的塑料森林。镇里手摆的树更割裂——还是早期叠方块的造型。

## 一、根因

1. **冠形只有一种**：`ForestBelt` 所有阔叶/樱/秋色都用同一个 `canopy` 网格（或 `canopy2`），
   松/杉才有锥体；树高、冠半径只是等比缩放，轮廓没有分型。
2. **灌木是固定三球**：每丛固定“主球 + 两个小球”，大小/朝向规律，远看是一排等距圆点。
3. **远山只有圆冠/扁冠/针叶锥**：没有树干、没有伞形/竖椭圆，32m 以上仍是“叠盘子”。
4. **镇内手摆树是方块冠**（`Tree()` 里三层 `LeafBox`），和新林带的自然冠形完全不搭。

## 二、改法

### 1. 林带七树种（`ForestBelt`）

概率表（`roll` 单次抽样）：

| 树种 | 概率 | 形态 |
| --- | --- | --- |
| 0 松 | 18% | 三层锥 + 0.34h 树干 |
| 1 阔叶 | 20% | 矮杆 + 三球不对称（0.31/0.19/0.16h） |
| 2 杉 | 14% | 窄高双锥 + 0.22h 树干 |
| 3 樱 | 5%（神社带 +35%） | 宽扁冠 + 低侧球 |
| 4 细高落叶 | 11% | 竖椭圆双层（0.20h × 0.34h） |
| 5 伞松 | 10% | 高干 0.50h + 两层厚冠 + 小顶冠 |
| 6 秋色阔叶 | 22% | 三球，金黄/赭色 |

- 每个冠块走 `Blob()`：随机 Y 旋转 + `canopy`/`canopy2` 各半，同一个网格也不再重复；
- 伞松第一版“0.34h 半径 × 0.16h 厚度”像插在杆上的桌板，已收窄到 **0.28h 半径、0.21h 厚度**，
  三块错位叠放，远看是层片松而不是飞碟。

### 2. 绿篱与灌木（`ForestBelt`）

- 绿篱由固定三球改为 **4~5 个不规则叶团**：每团独立偏角、偏心距、半径（0.45~1.0 倍主半径）；
- 每团单独取 `FootMinH` 贴坡，单团偶尔加高 1.3 倍，避免“一排等大圆点”；
- 冠块统一压扁加宽（ry = 半径 × 0.36~0.51，横向 1.05~1.5 倍）。

### 3. 远山冠形与树干（`MountainDetail`）

- 贴坡小灌丛（r125-200）：28% 双球丛、18% 竖椭圆、其余宽扁单球；
- 主林毯（r158 起）**乔木开始有树干**（1.1 + 0.32 × 半径高，宽 ≥ 0.18m，树皮并入独立网格）：
  - 伞状冠 20%：厚度 0.46 × 半径，60% 再挂一颗偏侧下的小冠；
  - 竖椭圆 30%：ry = 0.88~1.2 × 半径；
  - 云团冠 50%：55% 加侧球；
- 灌木层：30% 双球、16% 竖椭圆、其余宽扁（sy 0.40~0.56），不再铺一层同高的扁球；
- 针叶锥概率保持（灌丛 14% / 乔木 26%），竖向轮廓继续打散天际线；
- 所有冠/杆/锥仍按 `FootMinH` 足迹最低地面落位下沉。

### 4. 镇内手摆树换冠形（`Trees` / `Tree`）

- `Tree()` 新增两个共享冠网格（lump 0.24 / 0.36），把四类**叠方块冠**换成冠团：
  - 0~5 常规树：主冠 + 亮色侧冠（宽/高随 v 的 wide/tall 变体）；
  - 8 大树：双球大冠；9 柳树：三层压扁冠（保留垂坠层次）；10 桃花：粉冠 + 小球；
  - 6 松 / 7 柏 保留锥体；
- 冠块 UV 按 2.5 次平铺叶簇贴图（小冠 0.8m/重复，和林带一致）；
- 冠形朝向由位置散列（`x*37.7 + z*19.3`）决定，同一棵树每次构建一致；
- 删除已无引用的 `LeafBox()`；树干盒、碰撞胶囊、`ProximityHide` 不变。

- 林带里锥、伞、竖椭圆、三球、双球各占一档，近中景不再是一排球；
- 远山乔木出现可见树干，伞冠厚度加大后“飞碟”明显减少；
- 镇内河东两棵方块大树变为自然冠团，桥畔柳/桃保留原来的分层与粉色；
- `-fps 1`：渲染器 4175 / 顶点 9.4186M / 灯光 107（上一轮 4202 / 9.409M / 107）。
  渲染器少 27 个来自镇内树 4 件套 → 3 件套；总顶点基本持平。

## 四、取舍

- 伞冠仍是最容易读成“盘子”的形态，控制在 20% 并加厚；若后续仍嫌平，可再降到 10%；
- 镇内树冠体积比原来的方块略小（冠底与树冠高度按冠网格重算），碰撞胶囊未动，不影响穿行；
- 林带树种是固定概率 + 位置散列，布局可复现；要调整树种比例改 `Add()` 里的 `roll` 分段即可；
- 远山低处灌木仍偏扁，这是为了和陡坡贴合的刻意选择；真正的球感已由树干 + 多形态乔木抵消。
