# 20 · 物理引擎接入与可流动的河水

作者要求：**先优化，加入物理引擎，要能流动的水**。本轮把静态贴图水面换成实时高度场水体，并把 Unity PhysX 接进世界（碰撞、浮力、可推动物）。

> 2026-10-19 追加：作者随后要求“水面换回静止”。现 `WaterSim.Animate = false`，水面网格为平面、贴图不滚动、流速为 0；
> 高度场模拟与雨滴扰动代码保留，改回 `Animate = true` 即可恢复流动。详见 docs/22。

## 一、河水（WaterSim，默认静止）

- **模型**：沿河道的二维高度场，显式波动方程 + 顺流上风平流 + 阻尼。
  - 网格：顺河 1m × 横河 0.5m（220m × 16m → 221 × 33 ≈ 7.3k 顶点），每帧 CPU 模拟。
  - 波动：`h_new = 2h - h_prev + c²∇²h`（c=2.2 m/s），顺流项 `u·(h_upwind - h)`（u=0.10 m/s）。
  - 浪高夹紧 ±0.028m；阻尼 0.994；两岸 Neumann 反射；桥墩格点设为障碍（水从拱洞两侧绕开），并在墩周生成白沫。
  - 持续扰动：全域稀疏随机脉冲（风的细浪）+ 河源来波 + **雨滴扰动**（读 `Weather.RainAmt`）。
  - 水面网格每帧写回顶点/法线/顶点色；法线由高度差解析计算（不调用 RecalculateNormals）。
- **水面着色**：自定义着色器 `Campus/Water`
  - 基础水色 + Fresnel 天光反射 + 太阳高光（方向/颜色由 `TimeOfDay` 每帧写入全局）。
  - 细节贴图（原 water 贴图）沿 U 轴滚动，既扰动法线（细碎波光）又生成**顺流白沫线**。
  - 顶点色 R = 泡沫（岸边/桥墩/波峰），与昼夜环境强度联动。
- **构建注意**：运行时 `Shader.Find` 的自定义着色器会被剥离 → `Bootstrap.SetupProject()` 的占位材质列表加入 `Campus/Water`（与 PostFX 同一机制）。

## 二、PhysX 物理引擎接入

- **静态碰撞**：地形（MeshCollider）、46 栋建筑与主角家（BoxCollider）、树干（CapsuleCollider）、石护岸（MeshCollider）、石桥桥面/桥墩、廊桥桥面。浮物与可推动物会与这些真实碰撞。
- **玩家**：角色组上挂运动学 Rigidbody + CapsuleCollider（移动仍走原有手感/自定义 AABB），可推开动态物体。
- **可推动物**：货场 3 个木箱改为 Rigidbody（质量 26kg），落在地形碰撞体上可被推走。
- **浮力物件**（`Buoyant`）：
  - 用小船/木箱/落叶 + 弹簧跟随水面（`FloatHeight` 目标高度、刚度 60、阻尼 7），叠加顺流水流拖拽。
  - 系泊小船：主桥上游（x=-26）南岸，木质平底船，随波起伏。
  - 4 个顺流漂木 + 5 片落叶：漂到下游尽头（x>103）自动回到上游（`Drifter`），保证河面一直有流动参照物。

## 五、已知限制 / 下一步

- 水面与玩家不产生浮力（岸边 2.45m 护岸挡住；角色不进河），若要“下水”需加游泳状态与水面碰撞查询。
- 泡沫是近似混合（顶点色 + 细节亮纹），没有真正的白水粒子与尾迹；下一步可加桥墩溅水粒子与船尾 Wake。
- 河水不反射场景（无平面反射），只反射天光；后续可加 Reflection Probe / 平面反射相机。
- CPU 模拟在 PC 上开销很小（≈7k 格），WebGL 也可运行；若要更高分辨率需换 Compute Shader。
- 玩家仍用自定义碰撞（保持既有手感），物理引擎目前服务于场景物件与水面浮物。
