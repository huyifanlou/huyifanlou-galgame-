# 38 · 教室三项修正：门口通畅、12 座均布、门洞加宽

作者反馈（2026-10-26）：进门被遮住、座椅太多要 12 个均匀分布、出入口太小。

## 一、进门被遮住（两个原因叠加）

1. **走廊那面墙的墙裙整条横穿门口**：`Panel(sx1, zFront-0.04, sx2, zFront-0.04, h=1.1, skirt)`
   是教室侧的一面 1.1m 高绿带，从教室左墙一直拉到右墙，**没有按门洞断开** ——
   走到门口就是一条绿色矮墙，看着像被挡住。
   → 用已有的 `doorA/doorB` 参数把墙裙切成两段（门口两侧各让 0.12m）。

2. **门口正对第一列课桌**：课桌网格以教室中心 `cx` 对称排布，而教室门不在中心，
   于是某一列正好落在门洞里（教室 C：门 1059.2~1061.2，第一列课桌中心 1060.4 —— 正对门）。
   → 新增 `gridShift`：算出"门口中心"相对 `cx` 的偏移，把课桌网格整体平移，让**门正对两条列之间的过道**。
   四间教室的平移量：A +1.2m / B +0.6m / C +1.4m / D 0（门本来就在过道位置）。

## 二、12 座均匀铺满整间教室

原来 3 列 × 2 排 = 12 座，但只摆在讲台前 3m 内，教室进深 12.2m，**后面 7m 全空**，
看着像"座位太多挤在门口"。

改成按房间尺寸铺满：

| 教室 | 列 × 排 | 说明 |
|---|---|---|
| A/B/C（12.3m 宽） | 3 列 × 4 排 | 列距 3.2m，排距按进深拉伸 |
| D 多功能（17.3m 宽） | 4 列 × 3 排 | 列距 3.2m |

- 排距不再写死，用 `Lerp(zFront-3.0, zBack+2.6, r/(rows-1))` —— 从讲台后 3m 一直铺到后墙前 2.6m。
- 每座一张单人桌（0.62×0.42）+ 一把椅，椅子 `ry=180`（靠背朝后、人面向黑板）。
- 碰撞盒按单桌重算（±0.34 / z-0.21~+0.98）。

## 三、出入口加宽 1.2m → 2.0m

走廊北墙（z=-2.5）五段墙重新排布，四个门洞从 1.2m 加宽到 **2.0m**：

| 教室 | 原门洞 | 新门洞 |
|---|---|---|
| A | -19.2 ~ -18.0 | -19.6 ~ -17.6 |
| B | -11.0 ~ -9.8 | -11.4 ~ -9.4 |
| C | -0.4 ~ +0.8 | -0.8 ~ +1.2 |
| D | +14.0 ~ +15.2 | +13.6 ~ +15.6 |

同步改了：走廊侧墙皮 `WallDeco` 的门洞数组、四间教室的 `doorA/doorB` 参数。
黑板偏移 `boardShift` 相应调整（A -0.6→-1.0、C 0→+0.6），保证 5m 黑板不与 2m 门洞重叠。
