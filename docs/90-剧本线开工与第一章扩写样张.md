### v3 追加口径：**台词也书面化**（作者原话「台词书面化」）

"台词一律不动"这条**作废**。v3 把 32 条台词逐条过了一遍：改 27 条、留 5 条短笑话不动，
并在文末附**逐条对照表（原句 → 新句 → 动了什么）**，让作者能否决到句子级而不是整章级。
方向按人物分：

- **樊楼**：往"简净、冷"收，只删口水尾（哎／唉／算了／了啊），不硬加文言。
- **镜荧**：她本就自称"吾"、出身世家，书面化等于**回到她该有的腔调**（怎的／衣裳／相干／盘桓／钱银），
  反而更贴人设，所以可以比樊楼改得重些。
- ⚠ **雅化会吃掉梗的地方单列出来问**：唯一一处是"正好长在我的 **XP** 上"→"正正落在我的喜好上"，
  网络俚语一雅化就不好笑了，这条留给作者裁。
- `【内心】` 4 处**保持白话**（"中二病吗""石子是真的在发光"）——内心独白一旦文言就不像人想的。

**铺第二~八章的默认做法**：叙述层按 v2 的多词汇，台词按 v3 的书面化，每章末尾附对照表；
遇到"雅化会吃梗"的句子一律单列标 ⚠ 交作者裁，不自作主张定稿；
必须用内心独白才能交代的信息也单独标出来问，不要自作主张加独白。

### v4 追加口径：**台词量至少翻倍**（作者原话「台词数现在太少了，适当进行扩写，至少是现在的两倍」）

第一章实测：说话行 **36 → 95**（2.6 倍），其中新写 59 条。
**新台词一律在行首加 `※`**，作者原句不加标记——这样能否决精确到"这批新写的要不要"，
而不必退回整章。文末附**分场统计表**。

新写台词只做三件事，**不引入任何新剧情信息**：

1. **拉长攻防**——原稿一句谈成的事，拆成"开价／装不懂／再开价"三个回合。
2. **让人物有回嘴**——原稿樊楼常被一句话顶死，补上反问与冷嘲。
3. **把演出交给台词**——原来靠旁白交代的状态，改由人物自己说出来。

**扩写时不许吃后面的戏**：第一章不解释觉醒原理、刻印是什么、能否变回去、点了什么外卖——
那些是第三章的内容。每章扩写前先确认本章的"信息边界"，越界的句子宁可不写。

### v5 追加口径：**符合人设、保留梗、去掉文言浓度**（作者原话）

**v3 的"台词书面化"作废**——我做过头了，把台词改成了"罢了／所为何事／吾乃／盘桓／钱银／怎的／衣裳"，
那不是书面化，是**文言化**，而且吃掉了人物声口和梗。v5 的处理：

- **作者原句一律退回**，不再润色。XP、中二病、"吾名为镜荧"、"求收留"、"小樊楼不见了"这些梗原样保留——
  尤其"吾名"是她自己的自称，本来就该那么说，我改成"吾乃"反而把她改僵了。
- **新写的 61 条 `※` 台词同步去文言**（我方才→我刚、寻思→想、一星半点→还挺远）。
- **叙述层也拆文言词**：这般认想→一直这么想、毫无干系→一点关系都没有、只余→只剩下、
  尚未成形→还没成形、并未多露肌肤→并没有露出太多肌肤（＝原句）。
- **"书面化"只留在叙述层，且靠意象与动词，不靠虚词**：散不掉的暑气、复写纸描了五遍、
  亮得不讲道理、湿润的刺入、倒扣的杯子、自己的回声。
- 文末附**回退清单**（我加上的文言腔 → 回到哪句原话），方便作者核对有没有漏退。

**这条是后面七章的硬口径**：台词＝原句＋人设声口＋梗不删；叙述＝现代文学腔、词汇密度高、零文言虚词；
心理独白＝最多 4 处、保持白话；扩写靠攻防回合与回嘴，不靠加独白、不靠加设定。

## 文风基线（作者已定）

**吐槽日常 + 电影感演出**。落地成一套可解析的标记，为下一步对话系统做准备：

| 标记 | 用途 | 游戏里对应 |
|---|---|---|
| `【场景】` | 地点｜时间｜光线 | 背景切换 |
| `【演出】` | 角色动作、镜头 | 立绘动作 / 相机 |
| `【音效】` `【BGM】` | 声音 | AudioSource |
| `【旁白】` | 叙述 | 无说话人对话框 |
| `【内心】` | 没说出口的话 | 心声字体（无框气泡） |
| `【选择支】` | 玩家选项 | 对话系统的 branch/choice |
| `【伏笔】` | 不显示给玩家，写给自己的回收提醒 | 不进数据 |

规则：每行要么以 `【标记】` 起头，要么是 `角色：「台词」`，可以直接正则拆成对话数据。

## 为什么这么写

美化版的实际缺陷（全卷通病，后续每章都要处理）：

1. **叙述层几乎为空**——基本是"角色名：「台词」"串行，只有第一章少女登场那一段有像样的描写。
2. **原版里可放大的动作/心理钩子被润色压平了**：例如原版"径直走出浴室""希望这个家里没人吧"，
   美化版只剩结果。样张把这些还原成过程（顺手抄拖把杆又放下、纸条上那句谎话）。
3. **设定倾倒无处安放**：第二章"会议"连续 4 页只有代表在念世界观，没有地点没有人——下一轮单独立处理方案。
4. **独居这条线只当背景，不当信息**：样张用"我回来了"没人接埋温度，不解释原因，避免替作者把悬念写死。
