## 文风基线（作者已定）

**吐槽日常 + 电影感演出**。落地成一套可解析的标记，为下一步对话系统做准备：

| 标记 | 用途 | 游戏里对应 |
|---|---|---|
| `【场景】` | 地点｜时间｜光线 | 背景切换 |
| `【演出】` | 角色动作、镜头 | 立绘动作 / 相机 |
| `【音效】` `【BGM】` | 声音 | AudioSource |
| `【旁白】` | 叙述 | 无说话人对话框 |
| `【内心】` | 没说出口的话 | 心声字体（无框气泡） |
| `【选择支】` | 玩家选项 | 对话系统的 branch/choice |
| `【伏笔】` | 不显示给玩家，写给自己的回收提醒 | 不进数据 |

规则：每行要么以 `【标记】` 起头，要么是 `角色：「台词」`，可以直接正则拆成对话数据。

## 为什么这么写

美化版的实际缺陷（全卷通病，后续每章都要处理）：

1. **叙述层几乎为空**——基本是"角色名：「台词」"串行，只有第一章少女登场那一段有像样的描写。
2. **原版里可放大的动作/心理钩子被润色压平了**：例如原版"径直走出浴室""希望这个家里没人吧"，
   美化版只剩结果。样张把这些还原成过程（顺手抄拖把杆又放下、纸条上那句谎话）。
3. **设定倾倒无处安放**：第二章"会议"连续 4 页只有代表在念世界观，没有地点没有人——下一轮单独立处理方案。
4. **独居这条线只当背景，不当信息**：样张用"我回来了"没人接埋温度，不解释原因，避免替作者把悬念写死。
