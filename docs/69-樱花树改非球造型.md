# 69 · 樱花树与巨樱改《我的世界》式体素结构

作者（2026-10-30）：

> 记住不要球状的树
>
> 这种像几个长方体胡乱拼接在一起，看着很杂乱没有秩序感。你参考我的世界那种结构，

> 后续布局与尺寸调整见 [70-樱花林扩散与巨樱抬高](70-樱花林扩散与巨樱抬高.md)。

## 一、问题

docs/68 新增的樱花林把 v10~13 的桃花改成了 `MeshFactory.Canopy` 球冠，中央巨樱也是十几团
球冠。第一版改成“错位扁方块”后，虽然不再是球，但每块尺寸、朝向都不一样，实机看起来像
随手拼的长方体，缺少结构。

## 二、最终做法：体素网格 + 树干/分枝/叶团

统一按《我的世界》的体素逻辑生成，所有树块都是**等大 0.8m 立方体、轴对齐**（0.8m 正好是
叶簇贴图周期），树与树之间只做 90° 转向和 ±8% 尺寸差，不再有任意角度和长条盒。

### 1. 小樱花 v10~13

- 树干/主枝：`BuildCherryBark()`（`WorldBuilder.cs:2605`）用原木方块堆出 1×1 树干，
  顶部向 3 个方向（垂枝樱 4 个方向）伸出阶梯主枝；冠底能看到分叉。
- 树冠：`CherryLeafBlocks()`（`:2503`）按体素坐标摆叶团，每个叶团三层：
  - 底层：矩形缺四角（深色），
  - 中层：满矩形（主色），
  - 顶层：收小一圈（亮色），中央可加 1 块盖顶。
- 四个品种的骨架：
  - 染井吉野：标准宽冠，三向侧冠；
  - 白粉樱：树干高、冠窄，中央叠一层；
  - 八重樱：树干矮、冠幅最大，前后左右各探出一团；
  - 垂枝樱：宽冠四边各挂两格低垂叶块。
- 颜色按体素高度分三档（底深、中主、顶亮），块面 UV 用 4 种偏移打散重复感
  （`MeshFactory.BoxUV` 新增可选 UV 偏移参数）。
- 每品种按色阶合并成 3 个叶块网格 + 1 个原木网格，每棵树仍是 4 个渲染器（`:2446`、`:2567`）。

### 2. 中央巨樱

- `GiantLeafBlocks()`（`:2549`）：中央冠 + 四向主枝端冠 + 四角补隙 + 顶部小冠，共 10 个体素叶团；
  冠幅约 11m，冠顶约 11m。
- `BuildGiantBark()`（`:2623`）：2×2 原木粗干（7 块高）+ 四向阶梯主枝；主枝从 1.5 格起，
  避免和粗干重叠闪面。
- `GiantCherry()`（`:2822`）只负责实例 3 个叶块网格 + 1 个原木网格，落叶毯/步石逻辑不变。

### 3. 杜鹃

- `Azaleas()`（`:2870`）保持方块花丛（绿托 + 两层花块），与新树一致；本轮未再改。
- 花坛里的小花团仍用低模圆团（`EnsureBloomCanopies()`），因为它们是花不是树。

### 4. 远景

- `ForestBelt` / 远山的球冠是 docs/62 基线，**本轮未动**（见第四节）。

## 三、验证

- 构建：`Bootstrap.BuildWindowsBatch` 成功（Unity 2022.3.62f3c1，无编译错误）。
- 截图：
  - `shots/69f-cherry-wide.png`（樱花林入口，树干/主枝/分层叶团）；
  - `shots/69f-giant.png`（巨樱树下，2×2 粗干 + 四向主枝）；
  - `shots/69d-giant-top.png`（俯视，叶团结构与冠幅）。
- 帧率：`-fpslog` 620 帧，稳定 **59.9 FPS**（首 300 帧 7.9 属着色器编译）。
- 结构检查：樱桃/巨樱不再使用 `Canopy`、`CanopyBlob` 或任意角度长条盒；全部为等大轴对齐体素块。
