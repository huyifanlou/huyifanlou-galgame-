# 56 · 跑步动作 + 六个室内出口统一木门

作者（2026-10-27）：

> 人物加跑步动作。然后给所有内部建筑的出口加上门，不要留缝

## 一、跑步动作

- **操作**：Shift（左/右）按住 + 移动键跑步；HUD 顶部提示加「Shift 跑」。
- **速度**：走路 6 m/s → 跑步 9.5 m/s（`PlayerRig.RUN_SPEED`）。
- **动画**（`PlayerAvatar.Tick(moving, running, facing, dt)`）：
  - 新增 `_runBlend` 平滑过渡，避免走跑切换跳帧；
  - 步频 9.5 → 13.5；腿摆幅 42° → 56°；臂摆幅 36° → 52°；
  - 身体前倾 7°，头略微抬起 2°（抵消前倾，保持看前方）；
  - 身体起伏 1.0 → 1.7 倍；
  - 脚底小跳频率 10 → 13.5、幅度 0.05 → 0.075。
- **验收参数**：`-run 1` 强制跑步；`-sim s,1200` 模拟持续移动，用于拍跑步姿态。

## 二、六个室内出口加门

范围：家、教学楼、图书馆、餐厅、超市、食堂（共 6 个出口）。

- 统一走 `DoorFrame(p, it, x, z, halfW, h, face)`：
  - 门框：两侧立柱 + 门楣 + 门口地垫；
  - 门内侧门灯：暖色点光 + 灯罩，门口不再发黑；
  - 门扇：`DoorLeaf`，宽度 = 门洞 + 0.04m、高度 = 门洞 + 0.02m，
    **压住两侧门框和门楣，不留缝**；
  - 单开门：一扇；教学楼 5m 宽出口：双开门，各自盖半洞，中间加 0.10m 压条，
    盖住两扇重叠处的亮缝；
  - 细节：上下两块凹板、横向压条、踢脚板、黄铜把手、内侧合页。
- **碰撞**：门扇按 `IsWall=true` 注册 Solid，挡住门洞但不会被出口净空校验误报；
  出口仍由门内 `F` 触发传送。
- **删掉旧玻璃门**：家和教学楼出口原本各有一扇 2.2×2.5 / 4.4×2.7 的玻璃门，
  比门洞（2.4×2.6 / 5×2.8）小，四周各留约 10cm 缝，是作者看到「留缝」的根因；
  已删除，改由新木门整幅覆盖。
- 门颜色：门扇 `#8f6d50`、凹板 `#73573f`、压条 `#5a4432`、把手 `#d3b97a`；
  单开/双开、把手方向按门洞朝向自动取边。

## 四、教训

- 旧玻璃门「比门洞小一圈」就是缝的来源；换门扇必须**比门洞大**、压住门框和门楣；
- 双开门扇直接重叠会在灯光下出现亮缝/闪面，必须加中缝压条；
- 门扇碰撞用 `IsWall=true` 注册，室内出口净空校验不会把它当成遮挡物，F 出口不受影响；
- 室内门口普遍偏暗，加一盏门内侧暖光比单纯提亮门板更有效；
- 跑步不能只加速：步频、摆幅、身体前倾和起伏要一起变，否则像快走；
- `-run 1` + `-sim` 是拍跑步姿态最省事的验收方式。
