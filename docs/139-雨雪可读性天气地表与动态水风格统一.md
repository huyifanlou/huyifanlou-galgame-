# 139 · 雨雪可读性、天气地表与动态水风格统一

2026-11-16。作者反馈雨雪太小、天气切换影响弱，动态水与环境画风不协调。本轮直接修改实际天气和水材质，不增加边界外布景。

## 雨雪与切换

- 雨丝尺寸从 0.012～0.027m 调到 0.045～0.075m，发射从 1100/s 到 3600/s，分布从 34m 方形收至 24m，拉伸长度相应缩短，保留斜向下落与屋顶碰撞。近镜头消隐，避免粗雨条贴到眼前。
- 雪花从 0.035～0.105m 调到 0.12～0.26m，340/s 到 1050/s，24m 范围内分布近远雪片；降低发射高度，使第一人称眼前更快出现飘雪。增加屏幕最小尺寸以保证可读性，纹理由明显星芒收成柔和雪片，避免一屏发光星点。
- 专用 `Resources/Shaders/Precipitation.shader` 替换雨雪旧 Legacy 粒子材质：取消旧固定倍亮，颜色及雾使用一致的场景混合，消除白雪在天空前变灰暗的问题；深度软交界和近眼距离渐隐。夜间使用较暗冷色，不做自发光雪。
- 修复地面雨圈的多重低 alpha 相乘，提升实际可见度；165/s 表面取样扩散雨圈，并补短时飞溅水滴。雨圈沿用真实表面取高。
- 实际 Y 切换走 `TransitionTo`：降雨约 2 秒、降雪约 2.8 秒进入满强度；地表湿润约 3 秒、积雪约 3.4 秒形成。停止降水后保留约 24 秒渐干、30 秒渐融的过程。存读档 `Restore` 仍直接还原天气。
- 区分即时降水与地表残留：天空和水滴涟漪跟即时降雨/雪，不再因为地面还湿而继续保持雨云。

## 天气对地图的影响

雨天进一步压低直射光、冷却环境色，明显加深地表湿色；铺装有分布不均的薄水亮面，草地和叶片降低这种光滑响应，积雪表面恢复粗糙漫反射。雾和整体饱和度联动，雨天能见距离收至 16～136m、雪天 9.6～102m（14 点测试值）。雪覆屋面、叶片、路面与石沿，仍依据原有表面法线，并非实体积雪厚度。

室内保留停发/清空雨雪，天气表面响应由室内状态屏蔽；室内雾起点固定到 100m，避免更强的室外雪雾出现在房间和走廊里。

## 动态水画风

重写 `Campus/Water`：河道、池塘、水盘使用共同的灰绿色浅深水配色，按与建筑石材、植被一致的天空/地面环境色和太阳照明响应；接收真实阴影，压低强高光和大片亮色带，保留温和掠射天空色与夜灯反光。

水面用多方向、轻扭曲细波，微小波纹按风向移动。岸缘根据实际椭圆边界从浅到深，沿岸有破碎浅色细边；落雨产生分散、随时间扩散的水圈，并增强小波扰动。池塘和三层喷泉改 24 圈×128 段水网格，供小幅顶点起伏，边缘渐减以固定池岸。仍保留既有河流浮力/碰撞取高，不增加大幅水浪；场景反射仅为受控天空色与灯光响应，不是屏幕空间/平面镜面反射。

`WorldBuilder.WaterCraft` 给每块池水单独传中心/半径，喷泉各水盘不再错误套同一个池岸范围。材质和几何源都在 C# / Shader 内，无外部贴图或模型依赖。
