# 61 · 写实光影渲染（线性 / HDR / ACES / SSAO / 程序化天空）

作者（2026-10-28）：

> 现在可以改光影渲染方式了，调整为偏写实

## 一、总览：从“Gamma 直出 + 平环境光”切到写实光照链路

| 项目 | 之前 | 现在 |
|---|---|---|
| 色彩空间 | Gamma（`m_ActiveColorSpace: 0`） | **Linear**（构建脚本每次确保） |
| 相机 | HDR 开，但后处理用 `fixed` 低精度 | **HDR 线性 RT + float 后处理** |
| 色调映射 | 简单对比/饱和度，高光直接削顶 | **ACES 近似 + 曝光**（`_Exposure=1.0`） |
| 阴影 | 日光柔影 2048 / 90m；室内点光全无影 | 日光 **4096 / 140m / 0.85 强度**；室内靠 SSAO 补接触阴影 |
| 环境光 | 平坦 `ambientLight` | **三色环境光**（天空/地平/地面） |
| 天空 | 平涂昼穹贴图 + 夜穹 | **`Skybox/Procedural` 程序化天空**（太阳盘/大气渐变）+ 保留星空夜穹 |
| 后处理 | 泛光 + 移轴景深 + 分级 + 暗角 | 泛光 + **半分辨率 SSAO** + ACES + 分级 + 暗角；**移轴景深关闭** |
| 反射 | 无天空盒、无反射源 | `defaultReflectionMode = Skybox`，Standard 材质获得天空反射 |

> 美术仍是像素风；本次改的是**光照/阴影/色调/天空**，不是贴图写实化。

## 二、关键实现

### 1. 线性 + HDR + ACES

- `Game/Assets/Editor/Bootstrap.cs`
  - `PlayerSettings.colorSpace = ColorSpace.Linear`（初始化 + 每次构建 `ApplyWindowSettings` 都设置）。
  - `QualitySettings.shadowDistance = 140`。
- `Game/ProjectSettings/ProjectSettings.asset`：`m_ActiveColorSpace: 1`。
- `PostFX.shader`
  - 三个预过滤/模糊 pass 全部改 `float`/`float4`，不再用 `fixed` 截断 HDR。
  - 最终 pass 先乘 AO，再 `ACESFilm(col * _Exposure)`，然后显示空间饱和/对比/暖色/暗角。
  - 泛光阈值 1.10（线性 HDR），强度 0.08；暗角 0.18。
- `PostFX.cs`
  - 移轴景深默认 `DofMax = 0`，跳过三轮模糊（性能反而更好）；要恢复把 `DofMax` 调高即可。
  - 新参数：`Exposure`、`Saturation=0.94`、`Contrast=1.0`、`AOSStrength=0.30`、`AORadius=5`、`AOThreshold=0.55`。

### 2. SSAO（半分辨率深度）

- `PostFX` 在 `OnEnable` 里 `cam.depthTextureMode |= Depth`。
- 新建 `RenderTextureFormat.R8` 半分辨率 AO：
  - 8 抽头螺旋采样深度，比较邻域深度差（阈值 0.55m）；
  - `saturate(1 - d/180)` 对远景淡出，避免天空被压黑；
  - 两轮 5 抽头高斯模糊去噪；
  - 最终颜色在 ACES 前乘 AO。
- 参数保守（0.30），主要压家具/墙角/座椅缝隙，不制造黑边。

### 3. 三色环境光 + 更硬的日光

`TimeOfDay.cs`：
- `RenderSettings.ambientMode = Trilight`：
  - 天空色 = 天穹色 × 强度；
  - 地平色 = 天空/地面 55% 混合；
  - 地面色 = 地面色 × 0.90。
- 白天：`DAY_AMB 0.28 / DAY_HEMI 0.16 / DAY_DIR 0.95`；
  夜晚：`NIGHT_AMB 0.22 / NIGHT_HEMI 0.16 / NIGHT_DIR 0.40`。
- 阴影强度 0.95 → 0.85（保留天空填充，不再死黑）。
- 太阳 `shadowCustomResolution = 4096`；`QualitySettings.shadowDistance = 140`（Ultra 4 cascades）。
- 室内环境光仍是中性化 + ×2.1，避免室内被天光染蓝。

### 4. 程序化天空 + 星空

- `Bootstrap.SetupProject` 在 `Resources/mat_holder` 生成 `Skybox_Procedural.mat`（占位，保证 shader 进包）。
- `TimeOfDay.Init`：
  - `Resources.Load<Material>("mat_holder/Skybox_Procedural")`；
  - `RenderSettings.skybox = _skybox`、`RenderSettings.sun = _dir`；
  - `defaultReflectionMode = Skybox`（256）；
  - 相机 `clearFlags = Skybox`；
  - 关闭原昼穹 `SkyDayGo`；夜穹保留为透明星空层（月亮/星星仍由 `sky_night` 提供）。
- `TimeOfDay.Apply` 逐帧更新：
  - `_SunDisk` 白天 2（高质量太阳盘）、夜晚 0；
  - `_AtmosphereThickness` 白天 0.90、夜晚 0.40；
  - `_SkyTint` 白天深蓝 `(0.42,0.62,0.95)`、晨昏向暖色插值；
  - `_GroundColor` 与雾色混合；
  - `_Exposure` 白天 1.0、夜晚 0.10。
- **踩坑**：`PlayerRig.Init` 在 `TimeOfDay.Init` 之后又把相机设回 `SolidColor`，
  天空盒被纯色背景盖住，表现为“天空全黑”。
  已改为 `RenderSettings.skybox != null ? Skybox : SolidColor`。

### 5. 其它

- `WorldBuilder.Start` 的 `QualitySettings.shadowDistance` 90 → 140。
- `Main.unity` 由 `Bootstrap.SetupProjectBatch` 重新生成（相机/场景设置）。
- `StandardEmission.mat` 由初始化脚本重设（emission 占位）。

## 四、教训 / 后续

- Gamma→Linear 会让旧的 `_Threshold`/对比/环境光数值全部失准，必须整体重调；
  不能只改 ProjectSettings。
- HDR 后处理的中间纹理和 shader 必须用 `float`/`half`，`fixed` 会把 >1 的高光削平。
- 所有后处理 uniform 必须在最终 `Graphics.Blit` **之前**设置。
- `Skybox/Procedural` 需要占位材质进 Resources，否则运行时 `Shader.Find` 可能被剥离。
- 天空盒被相机 `clearFlags` 覆盖是典型顺序坑：`TimeOfDay.Init` 设了，`PlayerRig.Init` 又改回去。
- 当前太阳方向固定（只变颜色/强度），天空太阳盘/投影不随时间移动；
  后续若要更写实，可让太阳按小时沿天球移动，并同步阴影方向。
- 4096 阴影 + 140m 对中端 GPU 有压力；若掉帧，优先降 `shadowCustomResolution` 到 2048，
  再降 `AOStrength`/`AORadius`，不要先关天空盒。
