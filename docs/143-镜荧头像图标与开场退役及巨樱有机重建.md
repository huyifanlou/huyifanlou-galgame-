# 143 · 镜荧头像图标、开场退役与巨樱有机重建

2026-11-16。作者要求图标换女主立绘的侧脸头像、删除开场 Logo 动画，树木增加面数，巨樱摆脱倒三角并提高冲击感。

## 图标与开场

用内置 image_gen 以镜荧现有立绘为人物参考，制作银白长发、红瞳、黑冠的左向三分之二侧脸头像。身份、发色、眼色和服装领口沿用立绘，背景为深灰蓝、细香槟边框。未改原立绘。生成提示与来源完整保存在 `tools/branding/143-icon-prompt.md`，源图 `tools/branding/jingying-profile-icon-source.png`，安装到 `Game/Assets/icon.png`。

每次构建自动 `SetAppIcon`，八个 Standalone 图标槽都更新，并保留 Campus.exe 输出名。`exe-icon.png` 为直接从新 exe 原生图标资源提取的缩略图，已核对为镜荧头像；刷新了系统图标关联缓存，没有重启资源管理器。

自制开场 Logo 的 Update/OnGUI/计时和资源读取全部删除，IntroScreen 仅保留给已有 UI 判断使用的兼容接口，Live 永为 false。Resources/intro 和 meta 移到 tools/archive/143-branding/intro，旧 icon 也在该处备份；旧 `-intro` 参数不再恢复自制动画。正常启动不需要 `-nointro`。Unity 自带启动标识与游戏自制 Logo 区分记录：工程的 showSplash 设置为 false，但当前编辑器 API 回读仍为 true，不能据此宣称绕过引擎授权控制或删除引擎标识。

## 实际几何精度

- 近景叶片、花瓣轮廓从6边/7顶点改为10边/11顶点，增加卷曲边与中脊，每叶双面三角形12→20，圆润度和近景真实几何同时提高；远林继续旧低细节轮廓。
- `OrganicLimb` 采用 Catmull-Rom 曲线、平行运输截面和树皮起伏，普通树主干18边、巨樱主干28边，主枝22边，沿曲线细分。合批后释放临时网格，避免每次生成留下源 Mesh。
- 64棵近景树约1169万三角形，上一轮约653万；数量不变，原地面碰撞保持。仍是程序化精修，没有改成扫描资产或承诺 AAA 终稿。

## 巨樱轮廓

旧结构的问题是同一高度的向上放射枝和顶部半球形花冠，近看只剩倒三角。新主干有偏转、起伏和连续收细，六根主要横枝分别从2.8～7.4m高度伸出，先向侧面弯曲，再抬高末梢，保留向上生长的中轴。

花冠改成七组错位体量，共980组独立花簇，加侧枝端花簇和垂缘。低侧冠下降至约5m，中央冠上扬，整体宽约30m、高约17m；由内部与外层共同填充，底部不再是一张平齐的花冠“屋顶”。枝条与树冠都替换旧模板，未叠留旧巨樱。
