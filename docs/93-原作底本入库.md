## 怎么取到的（关键：别走阅读页）

1. **阅读页 `/reader/<id>` 的正文是字体混淆的**：实测第 9 章 1149 字里 **659 个是私用区码位（PUA）**，
   由自定义 web 字体 `DNMrHsQy…` 映射成真字。**作者登录后仍然混淆**，抓 HTML 只会得到缺字乱码。
2. **章节标题不混淆**，所以目录可以直接从书籍页 DOM 的 `/reader/` 链接里取（120 条全中）。
3. **正解是作家后台预览接口**：
   `GET /api/author/edit_article/v0/?aid=2503&app_name=muye_novel&book_id=<书号>&item_id=<章节号>&view=true`
   返回 `data.title / data.content(HTML) / data.volume_id / data.volume_data`，**明文无混淆**。
   - 该接口带 `msToken` 与 `a_bogus` 签名。**不要手拼**：在已登录页面内用 `evaluate_script` 发同源 `fetch`，
     字节的 mssdk 会自动补签名，`code:0` 直接拿到数据。
   - 直接 `fetch` 后台的 HTML 页（`/main/writer/preview/…`）没用——那是 SPA 壳，`textContent` 为空。
4. 全程只读（`view=true`），不触碰任何编辑、发布、删除操作。
