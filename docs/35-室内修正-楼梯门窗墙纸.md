# 35 · 室内修正：楼梯挡墙、门扇、墙纸补漏、FP 地图、教室座位

作者反馈：学校楼梯有墙挡住；家门旁边的窗子卡墙；室内要有门且不留缝；部分墙面没贴纸、墙纸没贴完整、装饰物撞墙；第一人称无法打开地图传送；教室座椅间距要拉大均匀。

## 一、学校楼梯（根因：挡墙通高 + 出生点落在门边墙的碰撞带里）
- 楼梯东侧挡墙原来从楼梯脚（z=2.6）一直立到顶——把入口挤成一条缝。现在**一层只挡北段（z 3.4..7.0）**，南段留作入口；二层通挡（防掉落）。西侧补了二层挡墙。
- 楼梯低端 2.6 → **2.55**，紧贴走廊墙消除 0.1m 夹缝。
- 挡墙多了个副作用：楼梯东侧 x=905.2 的挡墙（家）与门边墙stub会把直线行走的人挡住——家楼梯从**楼梯间西侧进**（走廊东段开敞），学校楼梯走**专用门洞（x -16.4..-15.0）**。
- **走路模拟验证**：`-sim w,900` 从走廊 (1044.3, 1.0) 一路 W → 穿过楼梯间门 → 上楼梯 → 终点 **(1044.3, 4.02, 7.55) = 二层楼梯厅** ✓（日志 `[ShotMode] player=`）。

## 二、家门口的窗
- 玄关窗原来在 x+2.7（0.8..2.4 与大门 -1..1 距离过近，视觉上"卡门框"）。挪到 **x+5.6**（鞋柜东侧空墙），与大门/后门完全错开。

## 三、室内加门（不留缝、完全贴合）
- 新增 `Doorway()` 原语：门框三边料外缘与洞口严丝合缝、门扇铰链在洞口左缘、半开 40°，几何尺寸全部由洞口宽高推导——**没有任何独立缩放**，不会出现缝。
- 家：9 扇内门（客厅/餐厨/走廊→家务/客卫/储藏 + 二层主卧/起居/次卧/书房/卫生间/衣帽间）+ 大门/后门深木色门扇。
- 教学楼：12 扇（四间教室 ×2 层、多功能、楼梯间、办公室、图书角）。
- 门扇只做视觉（半开贴墙侧），不参与碰撞——门洞本来就是通的。

## 四、墙纸补漏 + 装饰物裁剪
- 根因：`RoomSkin` 只贴房间**内墙**的里侧；**外墙的里侧**（一层/二层的西、东、南、北外墙内表面）整个裸着水泥底色。
- 新增 `WallDeco()`（墙面薄片按洞口列表裁剪成多段），把家的一层/二层四片外墙内表面全部补贴（客厅/餐厅/厨房/卧室各用对应壁纸），窗洞、门洞处自动断开。
- 教室墙裙改走 `WallDeco`：走廊侧绕开门洞（含门框宽度 0.09 余量），不再出现墙裙压门。
- 校验：`[Interior:home] 82 个碰撞盒，问题 0 处；[Interior:school] 136 个，问题 0 处`（东端多功能教室课桌越界一并修掉：列数 3→2）。

## 五、第一人称开地图
- 根因：FP 锁鼠标后 OnGUI 收不到点击；且室内直接 `mm.enabled=false`。
- 现在：**M 打开大地图时临时解锁鼠标**（`UnlockCursor`，FP 分支检测 `LargeOpen` 让位），关图回锁；**室内也能看地图**（顶部提示"室内 · 地图仅查看"，点击传送禁用，出门后再传）。

## 六、教室座位
- 3 组×2 排 → **3 列 × 4 排 = 24 座**，列距 ≤2.6m、排距 ≤1.3m（按教室宽深自适应），走道 ≥0.8m；东端 6.2m 宽教室 2 列。
- 桌椅碰撞盒同步（组宽 1.32、含椅深 1.22），校验 0 问题。
