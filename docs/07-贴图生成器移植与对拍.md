# 07 · 程序化贴图生成器移植 C# 与像素对拍（2026-10-16）

## 进展

`tools/source/textures.js`（20 余种程序化贴图）已整体移植为 `Game/Assets/Scripts/TextureLibrary.cs`：
mulberry32 随机、Canvas2D 常用原语（fillRect 含**亚像素覆盖率抗锯齿**、fillCircle、roundRect 描边、圆弧描边、
source-over alpha 混合）与全部贴图绘制流程 1:1 复刻。

**对拍工具**：
- 导出器改为「每张贴图独立种子」（与 C# 的逐张 NewR 对齐）
- Unity 菜单「Campus/导出 C# 生成贴图（对拍用）」→ `Game/Build/gen_tex/`
- 与 `assets/tex/` 逐像素比对
