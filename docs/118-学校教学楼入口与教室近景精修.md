# 118 · 学校教学楼入口与教室近景精修

2026-11-14。接 docs/117，按区域进入第二轮：本轮集中教学楼外入口、门厅、走廊和四间教室。没有改剧情、出生地或游乐场封闭规则，没有提交或推送。

## 做了什么

- 48 张课桌替换原实心桌斗和方杆腿：分层包边桌面、朝椅子的开口桌斗、圆管支架、横撑及橡胶脚帽；部分桌面有封皮/纸页/书脊/标签分离的课本、笔，部分桌侧挂织物书包。新部件在原桌椅碰撞范围内。
- 四块黑板替换旧板面组件：金属框、哑光板面、粉笔槽、粉笔、板擦、数学板书和实体函数曲线；原黑板及粉笔槽没有重复保留。
- 四个教室入口补木门套与实际班级文字，门洞保持敞开。七块走廊公告栏的彩色占位纸替换为带图钉、行文和栏目标题的纸张。文字贴近实际牌面，避免浮在墙上方。
- 门厅前台补石质台面、正面木格栅、金属压条、来访登记牌和课本；替换原台面。入口两侧木饰面、地面细嵌条加强空间收口，不形成高度障碍。
- 教学楼外侧补门廊柱础/柱头/细槽、檐底格栅、浅嵌灯、两侧铜框牌及中央钟面构图。装饰尺寸保持在已有门廊柱体阻挡范围内，未增加点光源。
- 修复四个讲台原来没有注册碰撞的问题，教学楼自定义碰撞从 87 增至 91。

专用资产在 `InteriorBuilder.SchoolCraft.cs` 和 `WorldBuilder.SchoolCraft.cs`；由原构建函数调用，共用 docs/117 的材质缓存、圆角网格和室内材质合批。其他学校建筑与其他区域的独有资产仍需后续分轮精修。
