# 27 · 窗口尺寸可调 + 鼠标视角回退

## 一、屏幕自适应改为可调窗口
- 不再强制全屏启动：默认 **1600×900 窗口**，窗口边缘可拖动调整大小（PlayerSettings.resizableWindow = true）。
- **F11** 在窗口 / 全屏之间切换；从全屏切回时恢复到 1600×900。
- `-shot` 验收模式仍保持窗口，便于自动截图。

## 二、鼠标视角回退
- 撤销“锁定鼠标 + 移动转向 + Alt 呼出”的方案，恢复原来的手感：
  - 鼠标**可见**，按住左键拖拽旋转视角（右拖视角右转、下拖俯视）；
  - 滚轮缩放（6~22m）；
  - Q/E 90° 步进；
  - 小地图直接点击即可传送，不再需要按住 Alt。
- HUD 提示已更新为“拖拽 视角 ｜ 滚轮 缩放 ｜ F11 全屏 ｜ M 放大地图 …”。

## 三、保留
- 圆形小地图、M 放大/缩小、点击传送不变。
- 天空黑幕、廊桥屋顶、地面铺装层级、锁帧/灯光裁剪等上一轮修正不变。
