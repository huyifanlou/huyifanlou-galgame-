## 一、范围

  奶油色短发、中分刘海、深色眉/睫块、2×2 眼、无嘴无鼻、猫耳发尖；

  - 衣服：参考的女式水手裙 → 既有的**男主藏青西装校服**（白衬衫、红领带、深蓝长裤、黑鞋）；
- **不动身份**：仍是男主樊楼（男高中生），金发长裙是觉醒后的女体形态（docs/49），不在本轮范围。

## 二、脸贴图：参考 8×8 正面逐格放大到 64×64

参考皮肤的正面是 8×8 像素格，本作脸贴片仍是 64×64，所以每格放大 8 倍（1 格 = 8×8 texel）：

| 行（自下而上） | 内容 |

| 8（y=56/48/40） | 刘海三排：两侧奶油色、中间浅色高光带，右端加深 |
| 5（y=32） | 中分：左侧三格发、中间两格露额、右侧发+深色边 |
| 4（y=24） | 眉行：深色 `#50483f` 两格 + 中央露肤，两侧发际 |
| 3（y=16） | 眼上排：外深边、眼白、蓝虹膜、中央鼻梁肤色、镜像 |

| 1（y=0） | 下巴行：两侧发梢 + 整片肤色 |

- 参考脸**没有嘴和鼻子**，本版忠实保留（近看是“无口”MC 皮肤）；
- 64×64 仍是平涂大色块 + Point 过滤，不做渐变，避免又滑回 docs/50 的写实脸。

## 三、脸材质改 Unlit

- 之前 Standard + 自发光在正午仍被发盖阴影压成暗褐色，和参考的淡肤色差太远；
- 脸贴片改用 `Unlit/Texture`（MC 皮肤常用做法），淡肤色 `#ffe9dd` 与蓝眼在背光/低头时也保持参考亮度；
- 代价：脸不随昼夜变暗，属于已知取舍；后续若要夜景压暗，可换成自写顶点色 shader。

## 四、3D 头发：奶油猫耳短发

- 发色整体压深到参考值：`#d5bda4` / 高光 `#e9d5ba` / 暗部 `#bda58d`
  （原先偏白的 `#ddc7b0` 在天空前会糊成白色）；
- 自发光从 0.22 → 0.10，暗部从 0.12 → 0.06，避免发盖亮成塑料；
- **删掉 3D 刘海楔块与发唇**：正面贴图自身已画好中分刘海，再叠 3D 楔块会在额头形成
  深色“蝴蝶结/胡须”阴影（上一版实拍问题）；现在 3D 只负责头顶、鬓发、后发体积；
- 猫耳加大：底宽 2.2→2.8px、高 2.6→3.0px、外倾 18°→14°，内耳前移到耳面之前，
  正面能看出耳廓；
- 后脑：底板改用暗发色，另加 3 缕错落锥形发缕（backStrandL/M/R），
  打破第三人称最常见的“木板后脑勺”观感；
- 侧发/鬓角/后颈的收窄锥形沿用 docs/52。

## 七、教训

- **参考皮肤的刘海已经画在贴图里**：再叠 3D 刘海必出暗楔块，3D 只做轮廓；
- 淡肤色脸用 Unlit 才稳得住；Standard 在这种“脸朝侧面光”的场景里会被头发阴影压黑；
- 奶油发色要压深一档，否则在天空/白墙前会读成白色头盔；
- 第三人称游戏里后脑出现频率最高，平板贴片必须加错落发缕，否则像木箱；
- 参考图是女角色，但本轮只借**头/发**，眼睛和衣服按男主设定替换。
