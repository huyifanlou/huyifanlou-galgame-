# 33 · 光照修正：背光面与角色正面

作者反馈：光影有问题，**人物正面在背光面太黑**，朝南/西看整条林线是剪影。

## 一、根因：那盏"北向补光"照错了方向

`TimeOfDay.Init` 里本来就有三盏灯：主太阳、SkyFill（天空色）、NorthFill（补背阴面）。问题出在 NorthFill 的旋转：

```csharp
fill.transform.rotation = Quaternion.Euler(22f, 200f, 0f);   // 旧
```

平行光是沿 `transform.forward` 射出的。这组角度算出来的 forward ≈ **(-0.32, -0.38, -0.87)**，和主太阳的 (-0.53, -0.76, -0.38) 在**同一个半球**——也就是说它照的是同一批面，等于把主光又加了一遍。朝北/朝西的面（-X、-Z 法线）**一点光都没多拿到**，所以背光面依旧死黑。

## 二、改法

### 2.1 补光方向掉头
```csharp
fill.transform.rotation = Quaternion.Euler(26f, 22f, 0f);    // forward ≈ (+0.30, -0.44, +0.84)
```
光线射向 +X/+Z，正好照亮 -X/-Z 的面。强度 `0.18 → 0.22`（白天）/ `0.12`（夜晚），颜色仍取天空色（冷），不投影。

> 强度一开始试到 0.45，整个场景被抹平、草地看着像塑料；0.22 是"能看清结构、又保住明暗对比"的位置。

### 2.2 角色单独加一点自发光
背光时角色的脸还是偏暗（精灵是一张朝相机的四边形，背面就是不受光）。给角色材质加 `_EMISSION = 0.16`（用主贴图调制）：

```csharp
MatLib.Sprite("player", 0f, 0.16f)
```

这样无论太阳在哪一侧，主角的轮廓和五官都读得出来，而且不会在夜里变成发光体。

## 四、遗留

- 草地在夜里偏绿偏亮（夜晚环境光 0.40 本来就这么设的），要更"夜色"可以压到 0.32，但会连带压暗建筑。
- 时钟塔这类深色大体的背光面仍然偏暗，属于材质本色，需要单独提亮材质而不是动全局光。
