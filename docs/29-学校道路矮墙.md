# 29 · 学校区域道路矮墙（入口留口）

作者要求：学校区域道路两旁加矮墙，但不能挡住建筑入口。

## 实现
- 矮墙沿以下学校区域道路/步道两侧布置（`TownData.BuildSchoolWalls()`）：
  - 中央街（学校段，x=-45，z -92…-26）
  - 西环路北（学校段，x=-84，z -76…-26）
  - 学校北支路（z=-71）、学校西支路（z=-54）、学校东支路（z=-45.5）
- 墙位：车行道放在人行道外（路宽/2 + 1.9m），步道放在路缘外 0.8m；高 0.6m + 压顶 + 立柱，和原校园的矮墙同一套构件。
- **自动留口**：
  - 每条横向道路/步道交叉处，按对方宽度 ±1.3m 留口；
  - 每栋 `s_*` 学校建筑的正门位置，投影到墙线上 ±1.5m 留口（只处理门在 4.5m 内的墙）；
  - 中央街西侧另留 6m 学校大门（z -34…-28，门卫旁）。
- 已有的门洞、台阶、绿篱都不受影响。
