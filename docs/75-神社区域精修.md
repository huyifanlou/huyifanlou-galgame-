# 75 · 神社区域精修（路灯、小摊排布、摊位样式、周边细节）

作者（2026-10-31）：

> 神社附近区域可以精修了，比如路灯和小摊排布，小摊样式，周围细节等，进行联网搜索

## 一、查到的做法

日本神社祭典（縁日）的常见构成：

- **屋台（yatai）沿参道两侧成排**，正面朝向参道/广场，中间留出通行带；
  食品类（章鱼烧、炒面、苹果糖、刨冰、饮料）和游戏类（捞金鱼、射的、水风船、面具）混排。
  参考：https://www.haradaeigo.com/japanese-culture/w/yatai 、https://www.japan-guide.com/e/e4803.html
- **提灯（chochin）**是祭典和神社参道的主力照明：摊位檐下一排纸提灯，
  参道上空拉串灯，鸟居/社殿前挂大红提灯；神社参道本身以**石灯笼**为主，不用现代路灯。
  参考：https://www.jeepe.jp/zh/articles/what-is-chochin-1757
- 神社附属设施：狛犬、手水舍、绘马架、御神签、赛钱箱、酒樽、社务所、幟旗、祭典告示板。

## 二、改动内容

### 1. 小摊排布（TownData.cs）

- 原先是东西向散放的 6 个摊位，南侧一排朝向错误（背对街道）。
- 现在**两排各 5 个、隔着祭典街相对**：
  - 北排 `z=-52.8`，面朝 +Z（广场）；南排 `z=-39.2`，`ry=π` 面朝 -Z；
  - 西段 x = 62.6 / 67.4 / 72.2，东段 x = 86.0 / 90.6，**中间 x74~84 的参道完全让空**。
- 全部摊位正面朝向街道中心，从参道望过去两侧摊位正面可见。

### 2. 小摊样式（WorldBuilder.cs）

- 新增 5 种品类配色与招牌：章鱼烧、炒面、苹果糖、射的、水风船；
  连同原有捞金鱼、面具、刨冰、饮料、杂货共 10 种。
- 雨棚分 3 种样式（条纹/素色/深色边）。
- 摊体补充：后帘 + 侧帘、棚下 3 只提灯（红/暖白交替）、前横杆、
  A 字菜单板、保温箱、两只木箱、煤气罐、食物摊加一只凳子、垃圾桶。
- 摊位侧面插幟旗。
- 品类道具：
  - 章鱼烧：铁板 + 9 颗丸子 + 酱瓶 + 托盘；
  - 炒面：铁板 + 面条堆 + 铲子 + 调料瓶；
  - 苹果糖：5 串插在架上的糖苹果；
  - 射的：3×5 奖品架 + 两把软木枪 + 靶子；
  - 水风船：蓝色水箱 + 7 只水球 + 2 个捞网。

### 3. 路灯改为神社照明（TownData.cs / WorldBuilder.cs）

- 删除祭典街 3 盏、参道 2 盏现代路灯（原来还有一盏正好压在参道中轴 x=78）。
- 改为：
  - **石灯笼 6 座**（`lantern` 道具，参道两侧 x=72.3/85.7，z=-56/-60，以及手水舍、社务所前各一）；
  - **提灯串 4 道**（参道上空两道横跨 x=79、z=-52/-57；祭典街两端各一道纵跨 z=-46，x=65/93）；
  - 鸟居挂**两只大红提灯**（x=±3.0，y5.55）和注连绳 + 5 枚纸垂；
  - 拜殿檐下 4 只提灯 + 暖光点光源；
  - 御神签架、社务所各挂小纸提灯。

### 5. 碰撞

- 新增道具全部登记 `BlockerDef`：石灯笼 0.4、狛犬 0.55、绘马架 1.3、
  御神签 0.6、社务所 1.5、手水舍 1.0×0.8、酒樽 0.8、赛钱箱 1.2×0.6、
  告示板 1.3×0.5；提灯串只挡两根立柱（0.18）。
- 参道中轴 x74~84 无障碍，可从鸟居直走到拜殿。
