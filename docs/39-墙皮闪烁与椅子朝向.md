# 39 · 室内"浮空布"真相：墙皮 z-fighting + 椅子朝向

作者反馈（2026-10-26 下午）：
1. 家里有块布浮空、椅子多了一个
2. 教室有布挡住、教室椅子朝向应该朝黑板

## 一、"布"其实是**墙皮和墙共面导致的 z-fighting**

两张截图里那块"布"——家里那块绿色/灰色大平板、教室里那块蓝灰色大平板——
都不是独立物体，而是 **`WallDeco` 墙皮与墙体共面**，两层面在同一深度互相争夺像素，
整面墙在闪，看起来就像挂了块抖动的布。

根因：`WALL_IN = 0.18`，墙半厚正好 **0.09**；而墙皮偏移也写成 **±0.09**（学校）和
**1.91 / 2.09**（家的 z=2 隔墙，2±0.09），**完全重合**。

修法：所有内墙墙皮一律再往房间内让 0.02m（错层）：

| 位置 | 原偏移 | 新偏移 |
|---|---|---|
| 家 z=2 隔墙（南面） | 1.91 | 1.89 |
| 家 z=2 隔墙（北面，4 段） | 2.09 | 2.11 |
| 家竖隔墙 x=ox±9.4 / -2.2 / +3.4 两侧（6 处） | ±0.09 | ±0.11 |
| 学校走廊墙教室侧 | ZC0+0.09 | ZC0+0.11 |
| 学校教室隔墙两侧（3 组 × 2 面） | ±0.09 | ±0.11 |

共 14 处。**外墙**（`WALL_OUT = 0.24`，半厚 0.12）本来就是 ±0.14 / 0.02 错层，不受影响。

> 这条在 `.zcode/memory/handoffs` 的 Pitfalls 里记过（"装饰/踢脚线与墙纸薄片共面会 z-fighting"），
> 这次是单层重建时新写的墙皮又犯了同一个错。**以后写任何贴面，偏移必须 > 半墙厚 + 0.02。**

顺带：教室**侧墙墙裙**原来放在 ±0.03，比墙皮（±0.11）更靠里，被墙皮盖住看不见 →
挪到 ±0.19，现在四面墙的绿色墙裙都露出来了。

## 二、多出来的餐椅

餐桌 2.4×1.1，原来摆了 **6 把**椅子：四边各一把，外加两把塞在 (ox±1.9, z=-5.6) 的桌角外，
既不在桌边也挡过道。
→ 只留 4 把（四边各一），并贴近桌边：南北 z=-5.05 / -3.35，东西 x=±1.55。

## 三、教室椅子朝向

两个错叠在一起：

1. **朝向反了**：`Chair` 的靠背在局部 `-z`，`ry=180` 时靠背朝 +z（黑板侧），人背对黑板。
   黑板在 `zFront`（z 较大一侧），学生要朝 +z → `ry` 应为 **0**。已改。
2. **椅子摆在桌子朝黑板的一侧**：原来 `Chair(z + 0.66)`，比桌子更靠近黑板，
   等于人坐在桌前、桌子在身后。改成 `Chair(z - 0.62)`（桌子远离黑板的一侧），
   人朝 +z 正好面向桌子与黑板。碰撞盒同步改成 `z-0.92 ~ z+0.22`。

## 四、沙发悬空

`Sofa()` 座面从 y=0.20 起、没有底座，远看像浮着。补一段 0.22 高的深色底座（y 0~0.22）。

## 七、追加：作者说"没有变化"，其实是走廊不是教室

作者下一张截图仍是一面大蓝灰墙。对照后发现**他站的不是教室，是走廊**——
正对 56m 长、4.2m 高的南墙。教室那侧的修正对他看到的画面当然没影响。

走廊墙原来只有一层蓝灰墙纸，什么都没有，远看就是一块大布。三项改动：

1. **墙裙 + 压条 + 踢脚线**（两侧墙，0~1.2m 墙裙 `#b6c0b2`、1.20~1.27 压条 `#8b968a`、
   0.02~0.14 踢脚线 `#5f4a38`），全部用 `WallDeco` 带门洞数组，不会盖住门。
2. **墙纸条纹改宽改淡**：`in_wall` 原来每 12px（≈8cm）一道竖条、`in_wall2` 每 10px（≈6.6cm），
   在 3m 距离上密集到像织物纹理——这就是"像布"的根因。
   改成 **48px / 56px**（≈32 / 37cm）且透明度减半，现在读作"刷漆的墙"。
3. **公告栏 7 块**（1.7×0.95，y=2.20，间距 8.4m）+ 教室门上方门牌 4 块，打断大片空白。

实拍：`shots/39-cor-along.png`（沿走廊看，墙裙/公告栏/灯/门都到位）、
`shots/39-cor-s.png`（正视墙面，不再像布）。
