# 63 · 远山与林带（边界缓坡 / 贴坡灌丛 / 林毯形态）

作者（2026-10-28）：

> 远处的山和树需要优化

从商店街顺着街口往西看，山脚有一整条**光滑的深绿带**：没有树、没有灌木，整面坡像一块塑料。
贴近看（`-px -120 -pz 27`）更明显——草皮从脚下一直铺到林线，中间没有任何细节。

## 一、根因（两层）

1. **镇界外有一道 3~4m 陡坎**。`RimH` 在 r=128（可行走边界）立刻叠加 44m 主峰的 Gaussian，
   局部坡度过 30°。坡上即使种了 1~3m 的灌丛，从坡下平视时也会被**上一级坡面自身**完全挡住，
   只剩坡底一排和坡顶一圈露出来 → 视觉上就是一条光板。
2. **早期“林缘灌丛”用了 2~4m 的大扁球**（sy=0.5）沿坡叠放，扁球侧面在坡面上互相拼接，
   形成一堵连续的光滑“绿墙”，把后来补的小灌丛全挡在后面。

## 二、改法

### 1. 边界缓坡（`WorldBuilder.RimH`）

界外 30m 内让山体高度渐入：

```csharp
h *= Mathf.SmoothStep(0f, 1f, Mathf.Clamp01((r - 128f) / 30f));
```

陡坎摊成缓坡，既不再挡光，也消除了“镇子被一圈土墙围住”的轮廓。

### 2. 贴坡小灌丛（`MountainDetail`）

- 删除 2~4m 大灌丛层；
- 新增一层贴坡小冠层：r 125~200、h ≤ 10m、半径 1.2~3.0m、85% 密度，从镇界草地一直铺到林线；
- 保留坎脚碎石。

### 3. 林毯形态（`MountainDetail` 主循环）

- 主林毯从 r=158 起（陡坡段不再铺大扁球），h<8 交给小灌丛；
- 高度 <32m 一律改用**圆冠/灌木形**（sy 0.5~0.68，半径上限 3.6/5.2m）；
- 陡坡检测（±2.5m 采样）超过 2.2m 时同样改用圆冠，避免扁球侧面在陡面上连成暗墙；
- 只有 32m 以上的远峰保留扁林毯（sy 0.34~0.46，y 抖动 ±0.3，混入 35% 圆冠和第二种更碎的冠形）。

### 4. 叶材质轻自发光（`WorldBuilder.LitTinted`）

叶簇材质加 6% 自发光（`_EmissionColor = color * 0.06`），背光树冠不再压成纯黑剪影。

## 三、验证

```bash
# 商店街看西侧山脚（原来那条光板带）
Campus.exe -px -40 -pz 27 -at -140,27 -fp 1 -pitch -0.02 -shot shots/63-shop-street.png
# 镇界平视（原来整面坡全裸）
Campus.exe -px -80 -pz 27 -at -200,27 -fp 1 -pitch 0.02 -shot shots/63-hill-80.png
# 河东看两岸林带
Campus.exe -px 100 -pz 0 -at 240,0 -fp 1 -pitch 0.04 -shot shots/63-east-ridge.png
# 学校北侧山脊
Campus.exe -px 0 -pz -40 -at 0,-220 -fp 1 -pitch 0.04 -shot shots/63-north-ridge.png
```

- 四组截图里山脚光板带全部消失，坡面由灌丛、碎石、树冠分层铺满；
- `-fps 1` 实测：渲染器 4201 / 顶点 9.49M / 灯光 107，与改前同量级（新增灌丛 ≈1.2 万实例，全部合并进既有网格）。

## 四、取舍

- 32m 以下的圆冠比扁林毯更“鼓”，远看层次略碎，但近-中距离不再出现叠盘子/瓦片；
- 东侧河岸是背光面，林带仍偏暗（自然阴影），只靠 6% 自发光提了一点暗部。
