# 52 · 男主短发美化（锥形发盖 / 斜扫刘海 / 竖发丝纹理）

作者（2026-10-27）：

> 头发要修改，看着太方正，需要美化

## 一、问题

docs/51 的短金发是一整块 8.6×1.5×8.6 的方发盖 + 直立方块鬓角/后发：
正面像一顶方帽子，侧面/背面是直角方块；纯色块没有任何发丝，近看是塑料感。

## 二、改法

### 2.1 轮廓：用锥形块替代直立方块

- `MeshFactory.TaperedBox` 新增 `HairVolume()` 创建锥形发块（pivot 在下端，向上变宽/变窄）；
- **发盖**：8.3×8.3 底 → 6.8×6.8 顶，高 1.5px，前倾 3°；顶面收窄，侧面是斜坡而不是直角；
- **头顶**：5.8×0.5×5.4 错层小块（z 轴 -4°），加一个小锥形呆毛，顶部不再是平板；
- **两侧**：0.6 宽底 → 0.9 宽顶、高 4.8px 的锥形侧发，往下收，不再是整条方柱；
- **鬓角**：0.35 宽尖 → 0.8 宽根、高 2.7px 的锥形，收在下颌附近；
- **后颈**：4.8 宽底 → 6.4 宽顶、高 2.8px 的锥形后发尾，后脑下缘收窄，另加 4.8×0.2 的封底小片。

### 2.2 刘海：两把斜扫锥形发束

- `fringeLeft`：根部在侧分线（x=0.8），高 4.5px，沿 z 轴 105°斜扫向左鬓，尖端收细；
- `fringeRight`：根部 x=2.0，高 2.0px，沿 z 轴 -100°斜扫向右额角；
- 上方留一条 7.8×0.2 的超薄发际连接片，填补发盖与发束之间的缝；
- 刘海不再是三块竖着的小方片，也不会出现尖刺（斜扫发束的尖端只有 0.2px 宽）。

### 2.3 表面：32×32 程序化竖发丝纹理

- `HairTexture()` 生成 32×32 竖纹：8 格一组的宽窄深浅发丝，`Repeat` 平铺；
- 只做竖纹，不加斜线/横纹——上一版 16×16 的斜线平铺后像竹篮，已移除；
- 两种材质：`_hair`（原色）与 `_hairD`（0.78/0.72/0.55 压暗），用于发盖/后颈/鬓角的层次；
- 发丝纹理平铺尺度 0.25m，近看是像素发丝，不是纯色块。

## 五、教训

- MC 方块头想“不方正”，靠**锥形块（TaperedBox）**改轮廓，比堆直立方块有效；
- 刘海用**斜扫的锥形发束**，根部在侧分线、尖端收细，能避免“小方片”和“尖刺”两个极端；
- 发丝纹理只做竖纹；斜线 + 平铺会变竹篮，横纹会变梯田；
- 侧发/鬓角/后颈都往下收窄，正面和背面的外轮廓才不是直筒；
- 脸保持 8×8、发型做层次，两者不冲突：作者要的是 MC 风格，不是低质量方块。
