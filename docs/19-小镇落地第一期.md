# 19 · 小镇落地第一期（Unity 原生重建）

作者指令：**不再参考 web 版的参数/几何/材质**（会限制引擎），小镇按 Unity 原生方式重建。
本文件记录第一期（地形水系 + 路网 + 建筑体块 + 地标）的落地内容、与总平面 V5 的对应关系、验收方式与后续。

## 一、决策：去掉 web 对位，改成 Unity 原生

| 项目 | 之前（web 移植期） | 现在（小镇原生） |
|---|---|---|
| 地面 | 一张 280m 平面 + 贴图 | 河道处断开的地形条带，河床下沉 **1.95m** |
| 水 | 贴地半透明面（池塘贴图） | 独立水面网格（世界 UV、流动）、河床、石护岸 |
| 桥 | 平面条 + 贴图 | **真实拱券网格**（拱洞由 MeshFactory.ArchFace 挖出）+ 拱券石 + 桥墩 |
| 道路 | 单一平面 + 压边条 | 车行道 + **12cm 抬高人行道** + 路缘石（路口自动断开） |
| 人物 | 恒定 y=0 | `WorldBuilder.GroundY()` 脚底跟随人行道/桥面 |
| 建筑 | 12 栋校园建筑配方 | 46 栋按总平面排布，立面纹理按世界比例；平屋顶改深色防水 + 女儿墙 |
| 世界 | 校园（±60m） | **小镇 220×220m（±95m）**；`-campus` 可切回校园做对照 |

web 版源码与本仓库历史仅作为资产配方参考；**小镇的数据/几何/材质不再以 web 参数为准**。

## 二、已实现（对照 docs/18 总平面 V5）

- **水系**：S 形河道 `z = 10·sin((x+40)/34)+2`、宽 16m；水面在 -1.95m，石护岸高 2.45m（砌筑缝贴图）+ 浅色压顶；两岸滨河步道（距中心线 12.5m、宽 5m），水面 UV 缓慢流动（`WaterFlow`）。
- **三座桥**：
  - 主街石拱桥（x=0，11m 宽，3 孔）
  - 中央街石拱桥（x=-45，5m 宽，2 孔）
  - 东段木廊桥（x=28，6.5m 宽，单孔木构 + 瓦顶 + 顶棚）
  - 石桥面片为真实网格拱洞（内外面都有），拱券石沿椭圆内缘一圈，桥墩压住跨与跨的接缝；石栏杆 + 望柱 + 压顶。
- **路网**：12 条（主街 11m 石板 / 中央街与环路青砖 / 老街商街 8m 旧石板 / 住宅北街·中街 / 车站街·车站路 / 公园联络路 / 夏日祭参道 12m / 神社石阶）；路口铺装盖住人行道断口；有路缘石与人行道的道路在交叉口自动留口。
- **建筑 46 栋**（含主角家）：
  - 学校区：宿舍楼（单栋）、教学楼、图书馆、实验楼、食堂、礼堂、看台、门卫、操场（跑道贴图）
  - 骑楼老街 6 栋、河东住宅四排（店铺 / 合院·两层小楼·平房 / 单元楼 4·6·5·4 层）
  - 神社（本殿/拜殿/手水舍 + 鸟居）、车站（站房/站台/站前广场/停车场/货场/铁路）
  - 游乐场：售票处/碰碰车/鬼屋/茶座/游戏摊/小吃街 + 摩天轮（旋转）/旋转木马/飞椅/跳楼机/小火车/大摆锤/马戏棚/冰淇淋车/小舞台/卡丁车
- **地标**：钟楼广场 + 钟楼（四面钟面）、鸟居、铁路（道砟/枕木/双轨）、夏日祭摊位 10 个。
- **植被**：樱花林、公园点景树、河畔柳树（16 株）、主街行道树、边界林带；灌木 110 / 花 150。
- **光照**：新增北向补光（抬起背阴立面），环境光 0.175；水面光滑度 0.38（去掉了大面积白色高光）。

## 三、校验

新增编辑菜单「Campus/校验小镇布点」（`WorldValidator.TownBatch`），直接对 `TownData.Build()` 运行 docs/18 的四条净距规则：

1. 建筑 ↔ 道路 ≥1m（含 3m 步道，斜向按 1m 采样）
2. 建筑 ↔ 河道中心线 ≥16m
3. 建筑 ↔ 建筑 ≥0.5m
4. 道路/步道不得压河面（桥位除外；桥宽按实际）

```
[Unity] -executeMethod WorldValidator.TownBatch
[TownValidator] ✓ 小镇校验通过：建筑 46 栋 / 道路 12 条，零违规
```

世界切换：默认小镇；命令行加 `-campus` 回到原校园（对照用，校园配方未改）。
