## 一、世界观（事件导演硬约束 —— LLM 生成剧情/事件时必须遵守）

- **两界**：人界 ⇄ 异界。两界合作自古在暗处进行；"公开日"（全球发布会）后正式向大众公开。
- **觉醒机制**：百年前两界大能设大阵压制觉醒能量；阵法将在公开日解除，溢出能量催生"新世界"。暗阵令多数人在 15 岁左右觉醒——所以觉醒者以高中生为主；刚觉醒者不会用能力也不自知。
- **等级**：S / A / B / C，仅代表能力稀有度，实力看后期修炼。S 级以上"特殊个体"的信息会被学校与官方隐藏（对外显示假信息）。
- **界府**：明部（公开治安，尚在磨合）+ 暗部（高危任务，原班人马）。
- **异界**：人人会魔法、侧重不同；中间地带每三个月清理魔物，兼作觉醒者试炼场。
- **修真者**：极神秘，几十年难见一次；百年前大阵思路来自他们（代表："妾身"）。
- **称谓约定**（导演生成对话必须遵守）：觉醒者＝能力者；镜荧称樊楼"帅哥/樊楼"；瑶清寒称"楼"；景楠称"樊楼/瑶妹子"；莉莉雅正式时称镜荧"镜荧大小姐"、生气时直呼"镜荧"。

## 五、文风指南（事件导演生成文本时遵守）

- 基调：轻小说式吐槽日常 + 群像相声 + 少量信息密集的设定章
- 对话风格：镜荧＝脱线挑逗；瑶清寒＝冷面毒舌短句；景楠＝话痨吐槽；莉莉雅＝礼貌但（对镜荧）腹黑
- 章节结构参考：日常场景 → 笑点/互动 → 设定或伏笔埋设
- 禁区：变身能力不走悲情路线（它是笑点与关系催化剂）；不出现暴力/不良内容
