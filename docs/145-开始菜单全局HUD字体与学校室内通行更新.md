## 进入游戏与 HUD

普通桌面双击先进入交互开始菜单，不再直接进入地图：有有效存档显示“继续游戏”，无档显示“开始游戏”，另有“新游戏 / 设置 / 退出”。继续读取最近有效的自动或手动档；新游戏从家中、第一章、第1天8点开始，清主支线与自动档，手动档保留，有现存档时在界面二次点击确认。开始菜单里可以设置字体后返回，设置的画面页也可返回开始界面。

沿用 IntroScreen.Live 作为已有输入/HUD暂停判断，现指开始菜单状态，未恢复旧 Logo 动画。验收用 -px/-indoor/-scenario/-shot/测试参数跳过菜单；-startmenu 强制显示，普通无参数启动总是显示菜单。

顶部旧整幅深色条替换为独立标题、日期天气、操作按钮卡片，左上主支线卡换成浅色纸面与统一字体。底部常驻探索按键提示，顶部按钮也有提示，读取 GameInput 的当前绑定，改键后会更新；Esc保持固定设置/返回。遮挡鼠标的 HUD 区域同步调整，原进出建筑按钮保留。

## 手记重置与存档兼容

手记的主线/支线页各自有重置按钮，二次点击确认，提示具体影响。主线重置回家及第一章，保留支线和手动档；支线重置清完成、追踪、停留计时，保留主线和手动档。回看状态先还原原进度后执行，避免改到临时回放状态。新游戏同时清主支线，所有重置只写自动档。

室内家具重排后，旧存档若位置落进新家具，会改用该室内安全出生点恢复，章句与其他记录保留，而不是把旧档判作不可读。

## 所有活动字体入口

字体使用 Google Fonts 上游的 Noto Sans SC / Noto Serif SC，SIL OFL 随包，静态化后随游戏发布：

- MapSans.ttf：地图 UI、设置、HUD、人物图鉴、存档、大小地图、场景字牌等，黑体400。
- MapHeading.ttf：真实600字重标题，避免小字号合成粗体糊成一团。
- StorySerif.ttf：主线正文默认宋体400；设置→阅读体验可选择宋体或清晰黑体，并实时预览、保存。

GameFonts 统一资源入口，GameUI/所有旧独立 GUI 字体入口替换，GUI skin设置统一地图字体；主线按选择刷新缓存样式。室内/室外 TextMesh 和门牌使用同一地图字体，校门旧文字 PNG 的活动绘制替换为动态字牌；未修改人物立绘。源脚本中不再调用 OS 字体工厂或引用雅黑/宋体/Arial。工具说明与上游地址在 tools/fonts/README.md，准备脚本 build-static-fonts.py；局部字体环境、变量源、wheel缓存已忽略，静态 TTF 与许可证正常入工程。
