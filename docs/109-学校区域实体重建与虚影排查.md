# 109 学校区域实体重建与虚影排查

2026-11-11，按作者要求从学校开始逐栋排查。本轮范围不等于全城清理完成。

## 确认的问题与处理

- 校舍仍混用整幅旧立面贴图与实体线脚、门厅，窗框/窗台重复。教学楼凸出体截取同一立面，窗户与楼层错位。改为纯色墙体、实体玻璃、窗框、窗台，楼层线脚不穿窗。
- 八栋校舍另叠夜窗覆盖网格。新校舍直接调整同一块玻璃材质的颜色与发光，不再生成 fx_s_*。
- 教学楼门厅、图书馆钟亭、礼堂柱廊、实验楼、宿舍阳台、食堂、活动中心、门卫及看台分别重建。山墙使用闭合棱柱，台阶从地面实心生成，钟亭嵌入实际屋脊。
- `SchoolExterior` 共用门廊立柱位置/高度，TownData 建立玩家 AABB，模型同时建立柱子、雨棚、屋顶的相机碰撞。
- 建筑在单栋内部按材质合并，保留 b_s_* 名称供排查。建筑材质关闭外扩描边和边缘光，避免薄构件壳体灰边。
- 重建校门牌匾连接、长椅、自行车架、公告栏、花池、垃圾桶。
- 校内普通树取消按相机距离整树隐藏，靠近树干不再突然消失。
- `PavingUnion` 将校园路径与广场连接处改为不重叠的铺装并集，世界 UV 连续，也支持斜向林道。
- 第一人称换人时保留模型隐藏状态，避免重建人物后身体重新进入镜头。

新实现为 `WorldBuilder.School.cs`；旧 CollegiateFront、Portico、LibraryCupola、ModernFront、DormDetail、Bleacher 及调用已删除。建筑坐标、交互名称与室内映射继续使用 TownData，门厅前脸和门共用 EntranceExtra。

这些是已确认的问题，不据此推断所有区域的“虚影”都来自同一种原因。
