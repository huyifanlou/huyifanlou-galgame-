# 116 · 对话、任务手记与统一设置 UI 重设计

2026-11-14。重新设计剧情对话框、任务栏等，按键绑定集中放在设置里，任务区分主线与支线。

## 参考与视觉方向

- [Hades 对话界面 / Interface In Game](https://interfaceingame.com/screenshots/hades-dialogue/)：角色与底部对白的层次、清晰的说话人身份和有限的功能区。
- [Life is Strange 手记 / Feral 官方手册](https://www.feralinteractive.com/en/manuals/lifeisstrange/latest/steam/) 与 [True Colors 辅助设置 / Square Enix](https://support.square-enix-games.com/hc/en-gb/articles/5673097409823-What-Accessibility-options-are-offered-in-Life-is-Strange-True-Colors)：阅读式信息架构、操作偏好集中管理。
- 只借鉴信息层次，不复制游戏图片或界面资源。墨蓝底、暖白纸面、香槟金细线、宋体标题与清晰黑体正文，统一校园悬疑的手记感。

## 界面与行为

- GameUI 统一 1600×900 设计坐标，等比缩放并缓存字体样式，所有按钮使用同一 GUI.matrix。
- 对话框拓宽至画面 84%，暖纸正文、左侧姓名牌，两侧立绘放在框后。底栏保留回顾、自动阅读、快进、暂离、设置、继续按钮。移除分散按键说明和 BGM/SFX 文本标签。字号与打字机速度从设置读取；长句可滚动，大字号增加框高。
- HUD 只保留标题、时间、地图/任务/记录/设置入口及小型任务卡。门口交互可点击，快捷键仍有效。
- 任务手记分主线任务和支线日常。主线显示八章状态、当前场次和地点，未来章节不可从任务页跳转；原回顾功能保留。支线为钟楼广场、樱花林、图书馆三个无对白探索目标，可追踪、直接前往、停留后完成，不改八章正文。
- 支线完成 id 和追踪 id 加入 ProgressSave。旧档缺字段按空状态兼容。支线完成自动保存；重新开始清空本轮任务并回家，保留手动槽。
- 设置由 HelpSidebar 升级，分阅读、按键、画面。39 个实际动作支持修改主键、列出备用键；同场景/全局冲突及保留 Esc 被拒绝。键位与阅读偏好写入 PlayerPrefs。运行输入与显示共用 GameInput，避免只改标签。
- 设置、任务、存档、回顾均有可见关闭按钮。Esc 按帧消耗，防止关对白/地图/人物菜单时又打开设置。设置开启时冻结角色、剧情和世界时间。H 入口保留，常驻界面不提示键位。
