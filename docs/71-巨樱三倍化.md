# 71 · 巨樱三倍化：3×3 粗干、16.8m 冠幅、26.4m 冠顶

作者（2026-10-30）：

> 还是不够大，基于其他数的3倍大，树干也要扩粗

> 注：作者随后要求樱花沿树干分三层分布（不再只有顶部一团冠），
> 见 `docs/72-巨樱三层树冠.md`。本文的 3 倍尺寸规格仍然有效。

## 一、改动

### 1. 巨樱按小樱的 3 倍重建（WorldBuilder.cs）

小樱基准：树干 1 格（0.8m）、冠幅约 7 格（5.6m）、最高约 9.6m。

巨樱新尺寸（`WorldBuilder.cs:2549`、`WorldBuilder.cs:2640`）：

| 项目 | 旧（docs/70） | 现 | 对小樱 |
| --- | --- | --- | --- |
| 树干截面 | 2×2（1.6m） | **3×3（2.4m）** | 3 倍粗 |
| 树干高度 | 9 块（7.2m） | **18 块（14.4m）** | 明显更高 |
| 冠幅 | 13.6m | **16.8m（21 格）** | 3 倍 |
| 冠顶 | 12.8m | **26.4m** | 约 2.75～3 倍 |

- 树冠分 6 层：y19 / 21 / 23 / 25 / 27 / 29，逐层内收，
  最底层 7×7 中央 + 四向 5×5 端冠 + 轴向补隙 + 四角 5×5，
  顶层 5×5 加中心盖顶。仍是 docs/69 的等大 0.8m 体素块，
  三色阶（底深、中主色、顶亮）和四套 UV 变体不变。
- 主枝：四向各从 2 格伸到 9 格（7.2m），托住最外层叶团；
  四角补阶梯短枝，角部叶团不悬空。

### 2. 空地、碰撞、地面铺装同步放大（TownData.cs / WorldBuilder.cs）

- 巨樱空地半径 13.5m → **16.0m**（`TownData.cs:429`、`TownData.cs:491`），
  树冠 8.4m 半径外仍留出步道空间。
- 树干碰撞半宽 1.1m → **1.4m**（`TownData.cs:798`），
  覆盖 2.4m 粗干（碰撞用正方形 AABB）。
- 落叶毯半径 6.8m → **8.6m**，每色 110 片（`WorldBuilder.cs:2861`）。
- 踏石带起点 7.6m → **9.2m**、终点 1.6m → **2.6m**，
  石头停在粗干外侧，不穿进树里（`WorldBuilder.cs:2883`）。
- 杜鹃/花丛在巨樱周围 4.5～5.0m 内仍排除，不压树根。
