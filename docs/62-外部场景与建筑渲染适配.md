# 62 · 外部场景与建筑渲染适配（日间玻璃 / 植被降饱和 / 夜景店面 / 静态合批）

作者（2026-10-28）：

> 优化所有外部场景和建筑，和渲染适配

承接 docs/61 的写实光照链路。本次把**外部可见部分**（立面、街道、植被、夜景店面）逐项对到新渲染下，
并顺手修掉一个“整条街的灯全被误关”的旧 bug。

## 一、日间窗户：从“贴片补丁”改为立面贴图本身

### 问题

切 Linear + ACES 后，所有建筑窗格都读成纯黑。第一版方案是在立面前叠 34 块玻璃片（`win_glass`），
但只覆盖 ~45% 窗格，且 Shaded 面仍黑，反而像补丁。

### 根因

立面贴图 `TextureLibrary.Building()` 把非亮窗画成 `#2c3548`（深藏青）。Gamma 空间还能读成“深色玻璃”，
到 Linear 空间后线性值只剩 ~0.03，被 ACES 压成死黑。玻璃贴片治标不治本。

### 改法

- `TextureLibrary.cs`
  - 非亮窗底色 `#2c3548` → `#5d7286`；
  - 新增上亮下暗的天空反射渐变（顶部 +30% 天光、底部 −20% 暗部）；
  - 两道斜向高光条（18% / 10%），保留原有随机反光斑；
  - 窗框/中梃不变。
- `WorldBuilder.BuildWindowGlow()`：**删除白天玻璃片**（`win_glass` / `WindowGlassRenders`），
  窗格完全由立面贴图表现；`WindowGlassMat` 只保留给店铺橱窗（夜里透暖光）。
- `TimeOfDay`：删除玻璃片开关，保留橱窗 `_Emission` 夜光。

效果：教学楼/住宅/商店街所有朝向（含背面、侧面）的窗格统一变成可读的玻璃，不再逐栋补片。

## 二、植被与草地降饱和

新渲染下草地/树冠的高饱和绿在阳光下接近荧光色。

- `TextureLibrary.Grass()` 全套调色板压向橄榄绿：
  - 底色 `#4a8743/#54904b` → `#5d7245/#657a4b`；
  - 草块/细颗粒/草叶丝同步换成 `#54703f` ~ `#788e58` 区间；
  - 团簇亮顶 `#7ab65c` → `#96a86e`。
- `WorldBuilder`：`ForestBelt` 合并林带色、`TREE_CROWNS`、`BUSH_GREENS` 之前已降饱和；
  草地 tint 保持 `#aebd8f`，与学院/小镇通用。
- 公园验收图：草地从荧光绿变为偏灰的橄榄绿，粉色樱树、土黄树冠作为点缀保留。

## 三、夜景店面与骑楼

### 已有效果（保留）

- 上層亮窗：`WindowGlow` 自发光片，按窗格哈希 45% 点亮；
- 店铺橱窗（绸缎/药铺/书店/照相馆）：夜间 `_Emission` 透暖光；
- 门灯、骑楼红灯笼：夜间自发光（`DoorLampMat` / `LanternMat`）；
- 校园建筑招牌：有 PNG 的 5 栋用招牌贴图做 Unlit 发光片。

### 本轮新增

- **小镇骑楼横匾**：小镇建筑没有招牌 PNG。给 6 栋骑楼商铺在横匾位置加暖色 Unlit 发光条
  （`w*0.55 × 0.22m`），夜里像亮起的匾额；日间随 `SignGlowRenders` 统一关闭。
- **骑楼暖灯**：原来每栋 1 盏，改为左右各 1 盏（x = ±0.26w，y 距地 2.75m，range 8.5）；
  `LampLightPower` 平行数组给骑楼灯 1.4×、路灯 1.0×，夜里把柱廊与店面抬起来。
- **柱列让开门洞**：骑楼柱列跳过 |x| < 1.15m 的开间，茶楼等店门不再被柱子正挡。

## 四、静态合批与“灯全灭”Bug

### 静态合批

`StaticBatchingUtility.Combine` 已覆盖 Flowers / Fences / Lamps / Buildings / Distant / Bushes；
窗玻璃/亮窗/招牌发光片移到独立的 `WindowFX` 根，建筑本体可安全合批。

实测场景规模：**4177 个 MeshRenderer / 884 万顶点 / 107 盏灯**（含室内，室内在远处被视锥裁掉）。

### 找到并修掉的 Bug

路灯/骑楼灯按相机 38m 距离剔除，原实现写在 `TimeOfDay.Update()`。
启动首帧相机还在原点（PlayerRig 尚未吸附），整街灯被判定为“远”而全部 `enabled=false`；
之后 0.25s 一次的剔除在截图/快速验收里往往还没跑第二遍，于是夜景只剩叠加光池贴图。

- 剔除逻辑移到 `TimeOfDay.LateUpdate()`（相机已到最终位置），频率 0.2s。
- 修复后夜景：柱廊、店面、街面都有真实点光照亮。

## 五、性能实测

`-fps` 参数（新增）：关闭 VSync/限帧、允许后台运行，每 300 帧打印 `[Perf]`。

- 焦点窗口、商店街机位、1600×900：**340~356 FPS**；
- 窗口被终端遮住时：约 6 FPS —— 这是 Windows/DWM 对非前台窗口的节流，不是游戏性能；
  用 `AppActivate` 把窗口切到前台后立即恢复 340+。
- 阴影/AO/后处理开关对比（后台节流状态下）：5.6 / 7.3 / 7.5 / 7.5 FPS，趋势符合预期。

诊断参数保留（仅影响启动配置，不影响正常游戏）：

- `-fps`：性能日志；
- `-noshadow`：太阳灯关阴影；
- `-noao`：SSAO 强度置 0；
- `-nofx`：关闭 PostFX 组件。
