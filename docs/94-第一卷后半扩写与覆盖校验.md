## 2｜覆盖校验脚本

`tools/check-coverage.py`，纯标准库，一条命令跑完：

```bash
python tools/check-coverage.py 5 8 \
  "Scenario/第一卷-初遇/05-测试-扩写.md" "Scenario/第一卷-初遇/06-测试结束-扩写.md" \
  "Scenario/第一卷-初遇/07-修罗场-扩写.md" "Scenario/第一卷-初遇/08-护送-扩写.md"
```

- 底本读 `Scenario/原作-我的人生是否有问题/原作全文.md`，按 `## 第N章　标题` 切章。
- 判定：两侧文本**去掉全部标点和空白**后做子串匹配，所以"逗号改句号""引号换直角引号"不算丢句。
- 三档结果：`[命中]`／`[近]`（只差 的·地·得 或阿拉伯数字↔汉字）／`[缺]`（真丢）。
- 扩写稿里 `## 台词分布` 之后的清单一律不参与匹配，避免"把原句抄进表格里"骗过校验。
- 计数口径：说话行 = 形如 `角色：「…」`（`※` 前缀＝新写）；另报 `【内心】／【演出】／【旁白】` 三档数量。
- **分母含无名行**：校长念等级、广播、甲／乙／丙同学的结果，都算说话行。
  所以 06 章的分母是 34 不是 25——上一版我手记"25 → 44（1.8 倍）"两处都不对，已在文件里作废重记。
