- docs/98 完成六人立绘后，作者「先搞建模」→ 把 C 阶段三人的 **MC 像素 3D 模型**实装进 `PlayerAvatar`。

## 二、做了什么（`Game/Assets/Scripts/PlayerAvatar.cs`）

- `CharacterDef` 加 5 个开关位：`male / elfEars / cap / headband / bangs`；新增三预设 `LiLiYa / YaoQingHan / ZiWei`（调色板 + outfit + hairStyle + 开关）。
- `outfit` 由 `sailor|dress|jacket` 扩到 **`maid | school | darkops`**：
  - `Build()` 身体加三套分支（女仆黑裙+白围裙+红领结 / 校服白衬衫+藏青背心+红领结蓝宝石+百褶裙 / 军装藏青大衣+金边立领+肩章+勋章+排扣+腰带）；
  - `Arm()`/`Leg()` 各加三套（女仆黑袖白口+裸腿白袜黑鞋 / 校服白长袖遮腕+裸腿黑鞋 / 军装藏青袖金口+白手套+藏青裤黑靴）。
- 头部配件几何（`Build()` 发壳之后）：精灵尖耳（两侧外上挑两段）、女仆白褶发箍（发际一圈荷叶边）、大檐帽（帽身+金帽墙+前檐+帽徽）。
- `FaceTexture()`：`bangs` 侧扫刘海盖额留一道额缝；`male` 更粗更低平直眉 + 下巴胡茬 + 上唇须 + 右颊疤。
- `FromId` 加 `liliya/yaoqinghan/ziwei`；`Cycle()` 顺序扩为 **樊楼→镜荧→景楠→莉莉雅→瑶清寒→紫薇**（C 键循环，实机查看）。

## 三、为什么这样

- 立绘与建模分离：立绘是统一画风的对话图，3D 模型仍走 MC 像素皮肤流程，但**外形/服装/发色/性别特征按立绘与人设对齐**，保证游戏里和立绘对得上。
- 全部改动**新增分支 + 开关位守卫**：`male/bangs/elfEars/cap/headband` 对樊楼/镜荧/景楠全为 false，`else`→`else if jacket` 行为不变，故三人**零差异回归**（截图核对：樊楼水手服/金发蓝眼无变化）。

## 六、补充：女建模眼睛统一 4×4（作者「女建模的眼睛都和女主一样4×4」）

- 问题：莉莉雅/瑶清寒 之前用 `face="default"`，走的是**男主脸模板**的眼睛（2×2 瞳孔、8px 虹膜、带眉），和女主镜荧的 4×4 女眼不一致。
- 修法：`CharacterDef` 加 `female` 位（莉莉雅/瑶清寒 = true；镜荧走 vampire 脸本就女眼；三男 false）。
  `FaceTexture()` 眼睛段拆成 `if (d.female) / else`：
  - 女眼＝对齐镜荧 v6：不画眉（童稚）、大虹膜(10px) + **4×4 瞳孔** + 上睫毛线 + 单点高光，位置 y24~40；睫毛色 `Lerp(pupil,iris,.25)` 随瞳色走（蓝/紫各自协调，不像镜荧固定 maroon）。
  - 男眼＝原样（眉 + 2×2 瞳孔）。
- 回归：镜荧(vampire 脸未动)、樊楼/景楠/紫薇(else 分支未动)零差异；截图 `shots/99b-{liliya,yaoqinghan,jingying,fanlou}-face.png`。
- 构建 build99b.log Succeeded。
- **追加修「脸上有黑边」（作者）**：两处原因——① 16px 深色睫毛线在齐刘海下糊成黑条 → 去掉女眼睫毛线；
  ② 女眼只填 y24~40，漏了 y16~24（男主眼原本覆盖该区），空处是纹理默认黑 → 女眼肤色底扩到 `R(8,16,48,24,skin)`。
  截图 `shots/99c-*`（仍有黑条=原因②）→ `shots/99d-*`（干净）。构建 build99c/99d Succeeded。
