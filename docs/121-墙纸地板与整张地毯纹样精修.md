# 121 · 墙纸、地板与整张地毯纹样精修

2026-11-15。延续 docs/120 的连续光照，本轮集中处理墙纸、地板和地毯的样式与材质尺度，未改变房间布局、剧情或入口。未提交、未推送。

## 修改

- 墙纸：新增细麻布、窄双线条纹和疏叶藤纹，替换活动房间中的旧圆点墙纸。家中客厅用细麻布，卧室局部灰绿疏叶纹及柔色麻布；宿舍用窄条纹；图书馆用细条纹衔接木护墙；书店与奶茶店用低对比麻布底。微表面起伏保持轻微，不把图案做成凹凸砖墙。
- 地板：家中改宽板橡木，约 20cm 板宽与错位端缝；图书馆/书店的编织拼木降低粗黑接缝，保留横竖拼组；餐厅从棋格换八角砖配菱形嵌块；奶茶店改约 80cm 大规格浅石砖，并分别设置木作、石砖的粗糙度。学校、实验楼、食堂等功能地面保留各自材料。
- 地毯：新增 `DecorativeRug`，每张毯子独立 0..1 UV，按实际长宽设计多层包边、留白和纹样。家中菱形章纹，图书馆/书店细菱格，宿舍间隔条带，餐厅低对比竖纹，奶茶店局部圆环；不再用世界坐标六条平铺纹模拟地毯，解决其看起来像木地板的问题。全铺织毯也删除旧长条接缝。
- 地毯使用薄织物底层与顶面图案，顶面留 1mm 间隔，取消原来另叠几何金边的方式；接触阴影仍有效，不新增通行碰撞。实验楼的导向区域保持环氧材料，不套装饰地毯。
- 图案按房间、颜色、尺寸缓存；纹理分辨率随物理长宽取 128～1024 的二次幂，长条毯不再挤在正方形纹理里。启用 mipmap、三线性过滤和 8 倍各向异性，细格纹在远处更连续。

主要文件：`DetailSurface.cs`、`InteriorMood.cs`、`DecorativeRug.cs`、`InteriorBuilder.cs`。历史 `wallpaper` 配方保留兼容，但当前家与宿舍不再调用旧圆点配方。
