## Decisions

- [2026-10-19] 小镇不再参考 web 版参数/几何/材质——米制世界、真实网格、原生材质；web 仓库仅作资产配方历史
- [2026-10-19] 水面默认静止（作者多次反馈"太波动"）；高度场代码保留，`WaterSim.Animate=true` 一键恢复
- [2026-10-19] 美术路线 = 混合管线：地形/水/路网/植被程序化，地标用 C# 程序化网格（本机无 Blender）；后续可换 FBX
- [2026-10-19] 性能三板斧：锁 60 帧+垂直同步、路灯点光源仅相机 38m 内启用、夜景立面贴图生成移除（改四格亮窗片）
- [2026-10-20] 植被/树用"渲染级硬排除"（Tree 入口直接 return）兜底，数据层过滤不可靠
- [2026-10-25] 室内定稿：单层无楼梯、少墙开放布局、出口=玻璃门扇+门廊（有顶有柱有灯）、窗全落无家具墙段；作者确认方案 A 后才动代码

## Pitfalls

- [2026-10-25] 运行时 Shader.Find 的自定义着色器会被构建剥离 → Bootstrap 占位材质列表必须收录（Campus/PostFX、Campus/Water）；Standard 的 _EMISSION 变体同样要占位材质
- [2026-10-25] 相机 farClipPlane 必须 ≥ 天穹半径+玩家最大偏移（170+95→压到 200 会出"天空黑幕"；现 320/穹 420）
- [2026-10-25] 坡屋顶两片屋面旋转符号极易写反（屋脊变 V 沟+山墙悬空）——通用公式：檐口低、屋面中心取 (檐+脊)/2、山墙从墙顶封到脊、补博风板/檐口封板/soffit
- [2026-10-25] 室内 FP 锁鼠标后 OnGUI 收不到点击 → 按 M 开大地图时 UnlockCursor，PlayerRig 检测 `Minimap.LargeOpen` 让位
- [2026-10-25] 室内装饰/踢脚线与墙纸薄片共面会 z-fighting 闪烁 → 全部内移错层（0.02m 起）
- [2026-10-25] 家具/挂画与门洞、窗洞重叠是最常见返工点——布局先出俯视方案图（PIL 画）给作者确认，坐标逐个核对后再实现
- [2026-10-25] `-indoor` 模式下 `InteriorManager.Init` 内部会直接进房，必须先 `rig.BindInterior(im)` 再 `im.Init`（顺序反了玩家瞬移到室外坐标）
- [2026-10-25] 验收截图的 -px/-pz 是**世界坐标**（室内建在 x≈900/1060），传局部坐标会拍到室外
