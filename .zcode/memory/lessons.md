- [2026-10-19] 旋转组件默认轴坑：Spin 默认绕 X，木马/飞椅必须显式 Axis=up（否则"建筑带动建筑"）
- [2026-10-20] 坡屋顶两片屋面旋转符号易反（屋脊变 V 沟、山墙悬空）——檐低脊高、山墙封到脊、博风板/檐口/soffit 收边
- [2026-10-20] 建筑立面贴图名解析：id 可能含下划线（s_dorm），Split('_') 取段会错——按前后缀截取
- [2026-10-25] 室内装饰/踢脚线与墙纸薄片共面 z-fighting → 全部内移错层 ≥0.02m
- [2026-10-25] FP 锁鼠标后 OnGUI 收不到点击 → 开图时 UnlockCursor，PlayerRig 检测 Minimap.LargeOpen 让位
- [2026-10-25] `-indoor` 先 BindInterior 再 InteriorManager.Init（内部会直接进房，顺序反了瞬移到室外）
- [2026-10-25] 家具/挂画与门洞窗洞重叠是最高频返工点——先出俯视方案图确认坐标，校验器（越界/插墙）+ 模拟行走双验证
- [2026-10-26] 贴墙装潢的定位基准必须是**真实墙纸面**，`cx±w/2` 只是家具/课桌网格宽度；四间教室墙位差 9~62cm，绿板墙裙因此整片悬空
- [2026-10-26] 分五段留门洞的墙，门洞上方无墙 → 门牌/指示牌必悬空；补视觉门楣但**不能加碰撞盒**（室内 2D AABB 不看高度，会堵门）
- [2026-10-26] 文档/提交信息写"已改"必须和 `git diff` 对得上——公告栏上一轮声称挪北墙，实际仍在南墙，四块悬在门厅
- [2026-10-26] 4m 层高下净门洞 1.2m 会读成"竖缝"；住宅门洞舒适下限 1.8m（本轮四道门 1.2→1.8，中心不动）
- [2026-10-26] 家具贴着远离门口的墙摆 = 从门口看不见，等于没摆；先站门口验证视线再定朝向（洗衣房原洗衣机全堆在门侧 1.4m）
- [2026-10-26] 改家具数量/位置必须同步 `Reg` 碰撞盒，否则留下看不见的碰撞（餐桌 6→4 把时漏改）
- [2026-10-26] Legacy TextMesh 默认字体材质是 `ZTest Always`——世界门牌会穿墙，背面文字还是镜像；自建深度测试裁切 shader，放 `Resources/` 用 `Resources.Load` 防构建剥离
- [2026-10-26] 0.05m 墙皮贴 0.24m 厚墙：偏移 0.09m 会整片埋进墙里 5mm（完全不可见），0.11m 才外露 15mm；走廊侧改完还要检查房间侧
- [2026-10-26] 大房间家具必须落在进门视线上；没有书的空书架/贴远墙摆 = 像杂物间（图书角四个空木箱）
- [2026-10-26] 门洞加宽后门楣不能加碰撞（室内 2D AABB 不看高度，会堵死门）；门套+门牌是让人读懂房间用途的最低配置
- [2026-10-27] 室内第一眼由入口视线决定：图书馆主书墙/超市生鲜岛必须正对门，家具全堆侧墙会显得房间是空的
- [2026-10-27] 超市商品不能复用书架书脊尺寸：商品块一大就像书墙；缩到 0.62 尺度、排距 0.17→0.13 才像货架
- [2026-10-27] 圆形地图缩放不能直接缩放贴图矩形（圆遮罩会跟着跑）；用 1024 底图 + 512 当前视图 + 固定遮罩，并预分配 Color[] 自写双线性采样
- [2026-10-27] 地图打开时 PlayerRig 必须跳过鼠标视角/滚轮，否则拖地图会同时转镜头或拉镜头
- [2026-10-27] 室内地图禁传送要在 HandleClick 和 MouseUp 两处都拦住，不能只靠 UI 文案
- [2026-10-27] 建筑级传送点按建筑 id 取坐标，建筑改名（餐馆→餐厅）不影响纹理与传送
- [2026-10-27] 室内面积翻倍不要把家具同步放大：保持人体尺度，用更多分区/桌椅组合填空间
- [2026-10-27] `Glass()` 是不透明窗玻璃，不能用于冷藏柜/展示柜/防溅板；展示面改开放金属框，否则商品被挡成白块
- [2026-10-27] 桌面小物 y 必须按 Table h + 0.02~0.03 落座；书堆 0.84 配 0.76 桌面会悬浮 5cm
- [2026-10-27] 贴墙挂画/酒架/文化墙先和窗、书架、柜台对坐标；否则会埋进书架或压住窗
- [2026-10-27] 大面积室内先排视线轴/主动线再摆家具（超市中轴高货架挡品牌墙是反例）
- [2026-10-27] 出口净空要写进 Validate（门内侧 4~5m、门宽范围），不能靠目测；中岛/水吧/绿植最容易压中轴
- [2026-10-27] 怀疑“旧布局没删干净”先查 Build 调用次数、场景序列化对象和旧函数定义，再判断残留 vs 新摆放
- [2026-10-27] 2D 精灵换 3D 模型只换视觉子节点，CapsuleCollider/移动/门/传送零改动
- [2026-10-27] 3D 模型所有子物体要显式设 Ignore Raycast 层；只在 Player 根设 layer 不继承，会造成相机避障撞模型
- [2026-10-27] 第一人称与镜头贴脸两种隐藏条件都要保留，否则 3D 模型会挡满画面
- [2026-10-27] 3D 低模取原精灵调色板（金发/藏青校服/红领带），换外观不换角色识别度
- [2026-10-27] MC 风方块人按「像素格 × 单格米制」（1.8m/32px=0.05625）拼盒体，比凭感觉拼更快更准
- [2026-10-27] 像素贴片（眼/嘴/刘海/衬衫）必须离方块面 0.01~0.02m，否则与面共面 z-fighting
- [2026-10-27] 方块人动画只需髋/肩枢轴整块旋转，不需要分段骨骼；Create/Tick/SetVisible 接口保持不变可无痛换风格
- [2026-10-27] MC 方块头做精细脸：8px 头正面换 32×32 贴片，比继续加 1px 方块便宜且好看；贴片 UV 必须 1:1
- [2026-10-27] 刘海用逐列高度（斜向碎发）比整块挖矩形自然；脸五官绘制顺序：眼白→虹膜→瞳孔→高光→睫毛
- [2026-10-27] 脸是主角：8px 方块头用 64×64 脸贴图，五官落笔空间是 32×32 的 4 倍；浅金发在暖光下会糊进肤色，发色要更金、发际线要有暗边+皮肤投影
- [2026-10-27] MC 比例下 3D 发片（方块或锥形）近景会读成纸板/尖刺：刘海画进脸贴图，3D 只保留头顶/鬓发/后发体积
- [2026-10-27] 脸贴图自发光用暖白（≈0.37）抬背光面，纯白自发光会把肤色洗灰；调脸先 `-dumpface` 导出运行时 PNG 再改
- [2026-10-27] 默认机位在角色背后且站定会背对镜头：拍正脸必须 `-facing 0 -freeze 1` + 相机在角色南侧，近景 `-dist` 下限已放到 2.2m
